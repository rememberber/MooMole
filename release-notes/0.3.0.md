# MooMole 0.3.0

## English

- Run the full bundled Mole cleanup from the disk overview with a separate confirmation and execution history. This route permanently deletes eligible items and can empty Trash. Item-by-item cleanup still lets you review and move supported items to Trash separately.
- Review supported browser downloads, Mail attachments and selected media exports. Organize personal files on selected folders or volumes, compare exact duplicates and similar photos or videos, and preview files before confirming a move, archive or Trash action.
- Manage ordinary app bundles and supported Homebrew Casks. Review compatible application updates, download eligible signed Sparkle packages, and retain the previous bundle when replacing a supported app.
- Recover eligible files from verified history receipts, restore retained app versions and export complete execution records. Review ZIP and TAR extraction, including supported password-protected ZIPs.
- Use Quick Look refresh, submit a selected folder for Spotlight indexing, or re-register an exact app copy. Storage trends, menu-bar monitoring, low-space reminders, login startup and scheduled folder workflows are opt-in.

Requires macOS 14 or later. Choose `arm64` for Apple Silicon or `x64` for Intel, verify the size and SHA-512, then open the DMG and copy MooMole to Applications. Quit the old app before replacing it. Packages use ad-hoc signing. See [Apple's first-open guidance](https://support.apple.com/102445) if macOS blocks opening. The database migrates to schema v8 with a backup of the earlier schema.

Review each confirmation and back up important data. Recovery depends on an intact receipt and an available destination. Moving files to Trash does not immediately free space. Full validation of Intel interaction, quarantined first open, permissions and cross-version upgrades is still pending.

MooMole is an independent, unofficial project for learning and research, distributed under GPL-3.0-only. Thanks to [Mole CLI](https://github.com/tw93/Mole) and its contributors. The bundled engine remains at 1.65.0. See the [official Mole product](https://mole.fit/). Matching source and dependency materials accompany both installers.

## 中文

- 在磁盘概览中运行内置 Mole 的完整清理，具有独立确认和执行历史。此入口会永久删除符合条件的项目，并可能清空废纸篓；逐项审阅后移入废纸篓仍是独立操作。
- 审阅支持的浏览器下载、邮件附件和所选媒体导出。在选定目录或卷内整理个人文件、比较重复文件和相似照片或视频，预览后再确认移动、归档或移入废纸篓。
- 管理普通应用和受支持的 Homebrew Cask。审阅兼容应用的更新、下载符合条件且签名可核对的 Sparkle 更新包，替换支持的应用时保留旧版本。
- 按有效历史收据恢复符合条件的文件或旧版应用，导出完整执行记录。支持审阅后解压 ZIP、TAR 及受支持的密码保护 ZIP。
- 刷新 Quick Look、提交选定目录的 Spotlight 索引，或重新注册指定应用副本。空间趋势、菜单栏监测、低空间提醒、登录启动和定期目录任务均由用户选择开启。

要求 macOS 14 或更新版本。Apple 芯片选 `arm64`，Intel 选 `x64`。核对大小和 SHA-512，再打开 DMG 并复制到“应用程序”；替换前退出旧版。安装包采用 ad-hoc 签名，系统阻止首次打开时可参考 [Apple 安全说明](https://support.apple.com/zh-cn/102445)。本版将数据库迁移到 v8，迁移前保留备份。

请阅读每次确认并备份重要数据。恢复取决于有效收据和可用的目标位置，移入废纸篓不会立即释放空间。Intel 原生交互、公开隔离下载首开、权限和跨版本升级的完整验收仍待完成。

MooMole 是独立的非官方学习研究项目，采用 GPL-3.0-only。感谢 [Mole CLI](https://github.com/tw93/Mole) 作者与贡献者，内置引擎仍为 1.65.0。欢迎了解 [Mole 官方产品](https://mole.fit/zh/)。两个架构均附有对应源码与依赖材料。

## 日本語

- ディスクの概要から内蔵 Mole の全体クリーンアップを実行し、確認内容と結果を履歴で確認できます。この操作では対象が完全に削除され、ゴミ箱も空になる場合があります。項目を個別に確認してゴミ箱へ移す操作も引き続き使えます。
- 対応するブラウザのダウンロード、メールの添付ファイル、選択したメディアの書き出しを確認できます。選んだフォルダやボリュームで個人ファイルを整理し、重複ファイルや似た写真・動画を比較して、プレビュー後に移動、アーカイブ、ゴミ箱への移動を確定できます。
- 通常の App と対応する Homebrew Cask を管理できます。対応アプリの更新を確認し、署名を検証できる Sparkle パッケージをダウンロードし、対応する App の置き換え時に旧版を保持できます。
- 履歴の有効な記録に基づいて対象ファイルや旧版 App を復元でき、実行履歴をまとめて書き出せます。ZIP、TAR、対応するパスワード付き ZIP を確認して展開できます。
- Quick Look の更新、選択したフォルダの Spotlight インデックス登録、指定した App の再登録が可能です。空き容量の推移、メニューバー監視、容量不足通知、ログイン時の起動、定期フォルダ処理は個別に有効にできます。

macOS 14 以降が必要です。Apple Silicon は `arm64`、Intel は `x64` を選択してください。サイズと SHA-512 を照合し、DMG を開いて MooMole を「アプリケーション」にコピーします。置き換える前に旧版を終了してください。パッケージは ad-hoc 署名です。起動が制限された場合は [Apple の案内](https://support.apple.com/ja-jp/102445)を確認してください。以前のデータベースをバックアップしてからスキーマ v8 に移行します。

操作の確認画面を読み、重要なデータをバックアップしてください。復元には有効な記録と利用可能な復元先が必要です。ゴミ箱への移動で空き容量は直ちに増えません。Intel のネイティブ操作、隔離状態での初回起動、権限とバージョン間更新の全環境での検証は今後の課題です。

MooMole は独立した非公式の学習・研究向けプロジェクトで、GPL-3.0-only で配布しています。[Mole CLI](https://github.com/tw93/Mole) の作者と貢献者に感謝します。内蔵エンジンは引き続き 1.65.0 です。[Mole 公式製品](https://mole.fit/)もご覧ください。両アーキテクチャに対応ソースと依存資料を添付します。
