# MooMole 0.3.2

## English

- The overview offers a scan for cleanup candidates you can review and move to Trash. The separate full Mole cleanup shows its scope and asks you to confirm permanent deletion.
- Recent Operations brings file processing, app uninstalls, full cleanup and Quick Look refresh results into one timeline. Filter for files eligible for a recovery request, confirm their original locations, and see individual or batch recovery results in the timeline immediately.
- The sidebar keeps everyday tasks visible and groups less frequently used tools. Application rows group secondary actions, while maintenance and scheduled processing show common actions and current status more clearly.
- Improved workspace tabs and toolbar controls. Fixed dialog dismissal and restoration of the background scroll position.

Requires macOS 14 or later. Choose `arm64` for Apple Silicon or `x64` for Intel. Verify the DMG size and SHA-512, quit the old app, then copy MooMole from the DMG to Applications. Packages use ad-hoc signing. See [Apple's first-open guidance](https://support.apple.com/102445) if macOS blocks opening.

MooMole is an independent, unofficial project for learning and research. Review each operation and back up important data. The app bundles Mole CLI 1.65.0. Thanks to the authors and contributors of [Mole CLI](https://github.com/tw93/Mole). See the [official Mole product](https://mole.fit/). Matching source and dependency materials accompany both installers.

## 日本語

- 概要からクリーンアップ候補をスキャンし、項目ごとに確認して対象をゴミ箱へ移せます。Mole の全体クリーンアップには専用の入口があり、実行前に処理範囲と完全に削除される内容を確認できます。
- 「最近の操作」で、ファイル処理、App のアンインストール、全体クリーンアップ、Quick Look の更新結果を時系列で確認できます。復元を申請できるファイルに絞り込み、元の場所を確認できます。個別または一括で復元した結果は、すぐに履歴へ反映されます。

- 作業画面のタブとツールバーの操作を改善し、ダイアログを閉じる操作と背景のスクロール位置の復元を修正しました。

macOS 14 以降が必要です。Apple Silicon は `arm64`、Intel は `x64` を選択してください。DMG のサイズと SHA-512 を照合して旧版を終了し、DMG から MooMole を「アプリケーション」にコピーします。パッケージは ad-hoc 署名です。起動が制限された場合は [Apple の案内](https://support.apple.com/ja-jp/102445)を確認してください。

MooMole は独立した非公式の学習・研究向けプロジェクトです。操作内容を確認し、重要なデータをバックアップしてください。Mole CLI 1.65.0 を内蔵しています。[Mole CLI](https://github.com/tw93/Mole) の作者と貢献者に感謝します。[Mole 公式製品](https://mole.fit/)もご覧ください。両アーキテクチャに対応ソースと依存資料を添付します。
