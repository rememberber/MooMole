# MooMole 0.2.0

## English

- Quick cleanup combines Mole candidates, applications and home-folder space usage. Supported user caches and ordinary logs can be moved to Trash after review and confirmation, up to 20 items per batch.
- AI deep scan uses an existing Codex CLI or Claude Code installation to explain selected-folder metadata and Mole candidates. Model-service metadata sharing needs explicit consent and uses your own quota. File contents are not sent. Suggestions remain subject to existing cleanup checks; extra findings are verification clues. Claude requires API/provider credentials and live validation remains pending; Gemini CLI and OpenCode are detection-only.
- Switch between Simplified Chinese, English and Japanese without restarting. Window dragging is restored; restrained task animations respect reduced-motion settings.
- Bundled Mole CLI is upgraded to 1.65.0, with updated source/rule checks and Steam data protection. README screenshots and SVG brand assets are updated.

Requires macOS 14+. Choose `arm64` for Apple Silicon or `x64` for Intel. Open the DMG and copy the app to Applications; quit the old app normally before replacing it. Settings and history stay in the app data directory. Packages use free ad-hoc signing without Apple Developer ID signing or notarization. Follow [Apple's security guidance](https://support.apple.com/102445) if macOS blocks opening; the app does not disable Gatekeeper or remove security attributes.

Uninstall still handles one eligible ordinary app bundle, retaining data outside it. Maintenance execution remains limited to the two-step Quick Look refresh. Protected, uncertain, changed or expired objects are retained. Moving to Trash does not immediately free space; cancellation stops only unstarted work. Check history and actual objects before recovery. Native Intel interaction, quarantined first open, cross-version permissions, full fault/recovery acceptance and complete corresponding-source/license review remain incomplete.

This independent, unofficial project is for learning and research. Back up important data and understand the risks. Thanks to [Mole CLI](https://github.com/tw93/Mole) and its contributors; please support the [official Mole product](https://mole.fit/). GPL-3.0-only. Matching source and dependency materials accompany each architecture.

## 中文

- AI 深度扫描使用已有 Codex CLI 或 Claude Code 解释所选目录元数据和 Mole 候选。向模型服务发送元数据前须明确同意，并使用自己的额度；不发送文件正文。建议仍须经过原有清理检查，扩展发现仅供核实。Claude 需 API/云服务凭据，真实调用验收尚未完成；Gemini CLI、OpenCode 仅检测。
- 简体中文、英语、日语免重启切换；修复窗口拖动，任务动效尊重减少动态效果设置。
- 内置 Mole CLI 升级至 1.65.0，更新来源/规则校验及 Steam 数据保护；更新 README 截图和 SVG 品牌素材。

要求 macOS 14 或更新版本。Apple 芯片选择 `arm64`，Intel 选择 `x64`。打开 DMG 并复制到“应用程序”，替换前正常退出旧版；设置和历史留在应用数据目录。采用免费 ad-hoc 签名，没有 Apple Developer ID 签名或公证。系统阻止打开时请依据 [Apple 安全说明](https://support.apple.com/zh-cn/102445)自行确认；应用不关闭 Gatekeeper、不移除安全属性。

卸载仍仅处理单个符合条件的普通 App 包，包外数据保留。维护仅开放两步 Quick Look 刷新。受保护、未知、变化或过期对象保留；移入废纸篓不等于立即释放空间，取消只停止未开始的操作。恢复前核对历史和实际对象。Intel 原生交互、公开隔离下载首开、跨版本权限、完整故障恢复和对应源码/许可验收仍未完成。

本项目独立、非官方，仅供学习研究；使用前请备份重要数据、理解风险。感谢 [Mole CLI](https://github.com/tw93/Mole) 作者与贡献者，也请支持 [Mole 官方产品](https://mole.fit/zh/)。采用 GPL-3.0-only；每个架构均提供对应源码及依赖材料。

- Mole CLI 1.65.0 を内蔵し、出所・ルールのチェックと Steam データ保護を更新。README の画像と SVG ブランド素材も更新しました。

アンインストールは対応する通常 App バンドル 1 件のみで、バンドル外のデータは保持。メンテナンス実行は Quick Look の 2 段階更新のみです。不明・保護・変更・期限切れの項目は保持します。ゴミ箱への移動で直ちに空き容量は増えず、キャンセルは未開始分のみを止めます。復元前に履歴と実物を照合してください。Intel のネイティブ操作、隔離状態の初回起動、版間の権限、完全な障害・復元および対応ソース・ライセンスの検証は未完了です。
