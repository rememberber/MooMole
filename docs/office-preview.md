# 办公文件的文本预览

文件整理、重复文件和软件内容的“预览内容”入口现在支持 `.docx`、`.xlsx`、`.pptx` 的首条文本摘录流程。按原有来源、扫描 ID 与项目 ID 取得文件，不接受任意路径或网络地址；读取前后继续核对当前扫描、文件身份、本地状态、单链接、账户所有权和保护。预览不勾选文件、不授予移动或废纸篓处理权限。

- Word：读取主正文中的段落、普通表格文字、制表和换行，忽略删除/移出修订、字段指令与不支持的替代表示，不执行字段。不是完整修订视图，页眉页脚、图片、批注、脚注和版式等未还原。
- Excel：按工作簿声明顺序选择工作表，以单元格地址显示共享字符串、内联文字、布尔值和保存的原始值。公式及其已有缓存作为纯文本显示，不重新计算，不应用数字/日期格式。标记被声明为隐藏/深度隐藏的工作表；行列等其他隐藏内容仍可能出现在摘录中，不声称复现可见区域。
- PowerPoint：按演示文稿关系列表的顺序逐张查看幻灯片文字，不用 ZIP 文件名猜顺序。图片、图表、动画、母版、备注和视觉排版未重现；XML 中的文字顺序不保证与画面阅读顺序一致。

空摘录明确提示“不表示文件或所选部分为空”；最多显示当前部分前 64 KiB 文字或 5,000 个单元格，截断有提示。工作表名称与正文为原始文本，不当作界面文案翻译，不解释为 HTML，不根据文件中的链接发起请求。

## 读取与格式边界

在已有单个预览 worker 内读取最多 32 MiB 的完整文件快照，只在内存处理包。OPC 主部件、幻灯片和工作表均按关系与内容类型定位，支持相应 Transitional/Strict 命名空间；不将任意同名 XML 认作正文。内容类型一次建立索引，关系目标只解析到包内的已核对项目，不解包到磁盘，不访问外部关系或执行宏/嵌入对象。

普通单盘 ZIP 最多 4,096 项、声明展开总量 256 MiB；只读取需要的 XML 部件，每个最多 2 MiB、每次累计 8 MiB。拒绝重复/歧义名称、链接、特殊项和未支持压缩。进入 ZIP 库前拒绝可能的 ZIP64 头，限制中央目录分配；本轮不支持 ZIP64。XML 限 UTF-8/1.0、64 层及每部件 100,000 事件，属性数和长度有界，拒绝 DTD/自定义实体。最多 512 张工作表或幻灯片，缺失/外部/歧义的必要关系不作猜测。

解析采用四秒工作预算，沿用八秒响应期限；若系统读取仍在等待，原生槽位保持到实际结束。关闭或切换部分不显示旧请求的迟到结果，不声称已经中断内核读取。加密、旧二进制 `.doc/.xls/.ppt`、宏专用扩展、其他办公格式、过大文件、未知编码和超限/不支持结构提示使用对应应用，不自动转换或启动 Office。

## 验证与后续范围

五项新增后端测试通过：三种包内结构的真实文件读取与原件保留、非文件名顺序关系、工作表共享/内联/公式缓存和隐藏状态、Strict 命名空间、UTF-8 截断、危险关系/DTD/重复/ZIP64/容量/时限，以及扫描后变化与保护拒绝。另用系统 `textutil` 在自动回收的系统 TempDir 导出一份独立 DOCX，正式预览读回中文正文并核对原包未变；未启动用户 Office 程序或触碰个人办公文件。精简原生输出收尾合并至 `.cache/verification/native-evidence.json` 的 `office-preview-native.json`。

界面已接入正文/工作表/幻灯片摘录、部分选择、隐藏/截断/空摘录说明、中英日文和现有独立文件处理确认。六份原生预览输出（包括独立 Apple 导出）均经正式 TypeScript 协议解析器接受，协议错绑、格式/页序/容量/异常名称拒绝另有单元验证。默认后端全量 689 项通过、105 项显式忽略；前端 251 项及构建/语言检查通过。办公预览十项与原有预览/个人整理/重复文件十一项 WebKit 页面回归通过；浏览器传输夹具验证了预览不选择或执行、工作表切换、公式/脚本文字原样显示、独立确认、关闭后的迟到结果及语言切换，不替代原生 App 的系统界面证据。

预览窗口补齐内边距后，办公及原有静态预览十三项再次通过。960×780 中英日截图在结束过渡动画后核对，文字、部分选择和返回操作可见且无横向溢出；截图、编译缓存与自建样例均在收尾清理，只保留精简验证记录。

这里证明有限文本摘录能力，不等同于 Office 的完整渲染或格式校验。真实第三方工作簿/演示文稿兼容性、打包 App 原生窗口、完整版式预览、其他办公格式、更大文件和故障矩阵继续保留在完整目标中。
