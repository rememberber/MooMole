# 紧凑桌面界面

2026-10-17，根据用户“简洁高效、更像桌面应用”的要求更新。沿用 React/Tauri，调整布局与信息层次，不更换技术栈或执行语义。

## 结构

- 侧栏只负责功能定位、设置、关于及 Mole 官方入口，当前页通过选中态和 `aria-current` 标识；不再重复“工作空间”、品牌副标题或本地运行宣传卡片。
- 顶部保留可拖动区域和紧凑、固定的操作工具栏。刷新、扫描、目录选择等主操作始终在同一位置；不再占用一整块页面标题区。输入和按钮不参与拖动。
- 主内容直接展示结果。移除页面面包屑、大标题/副标题、英文装饰标签，以及列表中与视图按钮重复的标题；有实际区分作用的数据分组、数量、路径、时间和状态继续保留。
- 首页直接显示 Mole CLI 版本、引擎状态、磁盘及系统数据，保留显著的版本位置；去掉宣传标语、装饰插图和与侧栏重复的功能卡片。
- 侧栏、卡片圆角及空状态留白收紧；不靠缩小关键结果字体或隐藏风险来压缩页面。常用窗口下尽量先看到数据，而不是导航和说明。

## 空间分析

工具栏合并返回、前进、上一级、可编辑路径、开始分析及选择目录。取消目录面包屑，祖先路径通过上一级或直接输入访问；按钮提供可访问名称和目标路径提示。

结果保留实际扫描路径，即使输入框已经改成另一条路径，也能辨认旧结果的范围。返回/前进仍重新调用 Mole，成功后恢复会话查阅上下文，失败/取消继续保留旧结果；不改变 32 份上下文、重载清空或选中路径必须绑定新结果的边界。

## 必须保留的信息

只读检查、浏览器示例、引擎不可用、保护、权限受限、未知大小、部分结果、过期、失败及取消状态不能因简化而隐藏。协议和技术证据按需展开，数据分组标题及恢复说明保留用途。

重复的页面页脚已移除。学习研究用途、使用风险、上游致谢及官方产品入口仍在首次使用和“关于”中，侧栏保留直接官方入口；窄窗口也能通过关于图标访问说明。首页继续显著展示 Mole CLI 版本。

## 验证边界

自动化回归检查六页的主操作、内容区域命名、版本、关于/官方入口、键盘路径提交和根目录边界；浅色/深色 960px 截图检查溢出及信息层次。会话上下文测试按实际可滚动范围比较，不假定旧布局高度。

原生验收覆盖最终构建、实际 Mole 读取、工具栏输入与导航，以及设置/关于入口。证据见开发记录第二十九阶段。本轮不宣称完整 VoiceOver、全部缩放比例、免费 DMG 首次安装或最终发布验收已完成。
