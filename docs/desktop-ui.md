# 紧凑桌面界面

2026-10-17，根据用户“简洁高效、更像桌面应用”的要求更新。沿用 React/Tauri，调整布局与信息层次，不更换技术栈或执行语义。

## 结构

- 侧栏只负责功能定位、设置及 Mole 官方入口，当前页通过选中态和 `aria-current` 标识；不再重复“工作空间”、品牌副标题或本地运行宣传卡片。设置旁不展示快捷键，侧栏不单独展示关于/应用版本；关于信息统一通过“设置 → 关于”访问。
- 顶部保留可拖动区域和紧凑、固定的操作工具栏。刷新、扫描、目录选择等主操作始终在同一位置；不再占用一整块页面标题区。输入和按钮不参与拖动。
- 主内容直接展示结果。移除重复页面名称的全局面包屑、大标题/副标题、英文装饰标签，以及列表中与视图按钮重复的标题；有实际用途的路径导航、数据分组、数量、时间和状态继续保留。
- 首页直接显示 Mole CLI 版本、引擎状态、磁盘及系统数据，保留显著的版本位置；去掉宣传标语、装饰插图和与侧栏重复的功能卡片。
- 侧栏、卡片圆角及空状态留白收紧；不靠缩小关键结果字体或隐藏风险来压缩页面。常用窗口下尽量先看到数据，而不是导航和说明。

## 连续工作区

根据用户补充，工具栏不再沿用侧栏底色，而是与内容区同色。浅色为白色工作区配浅灰侧栏，深色为深灰工作区配更深侧栏；侧栏始终保留独立的细竖线，功能导航和结果区域清楚分开。

页面位于顶部时，工具栏不显示横向分隔线，操作区与结果区自然连贯。页面滚动后显示细横线，固定工具栏使用不透明底色，避免下方内容干扰操作；回到顶部即收起分隔线，边框预留空间，不引起布局跳动。局部列表滚动不改变页面工具栏的边界。

沿用系统标题栏覆盖布局及窗口拖动区域，不增加另一排标题、浮动工具岛、大面积阴影或装饰渐变。当前采用实色分区，没有引入原生毛玻璃或桌面透底效果；浅色/深色均保留按钮边界、选中态、键盘焦点和只读提示。

主窗口正常退出后尽力记住最近普通尺寸和位置，重开时按当前屏幕工作区调整，显示前完成恢复；不恢复最小化、隐藏、最大化或全屏状态，不保留运行任务。坏记录或偏好保存失败不阻止使用，范围及退出边界见 [窗口恢复](window-placement.md)。

## 空间分析

工具栏合并返回、前进、上一级、可编辑路径、开始分析及选择目录；按钮提供可访问名称和目标路径提示。

根据用户进一步补充，保留有操作价值的目录面包屑：结果摘要中的原路径直接改成可点击的分段路径，不另起一排重复导航或标题。祖先目录可直接点击或用键盘跳转并重新调用 Mole；当前目录为 `aria-current="location"` 文本，不产生重复扫描按钮。路径段较长时省略显示并保留完整路径提示，多个路径段可换行，完整路径仍可在工具栏输入框查阅。

面包屑绑定实际返回的扫描路径，即使输入框已改成另一条路径，也能辨认旧结果的范围。任务进行中或引擎不可用时禁用祖先跳转，失败/取消继续显示旧路径与旧结果；根目录只有当前位置，没有伪造的父目录。返回/前进仍重新调用 Mole，成功后恢复会话查阅上下文；不改变 32 份上下文、重载清空或选中路径必须绑定新结果的边界。

分析任务在页面内显示请求目录、不确定进度和取消确认，取消按钮进入顶部固定工具栏。取消、失败及状态待确认有各自说明，保留旧结果；不在同一分析页重复显示浮动任务框或刷新文案。其他页面继续提供全局任务提示，终态说明仍可查看或关闭。详见 [空间分析](disk-analysis.md)。

## 必须保留的信息

只读检查、浏览器示例、引擎不可用、保护、权限受限、未知大小、部分结果、过期、失败及取消状态不能因简化而隐藏。协议和技术证据按需展开，数据分组标题及恢复说明保留用途。

重复的页面页脚已移除。学习研究用途、使用风险、上游致谢及官方产品入口仍在首次使用和“设置 → 关于”中，侧栏保留直接官方入口；窄窗口也能通过设置图标进入关于。首页继续显著展示 Mole CLI 版本。

系统状态中的进程快照在数据分组内提供名称/PID 搜索与排序，刷新仍集中在顶部工具栏。样本数量、采样时间及较早/未知状态直接可见，指标细节按需展开；列表只读，不增加进程终止操作。范围见 [系统状态](system-status.md)。

操作历史按数据来源分组，客户端任务的搜索、状态筛选和独立刷新位于分组内；点击任务行查看完整目录、时间和诊断，记录 ID 等来源细节按需展开。关闭详情恢复原行焦点，记录消失则回到搜索框；列表每批 50 条，明确最近 200 条查询边界。见 [客户端任务历史](task-history.md)。

任务详情内提供诊断摘要入口，用户主动生成后才展开完整预览和保存操作，不在历史列表增加一排导出按钮。生成后聚焦可滚动的预览；系统保存窗口结束后回到保存按钮。摘要省略路径、任务 ID、精确时间及原始诊断，范围见 [诊断摘要导出](diagnostic-export.md)。

设置关闭后返回实际打开它的按钮或快捷键前的位置，入口失效时回到侧栏设置；加载中取消和失败关闭也沿用该位置。执行详情返回原行，记录消失时回到刷新入口。公共弹窗在移除前关闭，不抢另一弹窗的焦点，嵌套 Esc 仅关闭当前层；详见 [弹窗焦点](dialog-focus.md)。

## 验证边界

自动化回归检查六页的主操作、内容区域命名、版本、关于/官方入口、键盘路径提交和根目录边界；浅色/深色 960px 截图检查溢出及信息层次。会话上下文测试按实际可滚动范围比较，不假定旧布局高度。

原生验收覆盖最终构建、实际 Mole 读取、工具栏输入与导航，以及设置/关于入口。证据见开发记录第二十九、三十阶段。本轮不宣称完整 VoiceOver、全部缩放比例、免费 DMG 首次安装或最终发布验收已完成。
