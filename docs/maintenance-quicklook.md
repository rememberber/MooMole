# Quick Look 首批维护范围与执行核心

2026-10-24：首批维护选择固定 Mole `cache_refresh` 中的两项 Quick Look 操作，先交付有实际用途、无需管理员权限的预览刷新。当前完成的是后端执行核心，**尚未接入执行计划、持久意图、确认和 App 操作入口，不能勾选首发维护门槛**。

## 支持范围

固定上游版本 `1.59.1` / `ba3a0f57f78e4c22818fda701219cc3dd4d6953f`，来源 `lib/optimize/tasks.sh:opt_cache_refresh`。按上游顺序分别建模：

| 固定步骤 | 系统操作 | 用户可理解的影响 |
| --- | --- | --- |
| 缩略图缓存刷新 | `qlmanage -r cache` | 请求重置缩略图磁盘缓存，后续浏览时由系统重建，初次显示可能较慢 |
| 生成器列表刷新 | `qlmanage -r` | 请求重载 Quick Look 生成器；可能影响正在进行的预览 |

本机 `/usr/bin/qlmanage -h` 的只读帮助确认了上述参数含义；本地 `qlmanage(1)` 也说明 `-r` 用于重置 Quick Look Server 和客户端生成器缓存。不把 `-r` 单独宣称为已重建全部图标服务。

这是 `cache_refresh` 的明确子范围，不是完整 handler 已交付。上游还会显式删除三个 Finder 缓存路径，这部分继续不支持；不调用 `optimize` 总入口、不直接删除目录、不修改偏好、不重启 Finder，也不请求管理员权限。其余目录项目继续保留原先只读状态。

## 固定执行边界

`maintenance/quicklook.rs` 仅提供两个内部枚举操作，不接受命令、Shell、域、键、路径或自定义参数。它不是 IPC，序列化结果也不能还原可运行授权。

- 仅允许真实/有效 UID 相同的普通账户；绑定当前账户目录。命令使用清空后的固定环境、明确 HOME 和工作目录，不继承 Shell、PATH 搜索或注入变量。
- `/usr/bin/qlmanage` 在本机是 Apple 系统链接。只解析这个固定入口，持有其物理路径的描述符链，要求固定系统位置、所有祖先 root 所有且无组/其他写位、普通可执行文件、无 setuid/setgid、本地物化且位于只读卷。调用前再次核对原身份、链接实际目标和卷状态；不凭 root 所有者忽略可能的 ACL 写入。
- 每步调用前必须由未来的封闭执行器提供最新规则/保护、确认、互斥租约和已提交持久意图的 gate；拒绝 gate、工具变化、预先取消或无法启动均返回 `notStarted`。gate 前后再次核对工具和账户，不声称最终检查与系统调用原子化。
- 启动独立进程组，标准输入关闭、输出丢弃。结果只依据拥有的子进程状态，不解析终端文案判断成功、对象或处理权限。
- 启动后非零、信号、取消、超时或无法收集都为 `uncertain`，不推断“未改动”。正常零退出为 `commandSucceeded`，仅表示系统命令返回成功，不表示缓存必为空、服务所有后续工作已结束、预览已修复或性能提高。
- 每步 15 秒后请求停止，TERM 后保留 1 秒再 KILL。使用 `waitid(WNOWAIT)` 保持主进程未回收直到最后一次进程组信号，避免 PID/PGID 复用；失去子进程所有权后不再按数字发送信号。回收完成才返回，异常展开也整理自身子进程。内核卡住的回收不承诺硬截止时间，未来 worker 必须继续持有操作租约。
- 已观察到零退出时，迟到取消不覆盖成功。取消停止尚未开始的下一步；对已启动的步骤不能撤销缓存刷新，也不能保证系统服务立即停止后续工作。不能自动重试未知结果。

## 后续接入要求

1. 建立独立的固定任务计划与一次确认，绑定原始选择、期限、引擎版本、最新保护上下文；不复用只读偏好审阅的执行资格。
2. 尊重 `cache_refresh` 的维护任务白名单及配置未知状态；明确客户端路径保护对服务级缓存刷新的影响边界。不能声称已枚举服务的所有文件操作，规则或保护影响无法确定时保留。
3. 两步分别在 SQLite FULL 意图之后启动、持久记录实际结果；前一步成功后取消、第二步失败、退出和重启必须保留已发生的事实。历史不能重新生成授权或自动重放。
4. 纳入清理、卸载、权限检查及更新交接的排他与 worker 租约；关闭观察窗口不结束结果收集。
5. App 明确展示两步的影响、确认、取消及逐项结果。恢复说明为缓存由系统重建，无原缓存备份、没有一键撤销；不承诺提速。
6. 在实际打包 App 中由用户明确触发正常执行，补齐取消/超时/中断、重启与缓存重建体验的证据。当前没有实际运行本机 `qlmanage -r` 或 `-r cache`。

## 当前验证

13 项普通 Rust 测试覆盖固定参数、零退出、带真实私有标记写入后的非零结果、启动前/后取消、忽略 TERM 的超时、迟到取消、启动失败、输出边界、失去子进程所有权和异常展开回收。自建 Shell 子进程仅存在于测试，不开放生产参数。另以只读方式验证本机 Apple 链接、只读卷及 gate 拒绝/取消，未刷新实际缓存。

这些是执行核心的证据，不能代替正式 App 的确认、记录、真实维护与发布验收。共用目标见 [首发执行门槛](first-release-execution.md)，其余偏好路线限制见 [维护边界](system-maintenance.md)。
