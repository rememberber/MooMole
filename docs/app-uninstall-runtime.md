## 核对实际包内进程

复用后端保存的 [独立计划](app-uninstall-plan.md)，检查前后重新核对完整 App 包、原期限及固定 Mole 保护。不接受前端路径、可执行结论或系统命令，不用同名的 Electron 等共享程序名判断某个 App 在运行，也不结束任何进程。

普通账户通过系统 libproc 枚举 PID 与可执行路径：最多 8192 槽、每路径 4096 字节，要求有效列表中有 PID 1 和当前进程，排除非用户态 App 的 PID 0。一次路径检查前后必须取得相同 PID 集合、所有路径读取完成，才报告本次未发现；列表变化/失败最多重试一次，共用约 1 秒检查点预算。已发现的包内进程不会被后续失败、退出或变化覆盖成未发现。

匹配完整 App 路径边界下的实际可执行程序，含 Frameworks 内辅助 App；相似前缀和别处同名 Electron 不命中。对同名包根的其他路径表示，有限读取根元数据，以原设备/inode 区分同对象别名与另一安装副本；无法核对时保留未知。这个只读身份补查不改变源路径必须通过严格无链接观察的要求，也不构成修改资格。

仅将匹配此包的最多 32 个 PID 返回，其他进程路径和 PID 不持久保存或返回界面。报告范围为 `bundleExecutablePaths`，**不是全局空闲、完整文件占用或后台服务证明**。读取资源的外部程序、包外解释器/派生程序、服务定义、登录项、软件管理归属仍有独立边界；此视图也不替代日志清理的授权 lsof 条件。

## 主程序格式边界

脚本可在包外解释器中执行，不能按“未发现包内可执行路径”准备确认。因此先对已绑定、无链接的主程序读取有界原生格式头：核对 Mach-O 大小端、CPU/位数、MH_EXECUTE 和命令表声明范围；Universal 最多 32 个架构，逐片核对头、范围、溢出/重叠与 CPU 一致性。不只看与 Java class 重合的 Fat 魔数，也不把 dylib 当作主程序。

读取前后核对持有主程序与原快照；截断/脚本/不支持格式不提供确认，读取失败或变化撤回。仅读取有界头部/架构表，不执行或完整读取代码；不是完整 Mach-O 验证、签名认证、发布者证明或 dyld 可运行保证。

| 结果 | 后续处理 |
| --- | --- |
| `observed` | 已发现包内运行程序；保留，提示本人退出后重查。即使其余检查不完整也不撤掉该正面发现 |
| `notObserved` | 仅表示本次完整路径检查没有发现；仍需后台/管理方式等条件，当前不能卸载 |
| `unknown` | 未取得完整稳定视图或预算用完；保留，不生成确认草稿 |
| `unsupported` | 脚本或不支持的主程序格式；保留，不生成确认草稿 |

运行观察绑定完整计划历史快照摘要和原计划 ID，原始单调时钟与墙钟共同限制新鲜度为 5 秒；重新核对不会把接收时间当观察时间或续期。报告只描述当次证据，不是锁，也不能消除进程在下一瞬间启动/退出的窗口。

## 确认草稿与代次

`prepare_application_uninstall_confirmation(planId)` 仅从仍保留的后端计划启动上述检查；重新核对当前源清单、首次使用确认和最新保护设置，仍有效且未发现包内进程时，准备随机 ID 的固定范围草稿。`discard_application_uninstall_confirmation(id)` 只撤下该草稿；撤下计划同时撤下其草稿，重建/复核同路径计划撤下旧草稿。

草稿最多 8 份、最长 30 秒且不超过原计划期限，固定只处理这一个完整 App 包，设置/缓存/个人数据全部保留。它绑定完整计划摘要、主目录、引擎位置、客户端身份/位置和保护列表。重复检查使用后端代次；旧结果（包括未知结果）/旧错误不能覆盖新结果，撤销后迟到 worker 不能恢复草稿。IPC 超时或观察界面消失不丢弃实际 worker；它持有原有两份应用检查名额之一及更新安装租约，结束或撤回后释放，不自动重放。

明确提交只能取用一次确认，过期、单调年龄超限、时间回退、计划/保护变化或重放均拒绝并消耗该次取用。取用结果是固定选择，不能由 `Archive` 或前端 JSON 恢复。v2 确认增加普通 App 范围的明确确认要求，提交入口见 [执行协议](app-uninstall-execution.md)；执行器重新取得仍发布的计划、当次对象/运行/管理条件、最新保护/确认/取消及持久意图，再进入最终原生门槛，不拿 30 秒前的运行观察直接执行。

## 验证与下一步

14 项新增 Rust 测试覆盖机器路径协议/原始名称、边界匹配、正面发现与不完整视图、超限/变化/预算、对象别名/其他副本、计划与原始新鲜度、脚本/主程序变化、原生/Universal 头及异常范围、短期选择的一次取用/上下文/撤销/代次/容量。

默认回归还在自建 App 内复制系统 sleep 作为真正运行的辅助程序：系统路径和报告均识别精确目标，检查后子进程仍存活；测试只回收自己的子进程，结束后本次观察未再发现它。此证据不代表完整 GUI App 或后台服务验收。另做普通账户只读能力探测：613 个列表条目、612 个非零 PID 的路径可读，PID 1 可读，无读取错误，约 0.004 秒；不是 root 权限或所有系统/隐私环境保证。

以上初期进程/确认验证没有操作已安装应用、真实个人数据或系统设置，没有授权窗口或废纸篓处理。后续执行器另有自建包实际移入和确切取回证据；前端及实际 App 的真实卸载/取消/退出/重启与恢复边界仍待完成。[首发三项执行门槛](first-release-execution.md) 保持未完成。
