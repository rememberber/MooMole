# 从操作历史恢复原位置

2026-10-30 原生窗口补验：独立优化 App 已从真实两项移动记录勾选并确认批量恢复，两个文件内容与身份保持，历史独立保存。另一次真实废纸篓处理成功，但当前权限下应用内恢复准备被拒绝，未执行；该文件随后仅由 Finder“放回原处”取回。见 [本轮原生验收](consumer-native-acceptance.md)，不把 Finder 取回计作产品恢复成功。

2026-10-30：个人文件整理和重复文件的可靠完成项目，可在活动执行历史中选择“恢复原位置…”。先重新检查当前收据位置与原位置，显示确切路径，再单独勾选确认，执行一项恢复。原收据只是核对依据，不直接授权恢复。

第一节点支持当前账户目录中的本地普通文件、同卷移回。原目录必须仍存在，原文件名必须空闲；同名冲突、目录缺失、文件变化、符号链接、共享硬链接、云占位或保护范围重叠时保留。不会覆盖、自动改名、创建目录、跨卷复制或关闭正在使用文件的应用。首批不接受缓存清理、应用包、未知结果或归档记录直接发起恢复；这些扩展仍在完整范围内。

恢复使用独立的结构化计划，绑定原批次、原项目、原快照摘要、实际收据和当前文件/目标目录见证。确认单次使用，墙钟和单调时间共同限制三十秒有效期。系统调用前重新读取原记录、保护和身份，沿用不覆盖的同卷原生移动。取消只阻止尚未开始的调用；已经移回不再自动撤销。未知结果不自动重试。

持久记录沿用 SQLite v8 的 move 方式，但快照来源独立为 `fileRestoration`，包含原收据关联。执行前先提交 FULL 同步的意图，另存恢复结果与实际位置；原处理记录保持原样。重启不重放，意图未完成按既有中断机制核查；恢复记录支持已有 v3 执行归档，不会从归档重建执行许可。

基本验证：自建文件先真实移动，再通过新恢复执行器移回，核对内容、原记录不变、一次性确认、重开数据库及 v3 归档读回；冲突、替换、保护、未知结果、父目录变化和提前取消有基本验证。前端新增选择、确认、确切路径和取消回归，并回归执行中断/归档，共十二项浏览器流程通过；203 项前端单元测试通过。arm64 release App 已构建并通过 ad-hoc、嵌套程序及 ZIP 解包校验，新入口的实际窗口验收仍待补充。

**尚未完成的废纸篓验收：** 自建样例真实移入废纸篓后，当前进程无法打开 `~/.Trash` 目录（macOS 返回 Operation not permitted），恢复检查因而拒绝；没有修改权限或绕过保护。样例通过测试专用的 NSFileManager 精确取回原路径，身份与内容核对后清理。该取回不算产品恢复成功。真实废纸篓恢复的显式原生测试仍保留为未通过的手动验收项，不把普通目录成功扩大为废纸篓成功。

## 批量恢复主流程

同一活动历史批次中的可靠个人文件、重复文件或相似照片完成项，可逐项勾选，最多 20 项，进入独立的整批确认。筛选不会撤销已勾选项，始终显示包含筛选外项目的选择数量；确认页列出全部当前位置和原位置。未知项、其他来源或仅归档记录不提供选择。原有单项入口保留。

原生仅接收原批次和项目 ID，逐项重新读取可靠收据；同一项、当前位置或目标重叠的计划拒绝。准备时任何一项不能核对，整批不提供确认，用户返回调整选择；已确认后遇到单项冲突、变化、保护或期限到达则记录跳过，其余继续。支持各文件回到不同的原目录，仍仅同卷、不覆盖、不创建目录。停止阻止后续调用，保留已完成结果，没有整批回滚。

整批具有独立的一次性、三十秒、墙钟与单调时钟共同约束的结构化计划；新的单项或批量检查撤销旧确认，过时的准备结果不能发布。确认后先提交一条包含所有所选项的 FULL 同步恢复记录，再逐项提交意图、实际移动和收据。沿用 `fileRestoration` 历史来源及 v3 归档展示，新批量快照有独立模块与修订；旧单项快照继续读取。存储失败立即停止，已移动却未保存完成证据的项目保持未知，重开不重放、不再次授权同一计划。

自建普通目录原生样例已验证：两份文件分别回到不同原目录、内容保留、原记录保持、同一恢复历史、数据库重开与归档读回；准备后目标冲突只跳过该项，第一项完成后取消保留第一项；收据保存失败保留实际移动且第二项标为未知，重开后仍不重试。证据在本地 `.cache/batch-restoration-native.json`。这项证据仍不证明真实废纸篓访问或实际 App 窗口已经通过。

本节点验证：Rust 全量四并发 623 项通过、84 项显式忽略；恢复相关原生测试 6 项通过、真实废纸篓样例 1 项仍忽略。前端单元测试 212 项，批量/单项恢复、历史跟踪/中断/核查及归档页面回归 26 项通过；三语言、格式及构建通过，并检查了 960px 视口下浅色/深色确认页。结果校验沿用完整十进制字符串设备号/inode，覆盖超出 JavaScript 安全整数的值。既有历史“无自动重放”断言补入已上线功能的确切元数据读取和事件订阅，恢复准备/执行仍不在允许列表。验证 App：`local-artifacts/MooMole-0.2.0-mac-arm64-OYhnD9`，通过 ad-hoc、架构及嵌套程序校验，未安装或发布；实际窗口验收仍待补。
