# 整份文件夹与 Mac 元数据归档

2026-10-31：新增独立的整份文件夹 ZIP 路线，保留所有来源，不自动清理。来源是用户明确选择的普通物理文件夹，完整纳入支持的目录、空目录、普通文件和隐藏内容；有任何受保护、未知或不支持项目就拒绝整份，不跳过后把不完整 ZIP 标成成功。它独立于旧的“所选普通文件归档”，不改变后者的数据格式与历史含义。

所有来源须本账户拥有、已落地、同一本地卷；最多 10000 项、64 层，正文加元数据最多 8 GiB，单项元数据 32 MiB、总元数据 256 MiB、名称总量 4 MiB。链接、硬链接、应用/图库包、特殊文件、ACL、非零文件标记、云占位、跨卷子项或无法核对的权限拒绝。普通来源根沿用个人路径保护，内部隐藏项须在整份范围中明确确认；不进入包外路径、不触发云下载。保留名 `__MACOSX` / `._*`、反斜杠/冒号及控制字符不支持。目标为已存在、来源之外的普通目录，不自动创建目录或覆盖同名 ZIP。

使用目录 FD 和 no-follow 枚举，每项核对 inode/模式/修改时间/变化时间、内容摘要与排序后的扩展属性。来源树与祖先身份绑定短期计划，执行前和发布前重新完整核对；不是原子文件系统快照。两分钟确认单次消耗，归档执行十五分钟循环预算；系统调用仍可能等待，取消和安装互斥随真实工作线程保持到完成。

每项通过系统 `fcopyfile(COPYFILE_PACK)` 生成 [AppleDouble](https://github.com/apple-oss-distributions/copyfile/blob/main/copyfile.3) 元数据，写入 ZIP 的 `__MACOSX`；正文与元数据均有独立 SHA-256/ZIP CRC 读回核验。保留普通权限位、扩展属性、Finder 标签、资源分支与隔离属性；不剥离安全标记。使用系统解压器实际支持的 Unix 时间字段保存秒级修改时间，先写完整普通目录树再写元数据，避免交错处理使填充目录的时间失效。读取引起的访问时间变化不作为内容变化；创建时间、纳秒时间、所有者映射、ACL、文件标记和所有解压工具的兼容性未承诺，不视为完整迁移/加密备份。

ZIP 本身不加密，隐藏内容可能包含私密资料。输出文件为 0600 权限，目标空间先按未压缩正文/元数据加 64 MiB 余量核对；发布前只要求剩余余量，不重复要求已写入的 ZIP 再占一份空间。临时文件由目标 FD 相对排他创建并绑定确切 inode；只有本次对象可回收。FULL SQLite 日志先记录建档，再持久保存发布意图与预计文件身份，`RENAME_EXCL` 不覆盖发布，之后核对实际文件与整包摘要。完成写入丢失则重开为未知，不自动重试、删除或继续发布。独立历史本轮 64 条，未知/中断需人工核对后才允许继续，且与旧所选文件归档共同执行准入。

后端自建样例已真正创建 ZIP，并由独立 macOS `ditto -x -k` 解压，核对 Unicode/隐藏名称、正文、空目录、根与空目录属性、Finder 标签、资源分支、隔离属性、权限及文件/空目录/根目录秒级时间。来源正文、扩展属性、模式和修改时间保持，另验证最终完成记录丢失时归档保留、重开未知、阻断不重放。新模块 3 项含主动原生样例、旧所选文件归档 7 项均通过；证据 `.cache/folder-archive-native-completed.json`、`.cache/folder-archive-native-lost-completion.json`。探针另记录系统时间字段与元数据顺序的实际行为，不使用用户数据。

文件整理工具栏已接入“归档文件夹…”：不依赖普通文件扫描；独立选择来源/目标/名称、完整核对、文件/目录/隐藏项目计数、正文与元数据预估及前 50 项名称预览。确认范围始终是整个来源，包含预览之外的支持项目；默认不勾选，ZIP 未加密与原件保留另外说明。可以撤销准备后更改范围、重新检查、取消两个阶段、查看结果和独立历史；运行接回只读，不自动准备或执行。未知核查只记录人工检查，不改为成功或补做操作。

新增 10 项 WebKit 场景与旧归档/个人整理 10 项回归，共 20 项通过：正式页面入口、完整确认、过期/错绑/整份拒绝、两个阶段取消、错误结果不重试、未知核查及运行接回。前端全量 231 项，Rust 默认全量 658 项通过，96 项显式忽略；上述原生样例已单独主动运行。中英日文案、构建及 960×780 确认窗口 `.cache/folder-archive-review.png` 已检查；真实 completed/unknown 记录也经前端协议读回，见 `.cache/folder-archive-protocol.json`。
