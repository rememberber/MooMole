# 工程产物：名称发现与逐项占用测量

2026-10-22。侧栏“工程产物”支持选择项目或项目所在目录，再手动扫描固定 Mole purge 名称匹配的目录。结果展示位置、有限类型线索、客户端保护；可逐项点击“测量占用”，明确区分已测与不完整结果；“查看空间”进入已有的 Mole 只读空间分析。尚未接入清理选择、计划或执行，也不是完整 purge 预览。

## 来源与含义

固定 Mole 1.59.1 / `ba3a0f57f78e4c22818fda701219cc3dd4d6953f`，34 个名称来自 `lib/clean/purge_shared.sh:MOLE_PURGE_TARGETS`。引擎准备阶段只读取 bin/purge.sh、lib/clean/project.sh、lib/clean/purge_shared.sh 的 SHA-256，并复核名称的完整顺序；改变后要求重新审阅。门禁已接入 CI，不 source Shell。

扫描由 Rust 结构化输出，不执行 purge（含 dry-run）、上游配置加载生命周期或清理函数，也不解析终端文案。原版 purge 会初始化缓存统计、加载/可能保存范围等，本客户端不调用这些生命周期。目录名只说明命名匹配；同名 bin/build/target 等可能包含源码、密钥或个人成果，不能据此认定可重建或可清理。

相邻普通单链接、已物化的 package.json / Cargo.toml 只分别为 node_modules / target 增加 Node/Rust 线索，不读取文件内容，不证明标记有效、项目独占或 Git 状态。其他名称继续显示用途与归属待确认。target 同时可能用于 Maven 等，不能仅靠名字断言是 Rust。

## 扫描范围与结构

- 一个明确选择的绝对、本机已物化物理目录；根目录 `/`、链接祖先、不可读/非本地/未下载目录拒绝。作为额外收窄，所选目录本身若叫某个产物名则要求选择项目或上层目录，不声称上游配置不允许此类名字。
- 相对所选范围最多 6 层、10000 个枚举子项、256 个候选、约 4 秒协作预算。产物目录记录后不进入其内部；隐藏目录（命名匹配的产物除外）、Library、Applications 不递归。链接不跟随，非 UTF-8/控制字符名称或超过路径预算保留跳过计数。
- 使用持有的目录描述符、相对 openat/fstatat、O_NOFOLLOW 和目录流枚举；先后核对目录身份与已发现的路径绑定变化。局部失败、非本地、链接、深度或数量/时间限制保留已有结果并报告 partial；所选根目录自身改变则整次拒绝。不是原子快照，也不防御最后复查之后的变化。
- complete 只表示该次定义范围内的名称查找结束，不表示整机发现完整、项目归属验证、内容测量或清理检查完成。空结果不等于没有工程产物；partial 的未显示位置也不能视为不存在。

名称发现协议 v2 包含 revision、root、checkedAt、completion、stopReason、visited、各类 skipped 计数及 items。每项返回 path/name/context/projectPath、projectHint、protection、`measurement: notMeasured`、`canExecute: false`；报告也固定不可执行。没有把目录 inode 大小当作总内容大小，不汇总“可回收空间”。

客户端保护复用已有组件边界规则，包括已知系统位置和设置中的保护目录；命中显示保持现状，规则不可确认显示未知，未命中仍注明其他清理条件未确认。返回前客户端保护列表若变化则拒绝响应。完整 Mole 白名单、作者内容/Git 已跟踪文件/密钥、活动构建、占用、七天保留、大小和实际移除条件仍未检查。

前端复核基线、请求根目录、时间、有限计数、partial 一致性、固定名称、严格子目录、层级/嵌套裁剪、类型线索与不可执行字段；旧协议或矛盾响应拒绝。只提交 root，不发送候选或命令来驱动扫描。

## 交互与任务边界

选择目录不自动扫描，取消选择保留结果；选择新目录清除旧结果。本次刷新失败保留并标注上次结果。当前目录与结果只保留在 App 会话内，不改 `~/.config/mole/purge_paths` 或新增设置迁移。离页不接收迟到结果、不会自动重扫，当前不宣称界面超时能中断系统读取。

原生独立单并发槽和安装操作租约由实际 worker 持有，6 秒 IPC 等待、8 秒前端等待；超时后 worker 返回前不可重复启动或交接安装。退出、首次说明未确认、引擎基线/完整性不可用时拒绝请求。扫描不保存伪清理计划或维护任务；“查看空间”沿用已有 analyze 任务、历史、取消和结果完整性机制，只读查看不授予清理许可。

## 读取 Mole 已保存的目录（阶段 104）

顶部“读取 Mole 目录”按需读取当前账户固定的 `~/.config/mole/purge_paths`。成功后从紧凑下拉框逐处选择，再手动扫描；读取不探测配置内目标是否存在、大小写是否相同或能否访问，不自动扫描、发现/保存项目目录，也不运行 `purge --paths` 交互式编辑器。原生扫描仍重新检查所选目标，不把配置路径当作许可。

语义依据固定 `lib/clean/purge_shared.sh:mole_purge_read_paths_config` 与 `lib/clean/project.sh:load_purge_config`，共用已有三文件源码摘要门禁。客户端读取 ASCII 首尾空白、空行、整行 `#` 注释、绝对路径、`~` / `~/` 当前 HOME，移除末尾斜杠并按精确路径去重。行内 `#` 属于路径，不执行 Shell、变量/命令或 glob 展开；与上游不同，不访问目标做物理路径/大小写解析，也不在没有保存目录时运行自动发现。相对路径、`~其他名称`、点/空路径段、控制字符、无效 UTF-8 或不带换行的末行均整份拒绝；可改用手动选择。

仅本机已物化的普通单链接配置文件及物理祖先可读，最多 64 KiB、256 行、64 个不同目录，每条不超过 4096 UTF-8 字节。持有描述符、相对 no-follow 只读打开；读取前后检查文件身份/元数据及路径绑定，变化撤回，不发布部分列表。缺失与空列表分别提示，读取失败撤回旧配置选项；已明确选择的扫描目录和上次扫描结果独立保留。配置列表只在 App 会话缓存，不写文件或 SQLite，无新增历史/迁移。

独立只读协议 v1 绑定 revision、当前账户配置来源、读取时间、ready/missing、路径列表及 canExecute=false；前端拒绝错配、过期、重复、越界或可执行宣称。与扫描/测量共享实际 worker 单并发及安装租约，6 秒 IPC/8 秒界面等待；等待结束不声称系统读取已取消。读取中禁用目录选择、扫描、测量/查看空间和再次读取；离页丢弃迟到响应，返回不自动重读。其他页面仍可用。

## 项目/工作区线索（阶段 95）

列表按所选范围内的固定 Mole 项目标记分组：最近的仓库/工作区标记优先，否则取最近的项目标记。固定源码的 5 个 MONOREPO_INDICATORS 和 16 个 PROJECT_INDICATORS 已纳入完整顺序审阅门禁；与产物名称共用三文件 SHA-256。项目组仅代表有限元数据线索，不证明实际归属、清单有效、Git 已跟踪状态或可重建。原有 Node/Rust 的相邻标记线索保留为独立信息。

只检查从所选根到产物父目录已遍历的祖先，不向根范围外探测；该范围可能截断真实工作区，因此不声称等同上游完整归属判定。每层固定检查 20 个去重标记：普通文件要求单链接、本机设备、已物化；`.git` 可为物理目录或普通文件，目录确认本机，文件不解析或跟随 gitdir。其他同名目录、链接、共享文件、未下载、无法读取或设备异常保留 unknown；不存在只表示范围内没有线索。

目录退出前再次核对全部标记元数据与缺失状态；标记/目录变化撤回受影响后代的线索并报告扫描变化。前后复查不是原子快照，也不防止最终检查后的变化。链上任何不确定标记都保留 unknown，不借其他祖先的标记证明归属。

`projectHint` 只有三种状态：`hint` 带范围内祖先 path、workspace/project 和固定标记名数组；`notFound` / `unknown` 不带路径、类型或正面标记。前端复核作用域、严格祖先关系、标记所属表及互斥字段；旧发现协议拒绝。按确切路径集中展示，未找到/未知统一放入“归属待确认”组，并逐项保留具体状态，不提供清理选择或组内可释放总计。

## 逐项文件占用（阶段 94）

点击某一行“测量占用”才进入该目录内部，不自动测量整张列表。使用独立 `measure_project_artifact(root, path)` 只读协议 v1，与名称发现报告分开，不修改其 `notMeasured` 原始字段，也不将分析任务结果回填成清理证据。后端核对原始所选范围、最多 6 层的产物路径与发现裁剪规则，拒绝范围外、链接祖先或别名路径；路径经过两份持有描述符的根/目标绑定验证。名称发现和测量共享原生单并发槽及安装租约，实际 worker 结束前不释放；保持 6 秒 IPC/8 秒前端等待，超时不声称已取消系统读取。

测量仅枚举元数据，使用目录描述符和相对 no-follow 调用，不打开文件内容，也不调用 du、purge 或 Shell。包括产物内隐藏项；最多相对 32 层、20000 个子项、约 3 秒协作预算。只将普通单链接、已物化且与目标同设备文件的 `st_blocks * 512` 计入 `allocatedBytes`，不统计目录自身元数据。共享硬链接完全跳过；符号链接、特殊文件、不可读、未下载/非本地、跨文件系统、深度、变化和数量/时间/整数计数限制分别保留原因。文件元数据前后核对，目录和路径绑定变化拒绝或保留 partial；不能给出原子快照，复核后仍可能变化。

完整响应包含固定来源、root/path、checkedAt、completion、stopReason、allocatedBytes、files、visited、skipped、hardLinks、special 及 `canExecute: false`。前端复核绑定、时间、整数/512 字节单位、有限计数、状态与原因一致性；错误或矛盾结果拒绝。显示“已测文件占用”或“部分文件占用”，后者有具体原因与上次测量时间；partial 且没有成功测得文件时显示“占用未确认”，不显示 0 B。无跳过的空目录/零分配文件可显示 0 B。

这是系统报告的文件分配块观测值，不是完整目录逻辑大小、独占物理空间或可回收空间。APFS 共享/压缩/稀疏文件、文件系统元数据与并发变化均限制其含义；不汇总成清理收益，也不由测量推断归属、可重建、七天保留或执行许可。

测量期间禁用选目录/扫描/其他测量与查看空间，可离页；离页忽略迟到响应，不自动重试。失败保留并标注上次测量；重新名称扫描或选择目录会清空旧测量，取消选择保留。结果只在 App 会话内保留，无新增历史/清理计划/数据库迁移。

## 筛选、排序与分页（阶段 105）

已有结果可按名称/完整路径查找（忽略搜索大小写）、按 Node/Rust/用途待确认线索筛选；仅改变当前列表，不重扫、不自动测量或访问文件。始终保留原扫描总数、时间、不完整原因和执行未开放说明；无匹配与原扫描未发现分别显示，清除筛选不会扩大范围或丢失测量。

保持项目/工作区线索分组，归属待确认仍在末尾。每组按路径或已测文件占用排序，不跨组比较，也不将组内值汇总为可释放大小。完整的零测量可参与排序；部分结果仅表示已测文件下限，完全没有成功测到文件的 partial 与未测量均排在组内末尾，不能作为零。重查失败保留的上次值可参与比较，同时保留错误、时间与部分原因。未验证的用途/归属、客户端保护和其他规则未知仍逐行呈现。

每页最多 50 项，跨组分页保留各组标题，匹配总数与显示范围独立展示；只有多页时显示翻页操作。关键词、类型或排序变化回第一页，成功重扫回第一页且清空旧测量；选择新范围重置全部列表偏好。普通离页/返回保留筛选、排序和页码，不自动发起任务。工程读取/扫描/测量期间禁用这些控件，其他页面仍可用。偏好只在 App 会话内保留，不新增持久设置、协议、权限或后台操作。
