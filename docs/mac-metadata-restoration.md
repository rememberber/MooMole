# ZIP 中的 Mac 文件属性恢复

2026-11-03：文件整理的“解压压缩包”新增默认关闭的“恢复 Mac 标签、资源分支及文件属性（ZIP）”。先选择来源、新目标文件夹及恢复模式，完整检查后，另行确认整个范围。改变模式或来源需要重新检查。普通 ZIP/TAR 的正文解压仍可独立使用，原包、归档前的原文件和已有目标内容保留，不自动打开或执行内容。

本节点打通“整份文件夹 ZIP → 应用内恢复”：正文、空目录、隐藏名称、FinderInfo（含隐藏标志）、Finder 标签/备注、资源分支、TextEncoding、支持的自定义数据属性、普通 Unix 权限及秒精度修改时间。检查显示恢复项、属性、可执行文件、Finder 隐藏项目及不应用的历史隔离记录数量，名称预览对应最终普通文件树。外层目标目录保持 0700；恢复的是其中原文件夹及子项的权限。容量是正文加原始元数据的预留预算，包含 AppleDouble 头部，不等同实际磁盘占用或释放空间。

不是任意 Mac 备份的完整还原：不恢复所有者、组、ACL、文件标记、创建时间、访问时间或历史安全批准。当前支持明确提供普通 Unix 权限、0x5455/0x5855 修改时间的 ZIP；缺少这些字段、冲突时间、特殊权限、不可读/不可遍历目录、链接、别名、未知系统属性、未配对/重复/损坏 AppleDouble、无法解释的 `__MACOSX` 内容整份拒绝。不会静默丢弃普通空目录或仅按 `._` 名称吞掉文件。可以另行选择正文模式保留原始元数据文件；不会自动降级后继续执行。TAR 的 Mac 属性、更多来源/编码/卷及其他备份属性仍在后续范围内。

AppleDouble 经过格式、区间、重复、配对、CRC 和摘要核对才消耗；单项数据属性最多 32 MiB（另限 64 KiB 头部）、全部原始元数据最多 256 MiB，沿用整个压缩包 2 GiB / 展开预算 8 GiB / 10000 项 / 64 层等限制。不把不可信 AppleDouble 交给 `copyfile` 自动 UNPACK；在本次排他创建、逐层 no-follow 和 inode 核对的暂存对象 FD 上逐项应用受支持属性，子项先于目录，最后完整核对内容、成员、身份、权限、时间、数据属性和隔离标记，再不覆盖发布。格式参考 [Apple copyfile 实现](https://github.com/apple-oss-distributions/copyfile/blob/main/copyfile.c)。

恢复模式始终通过公开 Foundation `NSURLQuarantinePropertiesKey` 在私有自动回收样例上取得新的系统隔离标记，再应用于所有输出并核对；不会重放压缩包中曾批准的隔离记录，也不修改原压缩包的属性。API 和属性说明见 [Apple URLResourceKey.quarantinePropertiesKey](https://developer.apple.com/documentation/foundation/urlresourcekey/quarantinepropertieskey)。这保留系统后续检查，不等于签名、公证、允许执行或已经验收 Gatekeeper 的所有打开情形。正文模式继续保留原压缩包的隔离属性。

失败/取消只清理本次确切对象，必要时先恢复确切自建目录的写权限；不 chmod 替换目录或删除其中用户新增内容。发布后不自动删除。完成记录丢失仍按已有发布意图重开为未知，保留已发布文件，不重放；未知须人工核对。新增可选 `macMetadata` 摘要，旧记录缺省时序列化形状保持；含新摘要的执行归档使用 v6，仍为固定十六表及现有预算，可与管理器升级记录共存。v1–v5 降级头部拒绝，归档只读，不生成新的解压、回退或恢复授权。

已验证应用自身归档及独立系统 `ditto` 两种真实 ZIP 的原生核心往返，含有效标签 plist、资源分支、根目录自定义属性、隐藏 FinderInfo、只读/执行权限、空目录、修改时间、隔离及原件保持；取消、替换/新增对象保留、完成记录丢失后 SQLite 重开未知、v6 导出/只读读回与降级拒绝。实际 Rust Header/View/Record/Detail 进入生产 TypeScript 校验通过；精简证据为 `.cache/verification/native-evidence.json` 中 `mac-restore-native.json` 和 `mac-restore-protocol.json`。页面确认、任务/历史、错绑、语言及相邻归档链路另有 WebKit 回归，不能代替实际打包 App 窗口验收。

本节点 Rust 默认全量 **737 通过、114 显式忽略**，新增五项含上述两种真实 ZIP 往返及故障/保护回归；忽略项未算通过。前端全量 **277 通过**；WebKit **53 项通过**（ZIP/TAR 解压、文件夹归档、执行归档和归档副本整理），含新模式中英日确认和只读 v6。生产构建、4475 条语言目录、前端格式、变更 Rust 文件格式、工作区清理六项回归通过；960×780 新模式确认及 1200×900 v6 详情截图已读回，内容无横向溢出。
