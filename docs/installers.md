# 安装包：明确范围的只读文件线索

2026-10-21。侧栏“安装包”支持原生选择目录，再手动扫描并展示位置、扩展名、文件逻辑大小、客户端保护和共享硬链接状态；DMG/ISO 可逐项读取系统连接列表，各类文件可逐项观察可见进程的打开记录。Finder 按钮只定位当前路径；不打开、安装或处理文件。这是首版文件名线索清单，不是完整 Mole installer 候选/清理流程。

## 固定来源与差异

固定 Mole 1.59.1 / `ba3a0f57f78e4c22818fda701219cc3dd4d6953f`。`bin/installer.sh` 的 SHA-256、六个扩展名（dmg/pkg/mpkg/iso/xip/zip）和默认 2 层深度纳入引擎准备及 CI 的源码审阅门禁。源码只读取，不执行或 source，不调用 installer（含 dry-run）或删除函数。

客户端只扫描一个用户明确选择的物理本地目录。工具栏提供固定 Mole 的 12 个默认位置（如下载/桌面/共享、iCloud、Homebrew、Mail、Telegram），也保留原生目录选择器；从不会自动遍历这些位置。扩展名匹配不区分 ASCII 大小写，是客户端文件名线索规则；不把名称匹配说成格式正确、已经使用完或可清理。

上游 ZIP 候选需要完成条目列表，再检查前 50 条中是否有特定安装条目。查找阶段仍不读归档数据，ZIP 初始显示“ZIP 内容未确认”；可点击“检查 ZIP”按固定规则手动读取完整、有界列表，结果只是条目名称线索。条目检查之后另可展开并手动测试 ZIP 压缩数据/CRC，不自动触发、不写出文件，也不因此证明用途/签名或可清理。DMG 可另行手动核对系统返回的内部 CRC32；其余格式仍只匹配名称，不检查内部数据。包目录（例如目录式 .pkg/.mpkg）不纳入普通文件清单，保留跳过原因。

## 范围、观察与协议

- 绝对目录路径不超过 4096 字节，拒绝根 `/`、点/父路径分段、链接祖先及未下载/非本地根。选择外接盘上的本地范围也只读，不预判卸载、挂载或移除安全性。
- 默认相对 2 层、10000 个枚举子项、256 个结果、约 3 秒协作预算；包括隐藏目录。链接不跟随，跨文件系统/未下载内容、不可读、名称异常、包目录或特殊类型、变化及预算分别记录。不扫描到的地方不能视为不存在。
- 共享目录访问组件复用工程产物原先的 fdopendir/readdir、openat/fstatat、O_NOFOLLOW 与本机/已物化检查，行为不变；根目录使用 AnchoredPath，逐项前后核对身份和元数据，退出核对目录变化，最后复查根/路径绑定。根变化拒绝整份报告，局部未覆盖保留 partial；不是原子快照，也不防止复查后变化。
- 普通文件只读 stat 元数据，不打开内容；`sizeBytes` 使用 Mole 的 `stat -f%z` 逻辑字节口径。已知零字节显示 0 B，无法表达或确认显示大小未知，不以未知补零。逻辑大小不等于独占分配块或可释放空间，不汇总回收收益。共享硬链接单独提示，不推断删除后能释放大小。

独立协议 v1 返回固定 revision/root/checkedAt、completion/stopReason、visited、七类 skipped 计数及 items。每项包含 path/name/extension、sizeBytes/measurement、classification、sharing、protection、`usage: notChecked`、`canExecute: false`；报告也不可执行。completion 仅表示定义范围的枚举是否结束，文件名、保护、挂载、占用及清理资格仍有独立限制。前端复核来源、请求根/时间、数量、partial、最多 2 层子路径、唯一名称、扩展名/ZIP 分类、大小与未知状态及不可执行字段，矛盾报告拒绝。

客户端保护复用现有路径规则与用户设置；命中/无法确认均提示保持现状，未命中不等于满足其他清理条件。原生返回前确认保护列表没有改变。完整 Mole 保护、完整进程占用、下载中/活动文件、真实安装包格式或移除条件仍未完成。六类普通文件另有可见进程的只读打开记录观察，未发现仍保留未知。DMG/ISO 另有手动系统连接路径观察，不能证明映像身份、挂载卷状态或未使用。

## 交互与任务边界

选择目录不自动扫描；取消保留列表，选择新目录清除旧结果。本次刷新失败保留并注明上次结果。离页忽略迟到响应，不自动重新扫描；范围和清单只在 App 会话内保留，无数据库迁移、伪计划或清理历史。

独立单并发槽与安装操作租约由实际阻塞 worker 持有，6 秒 IPC/8 秒前端等待，超时不声称取消系统调用；worker 结束前不能重复扫描或交接安装。退出、首次说明未确认、固定引擎不可用时拒绝。Finder 沿用现有只读路径定位入口，不承诺定位扫描时的同一对象；此入口不授予安装、删除或清理许可。

## 明确位置与列表查阅（阶段 98）

工具栏下拉框提供常用位置与其他 Mole 位置，共 12 项，完整模板及顺序与 `INSTALLER_SCAN_PATHS` 一起纳入源码门禁。只把 App 已有的当前 home 代入 `$HOME/`，共享位置保持原绝对路径，不做 Shell/环境求值、路径补全、存在性探测或后台读取。home 无效则不提供快捷位置，原生选择器仍可使用。没有新增系统更新路径，也不改 Mole 默认配置。

选中一处只设置本次范围，清除旧清单与 ZIP 观察，不调用扫描；仍需用户点击“扫描目录”。原生扫描的物理路径/本机/权限规则不变，不存在、受限或链接目录如实报错。列表仅保留在 App 会话，无自动范围记忆/重扫；取消原生选择仍保留原结果。

内容区支持按名称/路径和六种类型筛选，默认已知文件逻辑大小从大到小，未知大小排后，也可按路径排序。只对现有结构化结果做内存处理，不运行 CLI 或删除项目；保护/共享/未知字段保持不变，不汇总可回收大小。始终显示原扫描数量、完整性及“显示 N / M 项”，筛选空结果明确区分于扫描未发现，并可清除筛选，清除不重扫。

换根范围重置名称/类型筛选并清除旧结果；离页后查阅筛选回到初始状态，已有会话扫描/ZIP 观察按原机制保留。ZIP 检查或重新扫描期间禁用筛选，避免隐藏正在检查的行；工具栏的位置选择也遵守既有运行/选择/ZIP 检查互斥。常用位置控件明确设为非窗口拖动区域，保持可点击。

## ZIP 条目名称检查（阶段 97）

每行单独点击“检查 ZIP”，调用固定 `/usr/bin/zipinfo -1 /dev/fd/3`。不通过 Shell，不传递用户命令或继承 ZIPINFOOPT 等环境；原生重新核对范围内两层的单链接普通 ZIP，根与目标本机/已物化/同设备，持有描述符，相对 no-follow 只读打开后再次核对身份与元数据。子进程只接收复制的文件描述符，不根据扫描时的路径字符串重新打开归档。

复用现有进程组监督和有界管道：stdout/stderr 各不超过 256 KiB，2 秒运行预算和 2 秒 CPU 上限；停止/回收还有独立宽限，不能承诺 2 秒内返回。退出成功且列表完整后才匹配，最多 10000 条；有特殊控制/转义表示、无法处理的编码/列表格式、过大、失败或超时保留 unknown，不从成功前缀推断有安装内容。首 50 条以大小写敏感的 `.app/.pkg/.dmg/.xip` 路径片段后缀匹配，保持固定 Mole 窗口和类型顺序，门禁也核对该窗口与四类型数组。

界面区分“发现安装条目线索”“前 N 条未见安装线索”和“ZIP 内容未确认”。未匹配只描述窗口，不证明整个 ZIP 是普通档案；名称匹配也不证明文件格式、数据完整性/签名、可安装、冗余或可清理。条目检查不解压、不读取条目载荷、不执行归档程序，不从 ZipInfo 文本取得待处理对象或给出执行资格；只返回固定类型标签，不展示/保存条目名称。未来修改操作仍须独立结构化计划与实际保护验证，不能把此提示当作准入依据。

条目检查协议现为 v2，包含固定 revision/root/path、checkedAt、fileStamp、state/reason、totalEntries/checkedEntries、matchedTypes 和 `canExecute: false`。完整列表成功才有总数/窗口计数；unknown 不携带正面类型与计数。前后复查根、目标和路径绑定，变化拒绝整个观察；不是原子快照，最终检查后仍可变化。检查读的是当前路径独立观察，不回填旧扫描的大小或分类字段。

与名称扫描共用安装包单并发槽和安装租约，实际异步 worker 全程持有；12 秒 IPC/14 秒界面等待不假装中止底层读取。检查时禁用范围/扫描/其他检查和 Finder 操作，可离页且忽略迟到结果，不自动重试。重查开始即撤回旧观察，失败不继续显示先前正面提示；重扫或换目录清空所有 ZIP 观察，取消选择保留。共享硬链接不开放 ZIP 内容检查，需重新扫描确认状态。依旧只有会话数据，无新增数据库、维护任务或清理历史。

## 映像连接路径观察（阶段 99）

DMG/ISO 行提供“检查连接/重新检查连接”，选择或扫描不自动检查。固定调用 `/usr/bin/hdiutil info -plist`，复用进程组监督和 2 秒运行预算，stdout/stderr 各最多 256 KiB；只有完整成功输出才交给系统 Foundation plist 解析。最多 128 条映像记录，要求 images 数组与每项有效绝对 image-path；缺字段、异常类型/路径、解析失败或超限保留未知，不发布正面前缀。命令与参数固定、环境清空、无 Shell、无用户路径参数，不打开映像内容，不调用 attach/detach 或解析 alias。

结果仅区分“系统报告此路径已连接，请先保留”“本次连接列表未见此路径；文件占用仍未确认”与具体未知原因。连接包括尚未挂载文件系统的 attached 映像；只按系统报告路径精确比较，不根据卷名猜测，不把路径匹配当作当前文件与已连接映像的身份核实。大小写、路径别名、移动/替换或状态随后变化都可能影响观察；未列出不证明未连接、未占用或可清理，也不验证格式/签名。系统列表可能含其他映像位置，仅在原生内存解析，不返回/持久化其他路径、设备或挂载点。系统来源可在本机 `hdiutil info -help` 与 `man hdiutil` 查阅；使用 plist 接口而不解析终端文案。

独立协议 v1 绑定固定 revision、root、path、checkedAt、state/reason 与 canExecute=false。原生拒绝范围外、两层以外、非 DMG/ISO、链接/特殊文件、未下载、跨文件系统和共享硬链接；只持有元数据描述符，前后核对所选根与目标的身份/元数据/路径绑定，变化撤回整个观察。它不是原子快照；不从连接文本获得修改目标或执行资格。

复用安装包单并发槽、真实 worker 安装租约及保护设置复核；12 秒 IPC/14 秒前端等待不假装系统读取被取消。检查期间锁定范围、筛选、ZIP 与 Finder 操作；离页忽略迟到结果。重新检查开始撤回原观察，失败保留本次未确认；重扫/换范围清空，取消目录选择保留。只存本次 App 会话，无数据库迁移、系统权限请求、挂载/推出动作或清理历史。

## 可见进程占用线索（阶段 100）

六类普通单链接文件可手动“检查占用/重新检查占用”，扫描不自动触发。客户端附加观察遵守 Mole 对占用/未知保持现状的原则，但不运行 `_mole_complete_lsof_mode`、sudo 或完整删除生命周期，不声称取得完整进程视图。固定系统 `/usr/sbin/lsof -nP -F0pftDi -- <validated-path>` 只选择此文件，不递归目录；不收集命令名、文件名字段或展示/保存进程标识。读取 NUL 分隔机器字段，不解析终端提示文字。

每个文件记录必须绑定 REG 类型、当前目标设备号和 inode，完整成功输出才发布“发现其他进程打开此文件，请先保留”。排除本 App 的全部进程记录，避免自身 O_EVTONLY 元数据句柄让所有文件误报占用；这也意味着不判断本 App 内其他句柄。空列表或仅有自身记录显示“可见进程中未发现其他打开记录；视图有限，占用仍未确认”，不存在 noOpenHandles、idle、安全或可执行状态。非成功退出/超时/受限、记录不完整/身份错配、数量或字节超限均保留未知。即使发现句柄，也不证明正在下载或写入；记录不是持续所有者租约。

最多 4096 条进程/文件记录，stdout/stderr 各 256 KiB，2 秒运行预算及既有停止/回收宽限。参数与环境固定，不读取文件载荷，不关闭进程、不修改权限或申请管理员权限。原生只持有目标元数据描述符，重用明确根内两层、本机/已物化/同设备/单链接普通文件规则，前后校验根/目标/路径绑定；变化撤回。最终复核后仍可立即出现新句柄，不是原子快照。

独立协议 v1 返回固定 revision、root/path、checkedAt、busy/unknown、互斥 reason 与 canExecute=false；前端拒绝空闲或安全宣称。与 ZIP/连接检查共享实际 worker 单并发及安装租约，独立保留会话观察；当前检查类型单独绑定，避免同一行多按钮同时显示进度。范围、筛选、其他检查和 Finder 操作互斥；重查撤回旧占用观察，失败保留本次未确认；重扫/换范围清空三类观察，取消选择保留，离页忽略迟到。不新增数据库或清理历史，也不把原文件清单的 usage=notChecked 改写为已通过。

## 手动 ZIP 数据测试（阶段 101）

完整条目检查成功后，行内显示折叠的“ZIP 数据尚未校验”；展开仅显示说明，不读取数据，需另点“校验 ZIP 数据”。固定调用系统 `/usr/bin/unzip -tqq -P '' /dev/fd/3`，通过持有的只读描述符读取，不按旧路径重新打开。`-t` 在工具进程中解码并检查数据/CRC，不把归档条目写到磁盘或执行它们；只传固定空密码以避免交互，不接收或尝试用户密码，不展示原始工具诊断或条目载荷。环境清空、工作目录固定 `/`，不执行 Shell 或解压选项。工具选项可在本机 `unzip -hh`/`man unzip` 查阅。

只对当前压缩文件不超过 64 MiB 的 ZIP 执行测试，超出则保留未知；这个门槛不是解压后字节上限。运行预算与 CPU 上限各 2 秒、stdout/stderr 各 256 KiB，复用既有进程组监督、停止/回收/管道宽限。只有完整成功退出且 quiet stdout 为空才报告“ZIP 数据测试通过；签名与用途未确认”。非成功/读取受限/加密或不支持/超时、异常输出及超限均为未知，不从诊断猜测一定损坏，也不把前缀当作完成。它不是密码学认证、安装包用途、可安装性、冗余或移除资格。

条目检查升级为 v2，返回由原生持有路径 witness（身份、元数据及路径祖先）编码后计算的 SHA-256 fileStamp；前端拒绝旧协议/缺失或无效摘要。独立数据测试 v1 要求请求携带该摘要，原生重新执行原有明确范围/两层/普通单链接/本机/已物化/同设备校验，并在运行前与新 witness 摘要比较；不一致拒绝数据测试。结果也带同一 fileStamp，前端复核预期绑定，避免旧条目和新文件混用。摘要只是当次关联/变化检测，不是文件载荷哈希、持久信任根或执行凭据。最终复查后仍可变化，不提供原子快照。

数据结果只保留本次 App 会话，独立于名称/连接/占用观察；原扫描大小不改写。重新校验先撤回旧数据；工具正常返回的 unknown 不撤回同一 witness 的名称线索。IPC 失败/身份或协议无法确认时保守撤回旧名称与数据结果，提示重新检查 ZIP；重查条目、重扫或换范围也清除旧数据。取消选择保留，离页忽略迟到，不自动重试。检查期间范围、筛选、其他检查与 Finder 互斥，共享真实 worker 安装租约及 12 秒 IPC/14 秒前端等待边界。没有新数据库、权限请求、落盘解压、签名验证、处理或清理历史。

## 手动 DMG 内部校验和（阶段 102）

DMG 行内提供折叠的“DMG 数据尚未校验”，展开只显示说明；另点“校验 DMG 数据”才读取映像。固定系统 `/usr/bin/hdiutil verify -nocache -plist -stdinpass /dev/fd/3`，不挂载、不安装、不接收密码或执行载荷。只传已持有的只读 fd，环境清空、工作目录 `/`、stdin 为 null；不通过 Shell 或旧路径再次打开。`-nocache` 禁用本次工具校验缓存，不能把它当作整个 DiskImages 框架没有内部状态的保证。工具选项来源为本机 `hdiutil verify -help`/`man hdiutil`。

只处理明确根内两层的本机/已物化/同设备/普通单链接 DMG，128 MiB 文件门槛、4 秒运行及 CPU 预算、stdout/stderr 各 32 KiB，停止/回收还有既有宽限。完整成功退出后，系统 Foundation 解析 plist，要求根恰有 calculated/expected 两字典，每个恰有 Checksum Type/Value；仅识别 CRC32 与 `$` 后八位十六进制，实际/预期一致才显示“DMG 内部校验和匹配；签名与用途未确认”。失败、加密/受限/超时、超限、未识别/缺失/不匹配校验和或异常报告保留未知，不从终端文案认定损坏，也不发布正面前缀。ISO/其他格式与其他校验算法没有据此开放。

内部 CRC32 不是整文件哈希、密码学来源认证、签名验证或安装/清理资格。本机自建 DMG 副本的字节 100 变化仍通过，数据区字节 1024/中点变化被拒绝，已据此明确“不覆盖所有文件字节”；不宣称一次内部核对覆盖所有内容或无恶意。它也不证明映像没有挂载、未被使用或可移除；连接、占用观察继续独立并保留未知。

ZIP 与 DMG 的只读文件准备提取为共用内部 FileProbe，保留既有打开后身份/元数据/路径与本机检查，extension 由各固定入口指定而非 IPC 自选。数据结果 v1 绑定 revision/root/path/checkedAt/fileStamp、passed/unknown 与互斥原因，始终不可执行；前端严格复核。fileStamp 沿用 witness 编码摘要，只表示当前独立观察的身份/元数据关联，不代表绑定扫描时的旧大小或其他检查，也不是载荷哈希。前后复查变化则撤回，最终检查后仍可能改变。

与扫描/ZIP/占用/连接共用实际 worker 单并发和安装租约、首次说明/引擎/退出门槛及保护设置复查；12 秒 IPC/14 秒前端等待不假装底层读取停止。重试开始撤回旧 DMG 结论，失败保留本次未确认，重扫/换范围清空，取消选择保留，离页忽略迟到。只保留会话状态，不增加权限请求、配置/数据库/处理历史，也不改原扫描逻辑大小。其他格式、兼容性/资源验收、完整保护及执行仍待完成。
