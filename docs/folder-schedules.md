# 目录定期扫描

2026-10-30：持续管理可添加目录，选择十五分钟、一小时、六小时或每天的周期，明确保存并启用；新任务默认暂停，也可以先单次“立即扫描”。每个任务提供暂停/启用、编辑范围、移除、取消当前扫描、历史和“查看并整理”。移除配置保留扫描历史，不修改目录文件。

调度随 App 运行，每三十秒检查一次到期，一次扫描一个目录，其他任务或文件检查槽位占用时延后。休眠后只按当前状态判断一次到期，不回填所有错过的周期。退出后停止，下次启动读取保存的配置；菜单栏保留运行须由用户另行开启。没有安装登录启动项、系统调度服务或常驻 helper。

保存范围只授权观察元数据。通过当前目录进入文件整理时，仅传递目录，不复用历史文件选择或计划；用户仍须重新扫描、预览、选择和单独确认，之后使用已有真实移动、归档或废纸篓流程。[定期文件处理](scheduled-files.md)已有独立规则与明确授权流程；本扫描入口不会自动转换权限或执行文件处理。

## 范围与结果

最多八个明确保存的普通目录，本账户拥有、物理路径、本地已落地，绑定根目录及祖先的设备/inode、所有者、组和模式。沿用个人文件扫描器的系统/应用/资料库/隐藏/链接/硬链接/云占位/其他设备与用户保护排除规则；根目录包含受保护子项时允许扫描其他部分，受保护内容仍排除。更改用户保护会重建比较基线，不把因此少见的文件报为消失。

目录不在原位置、磁盘移除或身份改变时记录失败，不跟随链接或自动绑定同名新目录。暂停与移除不要求原目录仍可访问；同路径身份改变后启用会拒绝，需移除旧任务、重新选择并添加。显式编辑到另一个目录会清空原比较基线。

每次扫描仍受十秒、一万条目录项、两千个文件、十二层与七 MiB 扫描快照预算约束。报告所见文件数、逻辑大小、跳过数量和完整/部分状态；不代表目录所有内容、实际占用、可释放空间或“可安全清理”。扫描不是文件系统原子快照，也不能保证所有底层文件系统调用在预算时间内返回。

完整扫描按路径比较设备/inode、大小、精确修改时间及属性变更时间，给出新增、属性变化与“未再见”。不读取文件内容，不以属性相同证明字节相同；“未再见”可来自移动、排除或范围变化，不能推断已经删除。首次完整结果仅建立基线；不完整或取消时不推断缺失，也不替换上一份完整基线。每份记录最多列出一百条路径线索，数量汇总包括其余结果。

## 所有权、持久化与取消

专用 `folderscan` 任务使用真实注册表、共享文件检查槽位与更新租约，和其他修改/扫描任务互斥。确认尚未完成的任务不会因界面重载自动再提交。后台 worker 持有所有权直到收集与持久结果结束；退出沿用现有取消与有限等待流程。

独立可选 `folder_schedules` 与 `folder_scan_runs` 表保存范围、周期、代际、绑定、每目录上次尝试、最近完整基线及最近六十四条扫描记录，沿用 SQLite FULL 同步连接，不改写执行收据或 v8 版本。观察历史按声明的容量淘汰旧终态记录；每目录上次尝试独立保存，历史淘汰不会导致长周期任务提前再次扫描。比较基线只保留每目录最近完整的一份，最长八 MiB；配置与单条历史也有读取/写入上限。未知版本或损坏数据保留，不覆盖为默认设置。

写入未结束记录和尝试时间之后才开始遍历。修改配置、暂停或移除会取消对应在途任务；完成时再次核对配置代际、首次使用确认和用户保护，旧结果不保存为新范围的观察，也不更新基线。取消只停止观察，文件保持原样；部分结果可保留在历史中。

重开将未结束记录对账为中断，保留之前完整基线，不重放这次尝试；之后继续按已保存周期判断是否到期，手动扫描仍需用户点击。结果读取先观察旧记录与当前执行所有者，再对账确切记录，避免把刚开始的新任务误标中断。独立任务/基线/历史尚未加入旧便携执行归档，日志导出和更多管理能力继续待补。
