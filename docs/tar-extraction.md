# TAR 与 TAR.GZ/TGZ 解压

2026-11-02：文件整理工具栏改为“解压压缩包…”，在已有 ZIP 解压流程中增加 `.tar`、`.tar.gz` 和 `.tgz`。明确选择原包、已有目标目录与新名称，完整检查后展示实际格式、两端位置、文件/目录/隐藏项目、数据量与名称样本，默认不勾选；单独确认后才实际解压。更改范围撤销旧确认，支持两个阶段停止、结果、持久历史、未知人工核查及已有运行请求接回。原 ZIP 记录和既有调用保持兼容，不依赖原文件整理扫描。

格式处理独立，后续写入共用[ZIP 解压](zip-extraction.md)的确切来源/保护验证、匿名快照、单次两分钟确认、持久 FULL 发布意图、逐层 FD/no-follow、排他新建、完整读回和 `RENAME_EXCL` 发布。原包与包外文件保留，不覆盖或合并，不自动打开/执行。输出仍为私有 0600/0700，复制原包隔离属性并读回；不恢复执行位、原权限、时间、所有者、ACL、文件标记或 PAX 嵌入元数据。已有 AppleDouble 普通文件保留为独立文件，原始元数据仍在原包中，不称为完整备份恢复。

TAR 数据读取覆盖 USTAR、GNU 长名称，以及 POSIX PAX 的本地路径/大小；核对每个头校验和、UTF-8 名称、内容位置/大小及全部文件 SHA-256。允许规范的前导 `./` 与根目录标记，但规范化后重复、大小写冲突、文件/目录冲突、绝对/越界/歧义路径均拒绝。链接、设备/FIFO、稀疏布局、未知类型/布局扩展、悬空扩展、缺少结束块和非零尾随数据整份拒绝。元数据专用扩展只识别后忽略，不将其应用到输出；全局扩展不能改变文件路径/大小。

TAR.GZ/TGZ 先用固定版本 flate2 的单成员流读取器完整验证 Gzip CRC/长度并生成匿名 TAR 快照；多成员和尾随数据拒绝，避免只读取第一成员却声称完整解压。不会执行压缩包中的程序或调用系统解压命令来解释路径。现有锁文件已包含 flate2 1.1.10，本节点仅新增直接引用，没有变更第三方包版本。

原包最多 2 GiB；内容最多 8 GiB、10000 个文件和目录、64 层、4 MiB 显式名称。TAR 扩展单项最多 64 KiB、累计 16 MiB，总头数和解码流另有上限；Gzip 解码流最多为正文上限加 32 MiB 头/填充余量。持续检查取消和既有十五分钟循环预算，写入临时快照时复核可用空间，保留 64 MiB 余量。准备期间可暂占较大的匿名副本，失败/撤销/消费/到期自动关闭回收，不在 home、下载或文稿目录创建样例或长期副本。
