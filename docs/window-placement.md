# 窗口尺寸与位置恢复

2026-10-23，阶段 114。主窗口在正常退出时记住最近一次普通窗口尺寸和位置，重新打开时尽量沿用；不增加设置项或额外工具栏按钮。

## 用户行为

- 尺寸使用逻辑像素保存，位置使用系统物理坐标并保留当时缩放比例。启动按当前显示器工作区调整边界，菜单栏和 Dock 所占空间沿用系统报告，不从屏幕总分辨率猜测。
- 原窗口与当前屏幕重叠时选择重叠最多的可用工作区；原屏幕消失时优先主屏幕。尺寸受原有 960 × 680 最小布局约束，过大的窗口按当前工作区收小，位置调整到工作区内。不扩大为已完成真实混合 DPI、显示器热插拔或全部系统版本验收。
- 不恢复最小化、隐藏、最大化或全屏状态；这些状态不覆盖最近普通窗口几何。启动仍显示普通窗口，不恢复上次检查页面、滚动、选择或运行任务。
- 主窗口在后端取得数据目录占用权、尝试几何恢复后显示。重复实例或数据启动失败仍显示原有错误窗口及原生说明，不取得正常 AppState，也不保存窗口偏好。

## 存储和退出边界

窗口移动和调整尺寸时仅更新内存，退出才尝试写入 SQLite 独立 `window_preferences` 单行；不按拖动帧写盘，不写旧 settings JSON 或改变 user_version，不调用历史回收。保存采用事务，未知更新版本保留，已知版本的坏记录可在下次正常保存时替换。正文最多 1 KiB，尺寸、缩放、格式、缺字段和未知字段均校验；加载失败回到默认窗口，不阻止本机任务使用。

⌘Q、关闭最后窗口和 Cocoa 直接退出共用原退出流程。先启动既有任务退出期限，再尽力保存偏好；不等待应用数据库互斥锁，保存临时使用零 SQLite busy timeout 并恢复旧值。互斥锁仍被占用时可在最终 Exit 再尝试一次；已经尝试写入后不重复保存，不增加新的任务等待期限。失败只保留此前偏好和本机诊断，不阻止退出、不报告保存成功。

窗口位置属于便利偏好，不是任务持久化保证。强杀、数据库忙碌、存储失败或无法取得普通窗口时可能保持上一次记录；系统 I/O 挂起仍需实机故障验证，零 busy timeout 只保证不等待 SQLite 写锁，不保证任意磁盘系统调用都能立即返回。显示器工作区无法容纳最小布局时使用原默认窗口，不强行缩小到不可用布局。

偏好保存沿用安装准入锁：正在打开更新安装包时跳过这次保存，避免越过已经完成的数据保存检查；普通保存期间也不会允许安装准备同时开始。

## 验证范围

隔离测试覆盖普通窗口/异常尺寸与缩放、十轮 Retina 保存恢复不增长、工作区边界/原屏幕消失/负坐标/混合比例、无可容纳工作区、SQLite 重开与设置/任务不变、坏记录/超限/未来版本保留、只读/写锁/注入保存失败和 busy timeout 恢复。

原生证据和最终构建路径见 [开发记录](development.md)。真实多屏幕重连、缩放切换、低分辨率、Spaces、全屏/最大化切换以及系统/架构矩阵继续按 [发布路线图](release-roadmap.md) 验收。

实现使用当前锁定 Tauri 的窗口、显示器工作区和逻辑尺寸 API。设计参考官方 [窗口状态说明](https://v2.tauri.app/plugin/window-state/)，当前没有引入窗口状态插件或新增前端窗口命令权限。
