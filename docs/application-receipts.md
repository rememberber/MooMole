# 安装收据的只读补查

共享关联补查固定 Mole 收据规则覆盖的非标准安装位置。收据只是候选来源；每个应用仍重新读取实际 Info.plist、验证身份与 Mole 共享保留规则。不会因为收据记载过某个路径，就认为它属于所选应用或可以删除。

## 来源与范围

适配固定修订 ba3a0f57f78e4c22818fda701219cc3dd4d6953f 的 lib/core/pkg_receipts.sh，固定 SHA-256 为 5a75ca76477880016e035e76a688371653f354a57a8668f85906351609977894；除引擎清单外再绑定此摘要，资源变化保持未知。

固定调用系统 /usr/sbin/pkgutil --volume / --pkgs-plist 与 --export-plist ID，不经过 Shell、不解析终端错误文案或换行文件清单。使用 Foundation 解析 plist，要求列表为唯一、有界、可表示且不会成为选项的包 ID；导出结果的 pkgid 必须与请求一致、volume 必须为 /、paths 必须为字典。install-location 不另行拼接：导出的 paths 键与原 --files 路径语义对应，防止重复拼接安装前缀。

沿用 Mole 大小写敏感的 com.apple. 收据排除，以及 /usr/local/、/opt/ 范围和大小写不敏感 .app 后缀。保留原 case 分支顺序：整条路径以 .app 结尾时先作为候选，否则取第一个 .app/ 前缀。相对/单个根斜杠按原语义处理，不把 ../ 或异常分隔符规范化成新位置；控制字符、过长或不支持路径保持不完整。嵌套 App 候选继续由原应用检查器拒绝，不建立辅助包的独立卸载资格。

收据中记录但已不存在、不可读取或布局不支持的 App，经原候选检查器产生 partial，不以旧收据证明安装仍存在。标准 Applications、任意用户目录、其他卷和完整收据归属分析不在这份补查范围内。

## 边界与变化

- 系统包列表最多 512 项，最多尝试 64 份非 Apple 收据，最多处理 32,768 个路径键、补充 128 个不同候选。超限保持 partial。
- 每个子进程 stdout/stderr 各最多 2MiB；枚举按检查点使用 1.5 秒预算，每次命令最多 750ms，返回前列表重查最多 500ms、复核检查点最多 1 秒。命令失败、输出超限或超时均保持未完整读取，不解析错误文案推断原因；实际进程清理可能超过命令预算。元数据 I/O 也可能阻塞，检查点不是内核调用硬中断。
- 使用已有进程组所有权、输出上限、终止/回收与管道期限。停止后主进程已退出且输出已关闭时可提前完成宽限等待，最后组信号仍在回收主进程前发送，避免复用 PGID 风险。
- /private/var/db/receipts 为固定后端路径；要求本地、规范且非链接的目录。每份收据在导出前保存 .plist 和 .bom 的普通单链接文件元数据，通过目录相对 fstatat/openat 与 O_NOFOLLOW/O_NONBLOCK 验证；不直接读取 BOM 内容、不修改数据库。
- 返回前重新读取包列表，并核对收据目录与已接触文件的设备/inode、mode、uid/gid、flags、大小、mtime/ctime。新包、卸载、重装、替换、链接和读取失败不提升为完整；变化保持 changed。目录变化可由其他收据写入触发，保守要求重查。

不读取或写入 Mole 的磁盘收据缓存，不以 TTL 证明不存在，也不添加应用任务历史。整体继续占用原两个实际检查工作器之一；五秒停止等待后，尚未完成的真实工作继续持有名额直至结束，不能据超时认为子进程已结束。

## 界面与协议

沿用原「共享关联」折叠区域：先显示数据保留与不完整结论，展开后显示本次尝试的非 Apple 收据数及未完整读取、变化、预算或不支持原因。没有新增页面、卸载/退出/文件修改按钮。

应用检查协议 v19、installations version=5/source=moleListRegistryRootsVolumesAndReceipts。receipts 包含 code（observed/partial/notChecked）、issue、packageCount、checkedCount、entries、candidates；checkedCount 表示尝试核对的数量，partial 时不承诺这些收据全部成功。未知所选身份或固定资源时 notChecked、计数全零；收据 partial 要求整体 partial，receiptsIncomplete 仅在没有其他整体原因时使用。前端拒绝容量、状态或计数关系矛盾。

Mole 64、登记 32、常用目录 128、本地卷 128、收据 128 合计最多 480 个输入候选；路径/目录身份去重后最多持有和展示 32 个共享命中。observed 只表示本次支持范围未发现已知中断，不代表全机器安装发现、数据独占或执行凭据。完整关联与保护、真实权限/故障矩阵和执行前验证继续按 [发布路线图](release-roadmap.md) 推进。
