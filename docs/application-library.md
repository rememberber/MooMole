# 应用清单：查看与对比

2026-10-17。固定 Mole 1.59.1 / `ba3a0f57f78e4c22818fda701219cc3dd4d6953f`；当前功能只读，勾选不是卸载选择或执行计划。

## 使用流程

读取应用后，先看名称、安装路径、来源和上游大小。按名称、Bundle ID、完整路径或来源文本搜索，也可筛选普通应用、Homebrew、待确认来源，按大小降序或名称排序。每批显示 100 项，“当前显示”只勾选这一批，继续显示不会自动选中后续项目。

勾选用于对比应用包估算。筛选时保留勾选并显示未出现在当前列表中的数量；“只看已勾选”便于集中查阅。列表刷新失败时保留旧结果和勾选，成功接收新列表或离开页面后清空勾选，不将其带入新观察。勾选、筛选与排序均不持久化，也不调用任何卸载接口。

“位置与来源”提供完整路径、Bundle ID、Mole 原始来源及未知大小标记，可请求 Finder 定位。同名或同 Bundle ID 的不同返回路径分别展示和勾选，客户端不再合并；但上游已经去掉的副本无法从清单中恢复。Finder 请求仍走现有路径校验接口。

## 上游范围与证据

依据本地固定源码 `bin/uninstall.sh`：

- `main` 的 `--list` 分支在卸载路径前短路；`uninstall_list_apps` 返回 JSON，客户端继续使用现有只读任务运行器。
- `uninstall_print_app_search_dirs`：`/Applications`、`~/Applications`、`/Library/Input Methods`、`~/Library/Input Methods`、存在的 PlayCover 目录及可读取的 `/Volumes/*/Applications`。
- `_scan_discover_apps` 还合入安装收据识别的非标准安装位置，并跳过部分应用；`_scan_dedupe_bundle_ids` 根据 Bundle ID/应用包名等规则去重。因此这里不是所有系统应用、所有安装副本或关联文件清单。
- `uninstall_list_apps` 的来源仅为 `App` 或 `Homebrew`，`App` 在界面解释为普通应用，不推断 App Store 或安装者身份。未知来源显示“来源待确认”，保留原值。
- `uninstall_normalize_size_display` 会保留 `N/A`、Steam 管理等未知标记；大小可能来自缓存或受限探测，不表示完整关联数据大小。

大小格式依据 `lib/core/base.sh:bytes_to_human`，B/KB/MB/GB 使用十进制 1000，且已经舍入。客户端只将这些明确单位换算为排序/对比估算，保留原始单项显示；未知、非有限、过大或不支持的格式不计为零，也不参与已知汇总。明确 `0B` 与未知分开。全部所选大小未知时不显示 `0 B`，汇总超出安全数值范围时说明无法汇总。

此换算仅用于展示，不决定删除对象，不作为精确字节数、唯一物理占用或可释放空间依据。真实关联数据识别、共享内容、运行状态、保护、个人数据默认保留、卸载计划与受限执行器仍待完成。原生应用图标也尚未接入。
