# 登录时打开 MooMole

2026-11-03：持续管理新增当前 MooMole 主应用的登录启动设置。进入页面只读取 macOS 的实际状态，不注册、不撤销，也不根据历史偏好重放设置。用户明确勾选后可开启或关闭；系统登录项设置需要另外点击打开。仅配置当前运行的副本，建议从固定安装位置使用，并显示该副本的路径供核对。系统允许后，后续登录按正常方式打开应用窗口，不默认隐藏窗口或处理文件。

该开关独立于菜单栏、容量采集、低空间提醒、目录扫描与定期处理；开启登录启动不会开启其他功能，关闭也不会退出当前程序或关闭已经保存的偏好。没有新增用户 LaunchAgent 文件、后台/特权 helper、管理员授权或其他应用的登录项修改。其他应用的现代登录项管理仍待实现，本节点只配置 MooMole 自己。

使用公开的 [SMAppService.mainApp](https://developer.apple.com/documentation/servicemanagement/smappservice/mainapp) 和 [register/unregister](https://developer.apple.com/documentation/servicemanagement/smappservice/register%28%29)，在后台线程调用。原生适配只接受固定枚举动作和预期的本应用标识；核对 NSBundle、`.app` 和内部主程序，不接收前端服务标签、可执行文件、路径、URL、plist 或参数。只使用 mainAppService，不使用另一个 LoginItem/Agent/Daemon 的初始化方法。

状态分别为未注册、系统允许、需要批准、系统未找到服务与读取失败。观察到一个从未注册的自建应用先返回 `notFound`，明确注册后返回 `enabled`；因此不将首次 `notFound` 直接当成注册失败或未注册事实，也不因此自动发请求。用户仍可对已确认属于当前主应用的服务明确请求注册，由系统判断是否接受。要求批准时保留等待状态，不宣称已经可以在登录时启动、不重复请求批准或自动打开系统设置。

原生调用使用串行控制、实际任务登记和自更新/退出租约。十秒停止等待不表示系统调用已经结束，实际 worker、控制锁与任务占用直到返回后才释放；界面提示先刷新，不自动再提交。停止/退出只在请求前阻止后续步骤，已经交给系统的请求不能承诺撤销。运行观察绑定本模块持有的同一实际 Job 句柄，不能由其他任务复用同一个 ID 冒充活跃；读取和意图登记的所有权快照在对账期间保持一致。

明确设置前先在 FULL 同步的 SQLite 中保存意图，然后才调用系统，结束后另存返回状态。可选表 `main_app_login_records` 只在明确设置时创建，不改变 v8 数据库版本、清理/卸载/文件恢复历史或现有设置。保留最近 50 次配置记录；淘汰仅发生在新设置事务中，未核查的未知记录先阻断，不能被容量淘汰。未来/损坏记录保留并拒绝覆盖。调用失败、身份/响应错配、完成写入丢失或重开时没有原任务句柄的运行记录均保持未知，不重发注册、撤销或改成成功。

未知需要刷新并核对系统状态，再单独记录“已核查”；原结果不变。系统状态仍无法核对时不能补造成功或清除阻断。当前 OS 状态和历史事实分开，曾经系统接受的请求不证明它现在仍有效，注册也不能证明下次登录已经实际运行。App 移动、升级、系统撤销同意或其他副本的影响需要重新核对；没有通过永久保存一个布尔偏好绕过这些观察。

实际原生验证使用唯一标识、系统 TempDir 中的 ad-hoc 签名自建 App，通过正常 App 启动调用同一生产原生适配：首次 `notFound` → 明确注册 → `enabled` → 另一个进程读回 `enabled` → 取消注册 → 新进程读回 `notRegistered`。最终核对仅此样例的启动注册已撤销，删除样例目录；未修改已安装 MooMole 或其他软件的登录项，未注销/重新登录当前账户。早期只读样例发现 `notFound` 后未发出注册，样例亦已回收。脚本为 `scripts/test-main-app-login-native.mjs`。本机接受了该 ad-hoc 样例，不扩大为所有系统、安装身份、批准状态或后续升级都已验收。

真实临时 SQLite 回归覆盖默认读取不创建表、持久意图先于注入式系统修改、相同请求拒绝、关闭/已达目标状态、事务失败/请求前停止不修改、完成丢失后未知不重放、人工核查不改变结果、50 次保留上限及未来记录不覆盖。此部分系统响应为注入值，与上述真实 ServiceManagement 往返分别记录。页面覆盖默认不改、显式确认、首次缺失服务、待批准、拒绝/错配不重试、未知核查和中英日布局；传输夹具不是实际 App 窗口证据。

精简证据收尾保存于 `.cache/verification/native-evidence.json` 的 `main-app-login-native.json`、`main-app-login-journal-native.json` 和 `main-app-login-protocol.json`。实际打包 App 控件/系统设置窗口、注销/重新登录、不同安装位置/系统、升级后权限与长期生命周期继续待验收，不能以 native 或浏览器测试替代。完整八方向、其他启动来源、AI 与免费分发目标继续保持。
