# 路径观察与并发变化边界

2026-10-16。路径观察 v2、目录摘要 v2；clean v2、rules v3、SQLite v3 保持。本层只读取元数据，接入扫描捕获、计划保存和复核，没有修改 IPC。

## 路径与句柄同时核对

旧观察逐个对绝对路径调用 `symlink_metadata`；相邻调用之间若祖先被替换，后一次调用仍可能走入另一棵目录。旧目录遍历虽然使用 `openat`，但打开根目录后不再核对它与原路径的绑定，父目录被改名后仍可能完成对旧目录的遍历。

现在 `observation::AnchoredPath` 从 `/` 开始逐级观察：

1. 在已持有的父目录下用 `fstatat(AT_SYMLINK_NOFOLLOW)` 读取名称属性；拒绝链接和特殊文件，非末级必须为目录。
2. 用相同父目录句柄 `openat`，配合 `O_NOFOLLOW`、`O_CLOEXEC`、`O_NONBLOCK`；目录使用只读目录句柄，普通文件使用 macOS `O_EVTONLY`，不读取正文。
3. 核对打开前与实际句柄的设备/inode、模式、所有者和组；目标还核对大小、链接数及 mtime/ctime（含纳秒）。普通文件须为单链接，观察时已共享的硬链接保留为无法审阅。
4. 本次观察保留全部祖先句柄。返回前再次检查每个句柄的身份/属性，以及它在父目录内的名称绑定；末级目标还核对完整元数据。名称、祖先或目标改变则返回无法确认，不能发布为未变化。

路径最多 128 个普通组件，一次最多保留 129 个句柄，离开观察即关闭；不跨任务保存句柄。无效路径、无法打开、权限拒绝、资源不足均保留失败原因，不回退到较弱的绝对路径读取。这里不是权限或占用审计，也不证明目标空闲。

## 目录遍历结束前再核对

目录摘要复用同一套路径句柄。遍历子目录仍使用相对目录句柄；每个子项在观察/递归后，再核对它在父目录里的名称及属性。遍历完成后，重新验证所选根目录的全部祖先绑定与根目录元数据。持有一个已脱离原路径的旧目录句柄，不再足以返回成功。

既有 10000 节点、64 层、5 秒预算及子项禁止链接/特殊文件/跨卷等约束保持。预算在系统调用之间检查，无法中断已挂起的内核调用；这不是网络卷支持承诺。

## 旧记录

路径观察新增 `version=2` 和目标 `links`；缺字段按旧版本读取，显示需要重新扫描，不能保存新计划或进行有效规则复查。目录摘要标记 v2，不能复用 v1 摘要作为当前证据。历史仍可查看，不改写或补造旧观察；无需数据库迁移，执行记录的历史计划副本也仍可读取。

## 已验证与仍未解决

新增 7 组 Rust 测试全部使用自己创建的临时目录，覆盖打开前的源文件换名/换链接、已打开祖先被替换、打开后的源/父目录变化、文件修改/新增硬链接、目录根与祖先脱离、遍历中的子目录换链接/叶项修改，以及旧 JSON 兼容与重扫要求。测试包含中文、换行及 glob 字符。

其中一组刻意证明剩余限制：深层文件已经被观察完后才修改其正文，不改变任何父目录属性，本轮摘要仍可能等于旧摘要；下一轮遍历才能检测变化。元数据摘要不是原子文件系统快照，也不是正文校验。对每个名称依次检查，同样不能证明检查之间没有发生并恢复的替换，或检查完成后目标没有改变。

因此这些改动改善的是只读复核的检测边界，**没有解决实际按名称移动时的源 inode 绑定问题**。原按项执行实验继续复现最后检查之后替代文件被移走的风险，见 [执行实验](restricted-execution.md)。没有将这些句柄交给真实移动器，没有开放删除、恢复或系统维护。

后续仍需确定可支持的并发策略、完整模块条件及进程/锁语义，并验证取消、强杀、卷和权限矩阵；无法满足策略的范围不开放执行。免费 DMG、ad-hoc 签名和用户手动升级的发行方式保持。
