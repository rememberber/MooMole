# 使用 MooMole

当前是尚未完成首发验收的开发版本。以下说明对应已实现的桌面流程，不表示所有清理、卸载或维护能力均已开放。浏览器预览只展示示例，真实检查需启动桌面 App。

## 先查看结果

从固定安装位置启动，在“概览”核对 Mole CLI 版本和引擎状态。引擎未就绪时先查看具体原因，不能把示例或旧结果当作当前检查。

想了解磁盘占用，进入“空间分析”选择目录并开始分析；可在图表与列表间查阅、下钻，点击路径返回祖先目录。想了解运行状态，进入“系统状态”获取快照，按需开始或暂停持续采集。显示的占用不是可安全清理量；未知、无法读取和不完整都需保留其原意。

## 清理日志

1. 进入“清理”，点击“扫描清理预览”。核对用途和路径，只勾选确实不再需要的候选；需要保留的目录先加入保护。
2. 保存所选审阅范围，打开计划，点击“复查 Mole 规则”。扫描、保存计划和复查都不会删除文件。
3. 若出现“查看授权后移入范围”或对应移入范围入口，打开并核对列出的确切日志、保留数量和影响；其他缓存、目录或未知项不因此获得执行资格。
4. 勾选影响确认后，点击“授权检查并移入废纸篓”或“移入废纸篓”。需要系统授权时，由本人在 macOS 窗口确认；App 不收集密码。该授权用于只读占用检查，文件由当前账户处理。
5. 查看逐项结果。需要停止时用“停止后续项目”，等待当前项的实际结果；已处理的文件不会因取消自动取回。

没有可执行入口时先看逐项保留原因，不通过关闭保护或反复提交绕过未知。确认过期就返回重新复查，旧范围不会自动执行。

## 卸载普通 App

1. 进入“应用列表”，点击“读取应用”或“刷新列表”，找到目标 App。列表勾选用于对比，不表示批量卸载。
2. 使用目标的独立卸载入口，核对实际 App 路径及范围。正在运行时先自行退出，再“重新检查”；受保护、受管理、带专用服务、未知或变化时保留。
3. 确认它属于所支持的普通 App，并勾选范围确认，再点击“移入废纸篓”。本次只处理 App 包，包外设置、缓存和个人数据保留。
4. 查看实际结果。可“取消卸载”，但已进入系统处理的操作仍须收集结果；关闭结果窗口后可从状态提示或“操作历史”返回。

通过其他管理工具安装或需要官方卸载器的 App，使用对应卸载方式。没有发现限制不证明排除了所有后台服务，也不意味着已经清除全部残留。

## 刷新预览

预览异常时，进入“系统维护”，点击顶部“刷新预览…”。选择缩略图缓存和/或生成器列表步骤，点击“检查所选步骤”，阅读影响并勾选确认，最后点击“开始刷新”。

这会实际请求 Quick Look 刷新，可能影响正在进行的预览，系统随后重建缓存，首次显示可能较慢。无需管理员权限；不删除 Finder 缓存目录、不修改偏好或重启 Finder。没有原缓存备份或一键撤销，也不保证修复预览或提升性能。

查看各步骤结果，需要时点击“取消后续步骤”。已经启动的刷新不能撤销；“系统命令已完成”只表示命令正常返回，不代表系统所有后续工作结束。

## 核对结果与取回

| 看到的状态 | 下一步 |
| --- | --- |
| 已移入废纸篓 | 从结果或历史核对当时收据，在 Finder 查找实际对象；移入不等于立即释放空间 |
| 保留、跳过或未开始 | 查看具体原因；修正条件后重新检查，不用旧确认继续 |
| 正在停止或读取状态失败 | 等待并从“操作历史”刷新；请求取消或读取失败不证明操作未发生 |
| 中断、结果待核实 | 先核对原位置、废纸篓或预览的实际情况；完成后在确切记录中明确保存核查，不自动重试 |
| 已人工核查 | 原未知结果仍保留；新的操作需要重新检查和确认 |

需要取回文件或 App 时，优先使用 Finder“放回原处”；没有该项时核对原目录后手动移回。**原位置已有同名对象时取消，不覆盖。** 当前没有应用内自动恢复；收据描述当时的位置，对象被移动或替换后不能再作为当前位置的证明。

容量不足时，在“操作历史 → 归档…”查看范围，完整保存已结束且必要核查完成的记录。归档后仍可在该入口只读查阅、导出或打开归档文件；不从归档再次执行。请自行保管导出文件，其中可能包含路径、计划及收据；它不会自动上传，也仍占磁盘空间。

## 安装与更新

当前没有已经完成完整验收的正式发行版。后续正式下载以本项目 GitHub Releases 的架构匹配 DMG 为准，核对说明与校验值后安装到固定位置。ad-hoc 签名不等于 Apple 开发者认证或公证；首次打开按系统实际提示处理，不关闭安全检查或移除安全属性。

更新入口在“设置 → 关于”。下载通过大小和 SHA-512 校验后才显示打开 DMG 的入口；完成活动任务并正常退出，再按 Finder 提示手动替换。打开 DMG 不代表安装已经完成。具体系统边界见 [安装升级方案](distribution.md)。

记录留在本机，可能包含路径和检查结果，不保存文件正文或密码，不自动上传。更多说明见 [本地记录保留](local-data-retention.md)。

MooMole 是独立的非官方学习研究项目。使用前理解影响并备份重要数据；感谢 [Mole CLI](https://github.com/tw93/Mole) 原作者及贡献者，日常使用建议选择 [Mole 官方产品](https://mole.fit/zh/)。
