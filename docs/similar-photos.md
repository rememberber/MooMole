# 相似照片第一版

2026-10-30：独立“相似照片”入口支持选择普通目录，使用本机视觉特征寻找候选，缩略图并排比较、显示像素与大小、打开完整预览，手动选择后移入真实 macOS 废纸篓。默认不选，每组至少保留一张。

相似不等于相同，不表示不同表情、细节或独有内容可以互相替代。重复文件仍使用完整内容摘要匹配；本模块独立为 `similarPhotos`，不会把视觉距离当作内容相同或删除许可。

## 候选与范围

ImageIO 先按方向信息生成有界图像；Vision 的固定第二版 feature print 在本机比较。使用保守距离阈值 0.15；每组成员都须接近同一参考图，不通过任意长的传递链合并，不提供“相似百分比”或自动挑选最佳照片。参见 [Apple 图像相似度示例](https://developer.apple.com/documentation/vision/analyzing-image-similarity-with-feature-print) 和 [第二版请求](https://developer.apple.com/documentation/vision/vngenerateimagefeatureprintrequestrevision2)。

支持普通目录中的 JPEG、PNG、HEIC/HEIF、WebP、TIFF、BMP 静态图片。每张最多 32 MiB、八千万像素；本轮最多二百张，输入读取预算 512 MiB、特征/比较预算两分钟，缩略内容有独立容量上限。达到限制、取消、文件变化或解码失败时保留未完成状态，不将未发现结果表述为没有相似照片。照片图库、RAW、多帧、连拍关系与视频尚未覆盖。

## 选择与真实处理

仅接受当前保留扫描的确切项目 ID；确认展示所选照片与保留原件。结构化计划保存所选各自的内容摘要及本组保留照片的身份/摘要。视觉上相似的照片可以有不同内容与大小，执行前分别核验，不要求它们的摘要相同。

沿用个人文件的路径保护、Mole 路径级规则、权限检查、短期单次确认、逐项 FULL 同步意图、原生废纸篓、取消、未知结果与重启核查。所选照片或保留原件变化则保留本项，未知不重试，不清空废纸篓。结果、来源与实际收据进入共享历史及归档；原始个人文件/重复计划增加的可选字段为空时保持原编码。

## 基本证据与后续

- 自建不同字节/分辨率的图片经真实 Vision 分组，不同画面的棋盘格被排除；整组不能全部选择，保留原件被修改时拒绝处理。
- 显式原生样例通过真实 Vision、正式 Mole 规则及原生废纸篓执行，记录一项实际 moved，保留照片内容未变，实际收据与归档读回核对。样例按确切收据取回后全部清理，该取回不算产品应用内恢复验收。
- 浏览器验证独立入口、并排布局、默认不选、保留一张、完整预览、确切 ID、另行确认和结果；并回归个人文件、重复文件及语言。默认 Rust 回归 587 项通过，最后相关原生测试再次通过；前端单元测试与 arm64 App 构建/签名、嵌套程序和 ZIP 校验通过。

新入口打包 App 的实际窗口验收、更丰富真实照片集、阈值选择、RAW/连拍/视频、照片图库集成和完整故障矩阵继续待补。先转向附件与离线内容等尚缺的大功能，不以此节点代表重复/相似文件全部完成。
