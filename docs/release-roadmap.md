# 从当前原型到 1.0 正式发布的完整待办

更新时间：2026-10-17。文档基线：`6a8bae2`，当前开发分支 `dev`；新增进度见 [开发记录](development.md)。

产品宗旨：**对 Mole CLI 进行客户端可视化，并在其基础上提供更多人性化功能。**

体验宗旨：**简单直观。** 先展示结果、影响和下一步，技术细节按需展开，关键保护、未知与不可执行状态保持可见。

发行约束：用户没有付费 Apple 开发者签名能力。默认参考 MooTool Electron 的 DMG 下载、大小/SHA-512 校验和用户手动替换方案；采用 Tauri 对应的 ad-hoc 签名，不将 Developer ID 或公证作为正式发布前置条件。具体方案见 [distribution.md](distribution.md)。

本清单描述后续工作，不表示已实现、已获授权或已完成公开发布。`[x]` 为已有且有验证记录的基础；`[ ]` 为剩余工作。已有基础的覆盖范围以 [development.md](development.md) 为准。

## 里程碑与完成标准

| 阶段 | 主要范围 | 完成标准 |
| --- | --- | --- |
| 当前只读原型 | 基础界面、部分 CLI 连接、设置和任务记录 | 已完成当前记录的验证，不代表完整版 |
| 核心 Alpha | 结构化协议、统一保护、清理审阅及受控执行 | 确认范围与执行一致，取消及部分失败可解释 |
| 功能完整 Beta | 卸载、维护、工程产物、安装包、分析、状态和历史 | 冻结范围内各模块均走通实际用户流程 |
| 发布候选 RC | 兼容性、性能、安全、迁移、安装和升级 | 无发布阻断问题，免费发行 DMG、系统确认和手动升级实测通过 |
| 1.0 正式发布 | 可验证产物、源码及用户文档 | 干净机器安装/升级通过，发布材料完整并有维护入口 |

依赖主线：**范围与协议 → 计划/保护/权限 → 清理闭环 → 其他 CLI 模块 → 跨模块回归与 Beta → 免费分发/更新/RC → 正式发布**。公开名称、免费发行验证、CI 和文档可以与功能开发并行。

## 需要在后续明确的外部条件

这些是发布需要明确的实际条件，不需要用户购买 Apple 开发者账户，也不需要现在提供密码或私钥：

- 公开名称、图标、Bundle ID 与上游品牌边界。
- 首发架构、系统范围及可用的 Intel/旧系统测试设备。
- GitHub Releases 与更新清单的托管位置，以及发布流水线最小权限配置。
- 如启用自有更新签名，其免费生成密钥的保管者、备份和验证方案。
- 下载/反馈/隐私说明地址，以及 Beta 测试范围和维护负责人。
