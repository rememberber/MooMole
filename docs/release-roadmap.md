## 首个可用版本的硬门槛（2026-10-23 用户确认）

**首个对外可用版本必须包含真正的清理、应用卸载和系统维护执行。** 不将只读测试版作为该目标的替代，也不将模拟成功、仅测试编译的 writer、无须变更或全部跳过计为功能交付。三个模块分别在已声明支持范围内完成实际 App 的确认、执行、结果与取消/中断/恢复边界验收后，才进入首发发布关口。完整关口、当前缺口和开发顺序见 [首发执行验收](first-release-execution.md)。

- [ ] 清理：来源明确、具有实际用途的首批对象，走通真实规则、权限/占用检查、明确选择、处理及结果/恢复；现有限定日志循环的 fixture 不替代发布 App 验收。
- [ ] 卸载：首批受支持普通应用真正移入废纸篓，关联数据按精确归属和用户选择处理，个人数据默认保留；运行/共享/保护/未知条件不能由清单或位置线索充当通过。
- [ ] 维护：固定白名单任务真正执行，验收实际结果、影响、按次授权（需要时）、取消/中断以及任务特有的恢复或重建边界；现有只读审阅和实验不代替该流程。
- [ ] 三条流程分别通过受控原生 App、权限/失败及退出重启回归后，再完成免费 DMG 下载、安装、升级、发布材料与正式产物校验。

本机已通过真实 DMG → `~/Applications` 安装、正常退出后 Finder 明确替换、实际新构建启动/十表数据保持，以及映像推出后的内嵌引擎快照。该证据限同版本不同构建；跨版本/迁移、公开下载隔离属性、干净机器 Gatekeeper 与特权/TCC 仍待完成，见 [安装实测](distribution.md#本机固定位置安装与替换实测2026-10-25阶段-150)。

## 当前推进顺序（2026-10-23 更新）

用户确认将主线从应用关联目录的长尾规则扩展，切回可完成的用户操作。应用清单与只读详情阶段性收口；除影响正确性、安全或现有体验的修复外，暂停新增厂商/产品特例及系统共享位置。完整卸载仍在 1.0 范围内，但不作为其他模块开工的前置条件，也不要求先穷尽所有软件规则。

1. **解开清理的真实执行阻塞**：核对完整占用视图与无付费证书的受限按次授权路线，先验证固定只读检查的最小权限、调用方/对象绑定和失败行为；不删除完整视图要求、不让整个 App 以 root 运行、不开放通用 Shell。然后让已有日志循环通过发布 App 的真实规则及权限/故障验收，明确首批日常可用的日志/缓存支持范围，目录与其他类型须另行完成规则/执行验收。
2. **首批普通应用卸载闭环**：从明确应用身份及完整 App 包开始，接入不可混用的卸载计划、运行/保护复核、确认、原生处理、逐项结果及恢复。关联数据的归属与保留单独审阅；证据不足继续保留，暂停新增厂商特例不等于推迟整个卸载执行。
3. **固定维护任务的实际执行**：按固定 Mole 的具体任务选择首批可验证范围，完成当次条件/保护、固定操作、必要的系统授权及实际结果。偏好写入须解决原值/缺失证据、持久记录和并发边界；缓存刷新等任务按其语义验收，不把偏好实验当成所有维护的前置或执行完成。
4. **跨模块与发行**：三条执行主线均达到首发门槛，再做受支持环境的权限/故障、安装升级和免费分发验收，进入 Beta/RC。共用基础修复可以穿插；新增只读指标、便利入口和厂商长尾不继续替代尚未完成的核心执行。

清理权限已接入固定只读诊断及所选日志的条件确认和普通用户执行：每批一次 root 只读观察，逐项新鲜 Mole 规则，意图前及最终 API 前核对原始观察；unknown 不伪装成通过。实际 ad-hoc App 经本人操作定位并修复 f 字段及 Darwin Fileport 兼容性缺口，两份自建日志已通过真实授权/规则、移入/收据、Finder 取回和重启核对。接下来完成拒绝、取消/退出及故障矩阵，详见 [授权与执行交接](cleanup-authorization-probe.md)。代码、浏览器和 fixture 不替代实际 App 验收，单次正常流程也不代表完整清理模块已交付。

普通应用卸载已有正常移入/取回；实际 App 进一步验证连续两批分别在意图前及意图后 API 前取消，以及执行界面触发退出后的真实 moved 保留。重启后执行/设置共 10 张表摘要保持，无自动重放；其他取消时点、退出超时/强杀、权限和冲突矩阵仍待完成，见 [卸载实机证据](app-uninstall-interface.md#实际取消与退出2026-10-24-至-25阶段-143)。

状态持续采集、维护条件/原值观察、工程产物和安装包只读流程已有阶段性证据；这些保留为已实现基础。后续开发回到上述三条执行主线，不以继续堆叠只读功能或实验数量替代用户可完成的真实操作。工程产物/安装包的完整处理仍在 1.0 路线图中，不能借首发排序默认为已完成或删除其待办。

维护补充：固定安装位置的实际 App 已分别通过提交后 ⌘Q 和关闭最后窗口的意图前取消；两次重启十表保持、历史取消详情不重放。没有启动系统命令，不代替命令启动后的取消/中断、未知核查或缓存重建验收，见 [维护实机记录](maintenance-execution.md#已安装-app-的两个退出入口2026-10-25阶段-151)。

## 里程碑与完成标准

| 阶段 | 主要范围 | 完成标准 |
| --- | --- | --- |
| 当前开发原型 | 基础界面、部分 CLI 连接、设置和任务记录 | 已完成当前记录的验证，不代表完整版 |
| 核心 Alpha | 结构化协议、统一保护、清理审阅及受控执行 | 确认范围与执行一致，取消及部分失败可解释 |
| 功能完整 Beta | 卸载、维护、工程产物、安装包、分析、状态和历史 | 冻结范围内各模块均走通实际用户流程 |
| 发布候选 RC | 兼容性、性能、安全、迁移、安装和升级 | 无发布阻断问题，免费发行 DMG、系统确认和手动升级实测通过 |
| 1.0 正式发布 | 可验证产物、源码及用户文档 | 干净机器安装/升级通过，发布材料完整并有维护入口 |

依赖主线：**范围与协议 → 计划/保护/权限 → 清理闭环 → 其他 CLI 模块 → 跨模块回归与 Beta → 免费分发/更新/RC → 正式发布**。公开名称、免费发行验证、CI 和文档可以与功能开发并行。
