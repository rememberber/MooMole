# 按问题维护第一版

2026-10-30 原生窗口补验：已在独立优化 App 从问题入口、系统目录选择器和明确确认，真实提交自建目录的 Spotlight 索引并保留任务历史；原文件未变化。见 [本轮原生验收](consumer-native-acceptance.md)。只验证索引命令完成，搜索可见性及其他修复入口继续待补。

2026-10-30：维护页展示“文件预览不显示”“文件搜索不到”和“应用图标或打开方式异常”的操作入口，原有维护目录及两项设置观察继续保留。问题入口指向可真实执行的操作，不因展示入口就把其余维护任务标为可执行。

预览入口使用既有 Quick Look 两步刷新、独立确认、保护、逐项执行与持久记录。

搜索入口允许选择当前用户个人目录内的本地文件夹，准备两分钟有效的一次性确认。执行前重新核对目录身份、保护范围、普通账户和只读系统卷上的固定工具；账户根目录、资源库、隐藏路径、应用包及与保护目录重叠的范围拒绝执行。外接盘和其他账户目录尚未支持。

执行仅使用系统 `/usr/bin/mdimport -i`，递归提交所选目录，更新 Spotlight 索引；不使用 shell、不清空整卷索引、不重置隐私排除、不删除原文件、不请求管理员授权。系统自带工具的选项已按本机帮助核对；导入器机制参考 [Apple Spotlight 文档](https://developer.apple.com/library/archive/documentation/Carbon/Conceptual/MDImporters/Concepts/Troubleshooting.html)。

确认后先写入持久任务历史，再启动命令。沿用原有维护进程监督器，支持取消、六十秒超时与退出时收集；取消只能停止本次命令，Spotlight 已接受的后台工作可能继续。命令返回成功显示“索引命令已完成”，要求用原文件名重新搜索验证；不宣称问题已经修复。失败、失联和中断不自动重试，重启不重放；原索引没有撤销恢复功能。

基本验证：默认 Rust 回归 579 项通过，专用原生测试在自建文件夹中真实提交索引、命令返回成功且文件字节保留；前端构建及 203 项单元测试通过。新增浏览器流程覆盖选择后确认、确切目录结果、取消、重新进入和错误结果不重试，并回归既有维护/Quick Look 流程；共 27 项通过（旧文案断言更新后单独复验）。arm64 release App 已构建并通过 ad-hoc 签名、嵌套程序和 ZIP 解包校验；新入口的窗口流程未验收，不把原生工具测试当作搜索已恢复的证据。

图标/打开方式入口进入应用列表，由用户选择确切副本并单独确认，真实重新注册所选安装位置；不重置整个系统注册库，可能改变文档/URL 候选，没有自动撤销。系统接受且观察到路径只代表注册核对通过，仍须回到原问题验证。保护、取消、未知和持久历史沿用应用操作，具体实现与自建原生证据见 [应用操作](application-control.md)。

尚待深化：打包 App 新入口窗口操作、实际搜索和图标可见性检查、搜索隐私/权限的精确诊断、网络问题的真实修复；启动管理与空间预警已分别补通首条主流程，其他来源和完整生命周期待补。先继续其他大功能，再统一补更完整的故障与交互验收。

## 网络修复的当前证据与待办

本轮核对宿主为 macOS 27.2。当前固定 Mole 1.65.0 的 `flush_dns_cache` 先检查 VPN，活动或未知时跳过；管理员条件满足后执行目录缓存刷新，再读取系统受保护 plist 的确切服务标签，通过 `launchctl kill SIGHUP system/<label>` 刷新 DNS 服务。上游针对 macOS 27 已明确处理系统拒绝此信号的情况；不能改用按进程名强杀来绕过，也不能将仅第一步完成显示为完整 DNS 修复。具体见固定引擎 `lib/optimize/tasks.sh` 的实现。

尚未在本机触发管理员授权或执行这组网络修改，不能把上游注释当成本机已验证的成功或失败。网络检查、确认、逐项执行与验证仍待实现；须保留 VPN 活动/未知、授权拒绝、目录缓存部分完成和系统拒绝状态。免费分发路线不能默认依赖稳定 Developer ID helper；[Apple 的旧提权 API](https://developer.apple.com/documentation/security/authorizationexecutewithprivileges)已弃用且建议限制用途，本轮未据此加入通用提权入口。[SMAppService](https://developer.apple.com/documentation/servicemanagement/smappservice)等路线仍需在实际免费分发身份下验证，不能先承诺可用。先推进其他缺失主流程，不把此证据记录勾选为网络功能完成。
