# 界面按功能加载

2026-10-22。概览、侧栏、顶部操作和任务状态保持直接加载；应用清单、空间结果、清理审阅、维护、工程产物、安装包、历史、状态图表及设置/审阅弹窗的视图改为首次使用时加载本地模块。引擎、数据校验、权限和任务发起条件沿用原逻辑，不改变页面功能范围。

`DeferredView` 只负责界面组件的加载、等待和错误隔离。等待时在对应位置显示简短状态，失败时可重试；设置/审阅弹窗在等待时可取消、失败后可关闭，其他导航和 App 层任务/会话状态保持可用。React 会缓存已拒绝的 lazy Promise，因此重试创建新实例；成功的组件代码保留在本次 WebView 会话，返回页面可直接使用，不重复请求或先显示等待。代码缓存不等于缓存扫描、权限或可执行结论。

重试不刷新 WebView、不重新启动检查/执行或更新下载；原子进程/worker、安装租约和后台观察仍由已有协议管理。实际模块文件丢失、损坏或浏览器保留失败记录时再次尝试仍可能失败，不能把界面恢复当作底层任务重启或安装修复。失败不会展示原始异常/本地堆栈路径。

全部模块仍随 App 打包，不从远端下载界面，不改变 CSP、权限、IPC 或自动更新协议。最终 arm64 App 已在 Tauri 自定义协议下验证概览、设置/审阅弹窗、安装包/工程/维护/历史导航，以及空间分析返回/前进的筛选状态恢复与路径跳转；详细实测及未覆盖故障见 [开发记录](development.md)。加载体积降低不能代替真实启动耗时、WebView 内存、功耗或长期性能验收。

最终构建（十进制 KB）：主入口由约 522.87 KB 降至约 329.88 KB；HTML 还预载约 7.91 KB 的 React 共享模块，初始 JavaScript 合计约 337.79 KB，其余按功能加载。总 JavaScript 约 532.02 KB，分块后总量没有降低。默认 500 KB 分块警告消失，未提高阈值；最终构建及验证数据见 [开发记录](development.md)。
