# 应用卸载界面、历史与接回

2026-10-24：已将 [单 App 执行器](app-uninstall-execution.md) 接入实际界面，并在本机 ad-hoc App 完成自建 GUI App 的运行中保留、明确确认、真实移入、持久收据、历史重开及 Finder 手动取回。**这只覆盖已声明普通 App 范围内的正常流程和部分边界**，不代替完整取消/中断/权限矩阵或首发三模块验收。

## 从看懂范围到明确执行

应用清单保持原有搜索、来源、排序和勾选对比；勾选不表示卸载选择。每行的“卸载…”单独打开一个 App 的核对流程，实际传递保留的 Mole 任务 ID/原条目索引，不从显示名称、排序位置或前端路径生成修改对象。非普通来源、列表正在刷新或已有处理时禁用入口；完整资格仍由后端决定，前端不替代保护/运行/权限规则。

首次点击只准备计划并读取运行/后台/管理检查，不会发起处理或系统授权。弹窗先展示应用名、完整路径及“只移入 App 包、包外数据全部保留”。发现运行进程时提示自行退出再检查；发现管理/服务线索、未知、变化、失效或不支持时保留，不显示可用的执行确认。

仅后端 v2 确认有效时提供明确勾选和“移入废纸篓”。普通 App 的支持范围、系统处理后再核对及无应用内恢复的限制均在提交前展示。确认最长 30 秒，不自动刷新、不因前端重绘续期；确认过期或时间回退禁用执行，用户可明确重新检查。读取、勾选、关闭和到期都不自动提交。

前端验证计划/来源/完整路径、协议与固定范围、两组观察/确认的 ID 和摘要、原始期限、普通 App 明确确认要求，以及结果/收据/事件链；未知版本、矛盾数据或其他请求的响应不能当作成功或生成许可。设备/inode 保留十进制字符串，避免 JavaScript 大整数丢失精度。技术事件按需展开，界面不堆叠额外页面标题或规则卡片。

## 任务、窗口与历史

明确提交一次后立即消费本次前端确认，并保存请求 UUID 供接回；无论返回成功、失败、响应丢失或重复点击，都不自动重提。进度查询和重新读取只读取同一个请求。读取失败保留上次证据、退避重试；晚到运行态不能把已提交终态改回进行中。读请求先于后台准入抵达时，不用一次暂时“无记录”认定未执行；执行响应结束或已看到该请求后才处理明确无句柄/记录的观察。

“取消卸载”只发送当前确切请求 ID，不通过当前最新任务或应用名取消其他操作。取消在请求中时持续显示等待实际结果；一旦系统已调用，成功或待核实仍显示实际收据，不能改写成未处理。无运行句柄但持久记录仍为 running 时说明需要重启对账，不假装仍有工作或自动继续。

关闭提交前的弹窗撤下计划和确认，迟到检查不能重开弹窗。关闭已经提交的窗口只隐藏观察窗口，保留执行器需要的计划，顶部状态可重新打开；不暗中取消或抛弃原生结果。WebView 重载只恢复请求 ID/读取已有 running 记录，不重建计划或重发执行。窗口接回标识不可用时，仍可在持久历史查结果。

“操作历史”增加独立卸载记录，读取最多 64 份验证过的摘要；可打开确切逐项结果、原因、当时收据及事件。再次打开同一请求会重新读取；不因观察器上次已结束而停在空窗口。历史列表晚到响应不抹去本窗口已取得的保留证据。查看旧记录不生成新的卸载选择或触发扫描。

真实移入/待核实后保留旧应用列表并提示刷新，再次检查前需手动刷新；不把旧清单中的原路径视为仍可操作，也不自动重复卸载。弹窗关闭后返回原触发点，触发点已失效时回到内容区。

## 恢复边界

收据标注为“当时记录的移入位置”，不能声称它现在仍在原位置。当前没有应用内自动恢复，不跟随旧收据或原路径覆盖新对象。需要取回时，在 Finder 核对 App 身份与原目录，优先使用“放回原处”；如果系统未提供该项，可将确切的 App 移回原目录，原位置已有同名对象时取消。

本机真实 UI 试验中没有出现“放回原处”。已验证正常 Finder 备选流程：在废纸篓选中确切自建 App，复制，前往原来的 `~/Applications`，使用“移动项目到这里”（Option-Command-V）。移动前已核对原位置不存在；返回后原设备/inode、Info.plist/主程序哈希一致，旧收据位置不存在，包外标记不变。没有清空废纸篓或覆盖其他对象。该证据不证明所有卷/权限环境或冲突处理均已验收，历史保留的是当时 moved 事实，不自动标为已恢复。

## 验证与剩余关口

新增协议单元测试与浏览器交互覆盖明确确认/单次提交、过期/未知/坏协议、迟到检查撤回、运行中关闭不撤下计划、按请求取消、响应丢失、旧窗口重建、历史重开及浅深色最小窗口布局。浏览器 transport 全为 mock，不访问本机文件或调用原生操作。

原生验证使用唯一新建的 GUI App：实际清单共 59 项，按完整路径找到自建目标；运行中提示退出并保持零卸载会话，退出后重新检查才取得确认；实际 App UI 得到 pending → intent → moved 及确切收据。原生代码没有自动结束该进程；自建最小 App 未实现 Quit 菜单，测试工具经精确程序路径/包身份核对后只结束该测试进程，再继续卸载。没有处理其他已安装 App。

打开新包前使用 SQLite backup 保存用户数据库及已提交 WAL；实际 v3 → v4 自动备份/迁移成功，主题、保护、保留天数和首次说明确认保持。实际 App 的恢复证据与测试前备份见 `local-artifacts/native-uninstall-ui-130-lihcaoe4/`；不发布该本机私有目录。
