## 标记读取

使用已有应用目录/Contents/Info.plist 句柄、有界 XML/binary 解码和最后证据复核；只增加 LSBackgroundOnly 的读取，不接受前端元数据或路径。支持布尔、整数及最多 128 字节且无控制字符的字符串，按原函数接受 `1`、`YES`、`yes`、`TRUE`、`true`；不折叠大小写或裁剪空格。缺键单独记录 absent，显式未启用记录 disabled。标记是配置属性，不是主应用或后台服务的运行状态。

浮点数、集合、数据等未适配类型，以及过长/带控制字符的字符串保留 unknown；不把 NSNumber 的实数 1.0 误当整数 1。原 plutil 对集合等类型的 raw 表示可能有特殊行为，本轮只声明受支持类型的等价范围，其他类型不猜测。只启用已锁定 Foundation 的 NSValue feature 与既有 Core Foundation 类型判断，无新依赖版本。

## 只查询相关父目录

无需枚举全部 /Volumes：上游根集合成员关系只取决于所选路径的精确父目录，以及该位置的限定条件。本轮按以下条件对该父目录取证：

1. 精确固定根 `/Applications`、`$HOME/Applications`、`/Library/Input Methods`、`$HOME/Library/Input Methods`。
2. `$HOME/Library/Containers/io.playcover.PlayCover/Applications` 存在为目录时可列入。
3. `/Volumes/<非隐藏的单个目录>/Applications` 存在为可读目录，且不是系统或用户 Applications 的同一设备/inode 对象。

仅直接父目录相同算命中；前缀相似、嵌套目录和隐藏卷不扩大范围。HOME 来自后端 App 路径环境，与 CLI 运行器保持一致，不接受 WebView 覆盖。目录观察只返回受限类别，不返回额外的 HOME、卷清单、inode 或文件内容。

后台标记未启用时跳过目录 I/O；启用时至多持有所选父目录和两个去重依赖目录。使用本地、非已知 dataless 的目录句柄与设备/inode 比对，访问能力通过 faccessat/AT_EACCESS 观察；不按权限位推定可读。缺失/非目录的去重依赖只记录非目录条件并在返回前重查，其他读取错误保持未知。父目录/依赖保留路径解析、句柄、mtime/ctime 和本地卷条件；访问状态再次核对，变化时撤回为 rootsChanged。应用文件证据在这些观察之后复核。

目录别名可参与只读的同对象排除比较；所选应用本身仍服从原检查器的可识别链接/别名拒绝。本轮比上游额外限制读取到本地/非已知云占位目录，不支持或权限不完整时保留未知，不发布未命中。PlayCover 目录类别不意味着平面布局已可读取；缺少 Contents 的真实 PlayCover 应用仍受原检查器布局限制。

所有读取仍在两个实际工作器与 5 秒停止等待预算内，超时不强制中断内核调用，真实工作器结束前继续持有名额。句柄/元数据比较不是事务，不能消除观察后的挂载、路径或权限变化，不作为未来修改的身份凭据。
