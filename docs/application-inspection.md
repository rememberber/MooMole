# 应用身份与主应用运行观察

2026-10-18。应用列表的只读补充能力；依附固定 Mole 清单，不作为卸载计划、权限、签名或执行资格。

## 使用方式

展开应用的“位置与来源”时，在现有清单信息下读取本地版本/构建号、Bundle ID 比对和主应用运行观察。详情关闭、筛选移除或离开页面后停止观察；重新展开会重新检查，不在折叠行逐项轮询。可用“重新检查状态”手动更新；开始检查即撤下旧结论，失败不保留旧的正面证据。版本缺失显示未提供，身份不可读或无法判断运行时保留未知。

- “发现主应用运行”：本次按标识、安装路径及目录设备/inode 匹配到主应用实例；PID 只作展示，不作为进程身份或关闭目标。
- “未发现匹配主应用”：本次查询未在此安装位置发现匹配实例。辅助进程、后台服务和文件占用未检查，不能解释为应用未运行、没有使用或可以卸载。
- “运行状态无法确认”：身份缺失/不同、部分实例缺位置或 PID、来源失败等。Mole 清单与本地 ID 不同则不查询运行实例，提示重新读取列表；Mole 未提供 ID 时标记未比对，不伪造一致。
- 其他位置的同标识运行实例单独计数，按不同路径去重，不归到当前应用。继承上游去重后的清单范围，不能据此恢复 Mole 已省略的安装副本或识别共享数据。

显示检查时间，并一直说明瞬时、有限观察。结果接收一分钟后明确标记“较早结果”，要求重新检查；没有后台重新查询。计时绑定本次响应代次，旧请求/旧计时器不覆盖新结果。列表成功刷新时接入新任务 ID，关闭详情或切换页面后的迟到响应忽略。观察仅在当前组件会话内保留，不缓存到磁盘、SQLite 或任务历史，不恢复成旧版结果。

## 后端与读取范围

`inspect_application` 仅接收 taskId 与原始清单 index；验证 UUID，从临时结果缓存中的成功 apps 任务取有界路径和 Mole 原始 Bundle ID。不接受前端路径、标识、PID、Shell 或查询来源；未知/过期/淘汰结果和异常字段要求重新读取列表。

目标限可读取的本地绝对 .app 目录。拒绝可识别的链接/别名、父级跳转、网络卷及带 SF_DATALESS 的目标目录。保留应用目录句柄，用 openat/O_NOFOLLOW/O_NONBLOCK 相对读取 Contents 和 Info.plist；要求普通文件、单链接、同设备，拒绝链接、特殊文件、跨挂载和已知 dataless 元数据。不遍历关联内容、解析可执行文件或尝试写入，也不更改权限。

Info.plist 最多 1MiB，按文件大小和实际读取双重限制；通过 Foundation 解码 XML/binary plist 字典，提取三个有界字符串及受支持的 LSBackgroundOnly 标记。未知类型/无效标识保留未知，不把数字或任意值转成版本；本轮测试拒绝 XML 外部实体，不读取外部文件。返回前复核保留的目录/文件、相对名字及原目标的设备/inode、大小和 mtime/ctime，变化时整份观察撤回。这些复核不构成文件系统事务，不能消除最终观察后的替换窗口，也不为未来修改提供文件身份凭据。

运行观察使用 Apple [NSRunningApplication](https://developer.apple.com/documentation/appkit/nsrunningapplication) 的 runningApplications(withBundleIdentifier:)，只以刚读取的本地 ID 查询，最多 32 个返回实例。读取 bundleURL、bundleIdentifier、PID 与 terminated，位置不完整或目标不可读取保持未知；不按名称、厂商或标识相同就认为属于当前路径。运行属性受主运行循环更新和并发变化影响，查询结束后应用仍可能退出或重启。本轮不使用 PID 执行任何控制操作，也没有向系统查询全部辅助进程。

使用独立于图标的两个真实工作器名额；5 秒停止等待，已开始的阻塞读取继续持有名额直到真正结束，超额请求提示稍后重试。超时提示记录当时的静态检查环节，例如「核对安装收据」；它是观察位置，不表示已找到根因。该请求同时标记停止：仍在队列中的工作器不开始读取，已开始的工作器在当前阶段返回后的下个检查点退出，不继续后续发现/复核或发布部分结果。已阻塞的阶段仍按自身规则完成和释放资源，不能声称当前单次读取、阶段或进程清理被硬中断。面板关闭不强制终止 AppKit/文件 I/O，期限不是内核操作的硬上限。入口观察到安装准备或退出时拒绝新请求；已接受的纯读取不作为数据保存任务或退出阻断条件。没有启动/关闭应用、提权、服务注册、HTTP 或新授权弹窗。

正式程序每请求只增加一个静态阶段编号和停止标记，不存储路径、应用标识、分段耗时或诊断日志，不新增 IPC、设置或历史。显式真实只读测量、受控超时验证与未完成范围见 [详情检查性能](application-inspection-performance.md)。

协议 v25 返回 checkedAt、本地标识/版本/构建、identity（matches/different/unreported/unavailable）、running（observed/notObserved/unknown、展示 PID、其他位置数与原因）、protection（客户端命中原因/目录）、moleProtection（固定修订系统组件规则观察）、officialUninstaller（原清单名称绑定的官方卸载器提示）、background（后台标记与目录条件）、associations（21 个精确位置、24 类 Library 原名、空格/XDG/渠道/严格包名变体及有界组/派生目录的只读结果与客户端保护）、embedded（包内扩展实际标识的有界观察）、extensionData（已取得扩展标识的精确位置、有界 ByHost 及客户端应用组名称观察）及 installations（本次清单、系统登记、常用目录、本地卷与收据位置的共享保留核对）。规则先于应用文件观察读取；后台标记启用时才探测相关父目录及去重依赖，目录观察完成后复核应用文件。支持标记类型与条件边界见 [后台应用条件](application-background.md)，其他版本绑定和未完成范围见 [应用保护提示](application-protection.md)。前端校验版本、时间、字符串、枚举、数量/PID 边界和身份/结果一致性；未知协议或矛盾结果不发布部分通过。CSP、主 settings JSON 和数据库 schema 不变；只启用已锁定 Foundation/AppKit 的相关 API feature，无新依赖版本。

## 验证与后续

隔离文件系统验证 XML/binary、未知类型、标识不一致/未提供、运行路径与同标识副本、终止/无效 PID/缺位置、来源失败、符号链接/硬链接/FIFO/缺失/超大文件、外部实体及文件/Contents/应用包替换；只对自身临时目录写入。任务缓存验证原条目与 ID 绑定；前端协议和浏览器 fixture 验证未知/错误/重试、关闭重开、列表刷新后的迟到响应、一分钟较早提示和浅深色布局。真实主机验收和测试数见开发记录第四十七阶段。

后续仍需精确关联数据、共享归属、完整 Mole 卸载保护规则、完整活动/文件占用、退出提示与取消、拒绝退出/自动重启、计划和逐项执行。客户端系统目录/自身/保护目录已补充只读提示，当前检查不提供卸载按钮或自动退出行为，也不替代 Mole 规则与执行前复核。

应用详情现可按需查看 [21 个精确标识关联位置](application-associations.md)，显示发现、未发现和无法确认；全部保留，不证明归属或提供执行资格。共享、个人数据与完整发现/保护仍待完成。

安装副本现可查看 [系统登记位置的只读核对](application-copies.md)：候选会重新验证包内身份及文件证据，发现时提示关联数据可能共用，未发现仍不证明只有一个副本。

共享保留核对已扩展为同一 Mole 清单前 64 项加系统登记前 32 项的有界候选，按实际 ID/包名适配固定 Mole 同标识、派生标识与渠道保留规则；完整发现仍待完成，见 [共享关联](application-copies.md)。

共享关联已增加 [常用安装根的有界发现](application-discovery.md)，补查未登记/被清单省略的位置；目录问题、变化和上限保持不完整。命中仍持有证据，未命中释放句柄并在返回前重新核对元数据，不提供执行资格。外接卷枚举与收据仍待完成。

嵌入 appex、XPC 和登录项的实际标识检查使用同一新鲜主身份和规则绑定，详情按需展开；不查询其运行状态，也不证明签名或数据归属。预算、变化撤回和未完成范围见 [嵌入扩展](application-embedded.md)。
