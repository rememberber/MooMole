# 从 AI 线索进入个人文件整理

2026-10-30：AI 深度扫描中的普通个人文件线索，可以明确带入文件整理。先独立重新扫描并核对原始身份，再由用户重新选择，使用既有预览、移动、ZIP 或废纸篓流程。原来的 Mole 候选清理审阅继续使用原始 Mole ID；扩展元数据不会冒充缓存候选或直接成为修改计划。

## 两次明确选择

1. AI 报告生成后，“带入文件整理”只对本报告中有模型说明、保留了物理身份的普通文件开放。所有关注项默认不选，每次最多 20 项，筛选不改变确切 ID 的选择。保留与核实建议均可带入，**带入不表示 AI 认为文件可删除**。
2. “去文件整理…”只发送当前报告 ID、线索 ID 与新的任务 ID。客户端不提交模型生成的路径或新目录。服务端核对当前成功报告、原选目录、有效期、保护和身份，再启动普通文件的独立扫描；全部指定关注项必须能与新扫描的文件身份核对，变化、受保护、超限或未找到时拒绝，不猜测替代文件。
3. 文件整理用全新的 scan/item ID 展示结果。初始仅显示本轮关注项，但**处理选择仍全部为空**。可展开当时的 AI 保留/核实说明、预览文件，也可查看同一目录内本次扫描的其他普通文件。AI 来源不会改变普通文件扫描范围、保护规则或执行门槛。
4. 用户再次勾选要处理的文件，使用原有独立确认与真实执行。AI 的 `e0` 等线索 ID 不能传给个人文件执行器；模型文本、理由和影响均不解析为命令、目标路径或删除资格。取消扫描只结束检查，不处理文件。已开始的文件操作继续按原逐项收据、取消与未知核查规则工作。

## 身份、时间与记录

- 扩展线索只把本账户拥有、单链接、普通已落地文件标为可继续检查。隐藏/系统/资料库/密钥等普通文件保护继续适用；目录、共享文件和其他线索仍只能查看或核实。原始 Witness 只在服务端内存保留，明确从 IPC 和发给模型的 JSON 中排除。
- 个人文件线索有独立的十五分钟墙钟和单调时间检查，从元数据采集完成时起计算，模型耗时也算入。它不依赖成功的 Mole 缓存清单：Mole 扫描失败时，仍可在合格的扩展线索上进行独立文件整理；这不放开原缓存清理审阅。
- 重新检查前、检查后以及最终文件执行分别验证范围与实际身份。新文件扫描最多 2,000 个普通文件、10,000 个访问项、十二层、7 MiB 身份数据和十秒，部分结果与变化仍需如实呈现。执行继续使用正式 Mole 路径保护、当前用户保护、权限、持久意图与逐项收据；不宣称 AI 能确定备份、唯一性或文件空闲。
- AI 说明仅作为本次新文件扫描的内存注释，不写入个人文件 Plan、SQLite 执行历史或归档。重新普通扫描会撤下这些注释，App 退出后失效；文件扫描过期会禁用操作。实际操作记录保持“个人文件整理”来源，保存用户第二次选择后的确切对象及结果，**没有新增持久化 AI 解释审计**。原 AI 报告本身仍按十五分钟会话保留规则撤下。
- 页面切换或 WebView 重载只读取已有扫描状态，接回原目录及说明，不重新调用模型、扫描或修改。用户已经手动编辑的目录不会被晚到的读取覆盖；改变目录或重新扫描仍撤回处理选择。App 重启没有 AI 报告或可重放交接计划，不自动恢复请求。

## 验证

- 真实 Codex 调用只发送唯一自建目录内两份样例文件的元数据，没有发送正文或用户实际目录清单。模型返回两条 **keep** 建议；测试明确选择其中一条继续检查，再使用新的文件 ID 作第二次选择和移动确认，正式 Mole + 生产原生执行器完成一项同卷移动，内容与未选文件保持。实际数据库关闭/重开后执行收据完全一致。**这是保留内容的整理操作，不是模型建议删除的证据。**
- 私有证据 `.cache/ai-handoff-native.json` 包含实际发送线索、模型报告、重新扫描结果及移动收据；`.cache/ai-handoff-live.log` 为显式调用记录。测试使用和产品相同的 Agent 适配、模型结构化解析、交接解析、文件重扫和移动执行器；它没有走 App 窗口里的完整 AI 启动/Mole 全账户候选收集交互，不能替代该验收。
- 完整 Rust 默认回归 **638 通过、90 显式忽略**；显式真实模型/原生测试另行 **1 项通过**。最终补强扫描取消和时钟边界后，交接相关默认 **2 项再次通过**。覆盖陌生/重复 ID、报告替换、过期、回退、私有身份不外传、变化/保护拒绝、关注映射新 ID，以及取消不发布处理选择。忽略项没有计为通过。
- 前端 **216 项通过**；AI、交接及个人文件 **16 项浏览器回归通过**，包括默认不选、原 keep 说明可见、第二次选择与确认、变化或伪造关注路径拒绝、重载接回非默认目录且不重放。预览、归档、单项和批量恢复另行 **15 项通过**，合计 31 项相关页面回归。明暗布局已目视核对，原生 transport mock 不当作真实文件操作证据。
- 优化 arm64 App 已构建并验证最终 ad-hoc 签名、两份嵌套引擎、架构、资源与 ZIP 解包。最终开发产物 `local-artifacts/MooMole-0.2.0-mac-arm64-QEhGxf/`，41.77 MiB（`8d74328` 加本节点，dirty=true）；未替换用户安装、公开发布或推送。
