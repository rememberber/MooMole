服务端只接受来源类型、当前扫描 ID、项目 ID 与 PDF 页码，从保留扫描解析路径；不接受任意路径或 URL。读取前后核对保护、本地状态及文件身份，失效扫描、变化、共享硬链接、占位或受保护文件拒绝显示。

- 图片：系统 ImageIO 在内存中生成最长边 1024 像素的 PNG，按方向信息变换。输入最多 32 MiB、八千万像素；多帧仅显示第一帧并说明。参照 [Apple 缩略图参数](https://developer.apple.com/documentation/imageio/kcgimagesourcethumbnailmaxpixelsize) 与 [ImageIO 目标编码](https://developer.apple.com/documentation/imageio/cgimagedestination)。
- PDF：CoreGraphics 按用户选择逐页渲染为有界 PNG，支持前后翻页，不运行 PDF 动作。加密、无效页码、输入超限及异常页面尺寸保留给系统对应应用。
- 文本：仅显示前 64 KiB 的 UTF-8 内容，截断有明确说明。HTML/脚本/XML 作为纯文本展示，不执行、不加载引用资源。其他编码和二进制内容不冒充可读文本。

最多一个原生预览 worker；八秒未返回时保留该 worker 的槽位，避免重复堆积解码。关闭窗口不展示迟到结果，不宣称已经中断系统解码。原文件不改写，不把未知格式转为可处理对象。

验证：自建 PNG、两页（含旋转页）PDF 与 UTF-8 文本的真实原生预览，核对原文件保留；PNG 和旋转 PDF 输出已视觉查看。586 项默认 Rust 测试通过，11 项文件预览、个人文件及重复文件浏览器流程通过，另有前端构建/单元测试及格式检查。新入口的打包 App 窗口验收、更多办公格式、影音播放和大文件编码仍待深化。

## 影音播放第一条主流程

普通 WAV、MP3、自包含 MP4/M4V/M4A/MOV 可在同一预览窗口手动播放、暂停和拖动定位，默认不自动播放。关闭窗口停止播放器并撤销本次预览地址；过期会停止并提示重新扫描。可播放的编码取决于系统，格式名或文件较大不表示一定能播放。流媒体、播放列表本身、外部引用、已知加密/DRM 和未支持容器保留给对应应用，不把失败改称已显示内容。

后端只接收来源、当前扫描 ID 和项目 ID。逐项核对保护、扫描时效、文件与祖先身份、所有权、单链接及本地状态，再通过持有的父目录描述符打开只读文件。软件来源同时核对其结构化来源绑定，例如所选聊天导出清单和播放列表必须仍一致。只发布随机且短期有效的预览能力地址，不把路径转换成通用文件 URL，也不启用宽泛的 Tauri 文件资产范围。

专用 `moomole-media` 协议只处理主 WebView 的 GET/HEAD，使用确切来源的 CORS 和窄媒体 CSP，不开启 HTTP 监听端口，不提供任意路径或 URL 参数。每次请求前后重新核对当前扫描、保护、来源、持有的路径和文件身份；关闭、替换、过期或变化后拒绝继续提供数据，不把变化时已读取的缓冲区发回。检查不是文件锁，不能保证阻止其他程序同时写入；已提供给播放器的旧片段不能被远程收回。

使用单段字节范围读取和定位，每份响应最多两 MiB、最多两个原生读取 worker，不把大电影整体读入 Rust 缓冲区。当前支持最大十六 GiB 的准入；无范围 GET 只支持两 MiB 内文件，更大文件要求播放器发送单段 Range，多段/无效/越界范围拒绝。HEAD 仅报告已核对文件的长度与类型。响应不缓存，后端不写原文件；浏览器/系统解码器自身的缓存行为不构成未落盘的额外承诺。实现参考 [Tauri 原生媒体字节范围处理](https://github.com/tauri-apps/tauri/blob/dev/crates/tauri/src/protocol/asset.rs) 与 [HTTP 范围语义](https://www.rfc-editor.org/rfc/rfc9110.html#name-range)。

MP4/MOV 做有界结构检查：元数据最多八 MiB、顶层最多 2,048 个盒、元数据最多 4,096 个盒和十二层；要求各轨道数据引用为自包含 `url `，拒绝外部/未知引用、引用电影、压缩元数据及已知加密编码条目。这不是完整编码或容器正确性验证；无法解码仍明确显示失败。WAV/MP3 检查对应文件头，真实播放交给系统 WebView 解码器。外部引用不是本轮支持范围，相关约束也见 [W3C ISO BMFF 格式说明](https://www.w3.org/TR/mse-byte-stream-format-isobmff/)。

单文件预览保留一个能力；新版[视频并排对比](video-comparison.md)在一次会话中最多保留四个独立能力，换会话撤销旧能力；有效期不超过当前扫描的十五分钟期限，并有单调时钟边界。关闭时清空播放器来源，迟到的准备结果也发出撤销；IPC 丢失或 WebView 重载时不重新播放，原生定时回收最迟在过期后下一个三十秒周期移除保存引用。已经开始的有界读取可以结束，但回发前还须核对能力存续。准备检查仍使用单 worker 和八秒响应期限，超时不释放仍在工作的槽位，不循环重试。

验证使用自行生成的真实 PCM WAV 与三秒 H.264 MP4，不用用户音视频。视频生成器和小样例在 `tests/fixtures/media/`；原生测试验证该视频的真实容器与字节范围、六十四 MiB 稀疏 PCM 的定位/分段上限、原文件保留、撤销/过期/保护/读后变化、HEAD 与无效范围、外部引用/加密及异常盒长度拒绝。证据在 `.cache/media-preview-native.json`。浏览器通过单独的传输模拟播放同一个 H.264 文件和 WAV，验证未自动播放、实际时间推进、暂停、定位、过期和关闭/迟到清理；这些是页面播放器证据，不代表 Mac WKWebView 自定义协议已验收。
