# 文件内容预览

2026-10-30：文件整理与重复文件结果中，可从每一项“预览内容”打开图片、PDF 或文本。预览独立于勾选、移动和废纸篓确认，不产生处理许可。

服务端只接受来源类型、当前扫描 ID、项目 ID 与 PDF 页码，从保留扫描解析路径；不接受任意路径或 URL。读取前后核对保护、本地状态及文件身份，失效扫描、变化、共享硬链接、占位或受保护文件拒绝显示。

- 图片：系统 ImageIO 在内存中生成最长边 1024 像素的 PNG，按方向信息变换。输入最多 32 MiB、八千万像素；多帧仅显示第一帧并说明。参照 [Apple 缩略图参数](https://developer.apple.com/documentation/imageio/kcgimagesourcethumbnailmaxpixelsize) 与 [ImageIO 目标编码](https://developer.apple.com/documentation/imageio/cgimagedestination)。
- PDF：CoreGraphics 按用户选择逐页渲染为有界 PNG，支持前后翻页，不运行 PDF 动作。加密、无效页码、输入超限及异常页面尺寸保留给系统对应应用。
- 文本：仅显示前 64 KiB 的 UTF-8 内容，截断有明确说明。HTML/脚本/XML 作为纯文本展示，不执行、不加载引用资源。其他编码和二进制内容不冒充可读文本。

最多一个原生预览 worker；八秒未返回时保留该 worker 的槽位，避免重复堆积解码。关闭窗口不展示迟到结果，不宣称已经中断系统解码。原文件不改写，不把未知格式转为可处理对象。

验证：自建 PNG、两页（含旋转页）PDF 与 UTF-8 文本的真实原生预览，核对原文件保留；PNG 和旋转 PDF 输出已视觉查看。586 项默认 Rust 测试通过，11 项文件预览、个人文件及重复文件浏览器流程通过，另有前端构建/单元测试及格式检查。新入口的打包 App 窗口验收、更多办公格式、影音播放和大文件编码仍待深化。
