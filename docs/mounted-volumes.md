# 从磁盘进入空间分析与文件整理

2026-10-30：空间分析工具栏新增“选择磁盘”，列出启动卷根目录、当前账户目录，以及 `/Volumes` 下直接挂载的可识别本地卷。选择启动卷进入 `/`，账户项进入当前账户目录，两者不混用；已挂载项目也可能是磁盘映像，不据此声称属于外接物理硬件。原有目录选择和路径输入保留。

每项展示路径、文件系统、所在卷可用量和总量，保留只读、未知容量、不可核对和列表不完整状态。只读卷允许分析，不意味着能修改；APFS 容量可能共享，列表中的数值不能直接相加，也不能以扫描逻辑大小推断可释放容量。启动根目录只提供分析和继续导航，整理需进入具体个人文件夹；系统、资料库、其他账户、保护和不可执行对象继续由现有原生规则保留。

## 原生观察与选择边界

- 用 [getfsstat](https://developer.apple.com/library/archive/documentation/System/Conceptual/ManPages_iPhoneOS/man2/getfsstat.2.html) 填充自有固定缓冲区，不使用跨 worker 共享的 `getmntinfo` 缓冲。最多观察 256 个挂载项，列出最多 32 项，枚举本地可见的直接挂载位置；网络、隐藏系统挂载、不常规挂载点等不是完整设备盘点范围。MNT_NOWAIT 避免等待所有文件系统更新，容量仍以所选目录描述符上的 fstatfs 观察为准，不承诺严格实时或原子快照。
- 文件系统的本地属性按 [Apple 对 MNT_LOCAL 的说明](https://developer.apple.com/library/archive/qa/nw09/_index.html)核对。新列表替换旧短期选择；随机 ID 不由路径推导、不持久化，墙钟与单调时钟共同限制两分钟，只能取用一次。选择前重新打开确切位置，核对卷来源、文件系统标识、设备/inode、挂载位置及只读状态；普通目录还核对祖先见证。失联、同路径替换、过期和刷新均不能直接复用旧选择。
- 现有文件修改见证工具有意拒绝 `/`，本节点不放宽它；启动根目录用固定 `/` 的只读描述符读取文件系统信息并核对根对象，不遍历子项、不提供根目录修改许可。普通文件修改仍需独立扫描及原有结构化确认。
- 接口最多等待三秒；超时的读取 worker 仍持有原读取槽和更新租约直至真实返回，不能重复叠加读取。超时或失去界面观察不自动开始分析。选择只交还刚核对的只读分析路径，不向文件执行器交付删除对象、任意命令或许可。

卷位置在选择后仍可能变化，本节点不承诺把整段长分析锁定为原子磁盘快照，选择完成后也不持有挂载根阻止用户卸载。后续文件整理重新扫描当前实际目录、确切选择、确认，并沿用执行前的路径/文件见证、Mole 保护、只读与权限检查；分析结果和容量信息均不授权修改。基础流程共用取消、真实收据、历史与归档，未加入自动删除、挂载/卸载或系统权限变更。
