# 开发记录

## 2026-10-15 · 第一阶段：可运行的 CLI 可视化客户端

按 [guidance.md](guidance.md) 首先创建 `.gitignore`，随后搭建 React + Vite + TypeScript + Tauri 2 + Rust + SQLite。按用户补充的 [产品宗旨](product-direction.md)，以 Mole CLI 的能力可视化为主线，开发缓存测量为补充功能。

### 已实现

- 参考图风格的主窗口、侧栏、卡片、设置弹窗及浅色/深色主题。
- 固定上游提交的引擎准备脚本，保留 Shell 资源和许可证，编译分析/监控程序。
- Rust 侧只读命令适配：目录分析、系统快照、应用清单和 `clean --dry-run`。
- 目录下钻、筛选、占用条、完整性标记、Finder 定位与原生目录选择。
- 三类开发缓存的补充测量、影响说明和保护列表。
- SQLite v1 迁移、设置、任务记录、保留期限及启动后的中断识别。
- 原生任务取消、进程组清理、超时、输出上限及诊断文本保留。
- README、首次使用说明、关于页中的学习研究、风险与 Mole 官方产品引导。

### 验证证据

- `npm test`：3 项通过；未知/零/部分占用、缺失指标及 home 路径边界。
- `npm run check:rust`：7 项通过；SQLite 持久化与重启恢复、无效设置、目录输入、控制序列处理、stdout 错误诊断、进程组取消和超时。
- `npm run test:e2e`：3 项通过；浏览器示例数据隔离、目录筛选、主题、弹窗关闭、用途说明及全部主页面无横向溢出。
- `npm run build`：TypeScript 与 Vite 构建通过；`npm run format:check` 通过。
- `npm run tauri -- build --debug --bundles app`：生成约 48 MiB 的 `MooMole.app` 本地开发包；内含完整引擎资源与元数据。
- 原生窗口验证：首次使用确认后读取真实系统快照；参考图目录扫描返回 8 项、1,472,684 字节，界面显示 1.4 MB；应用列表返回 58 项。
- 原生窗口验证：`clean --dry-run` 成功完成并展示 Mole 预览；另一次运行从界面取消，SQLite 分别记录 `succeeded` 与 `cancelled`。
- 进程路径核验：打包应用从 `Contents/Resources/mole/` 调用引擎，未依赖全局安装的 `mo`。
- 已人工检查浏览器概览、分析、设置截图，以及原生分析界面。

### 当前边界

第一阶段不是完整 MVP。清理目前展示引擎的文本预览，结构化逐项审阅和实际删除未开放；应用清单尚不执行卸载；维护、工程产物/安装包、Mole 原始历史和长驻状态流待接入。客户端保护列表目前只作用于补充的开发缓存检查，完整清理预览继续遵循 Mole 自有白名单。

浏览器模式明确使用示例数据，不支持真实本机操作。真实系统验证目前只覆盖 Apple Silicon；Intel、最低系统版本、签名公证、公开发行更新链及完整安全审计尚未完成。开发包不是已签名公证的公开版本。
