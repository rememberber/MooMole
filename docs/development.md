- 清理页保存审阅计划，历史页查看和重新复核；重启恢复最近扫描，未保存勾选不恢复。

## 2026-10-15 · 第五阶段：用途影响说明和目录内容复核

开始时工作区干净，前两份提交已保存；本轮继续补齐审阅信息与受控执行前的观察能力。

### 已实现

- 后端按明确路径边界提供用途、可能影响和可恢复性说明，覆盖默认 npm 内容缓存、Homebrew 下载缓存、用户日志/诊断报告及需逐项确认的应用缓存范围；其他位置保留未知。

- 描述符相对遍历和 no-follow 打开，拒绝链接、特殊文件、共享硬链接、跨挂载、超过 64 层或单次 10000 节点的范围；每次遍历在系统调用间检查 5 秒预算。

- 已有普通文件计划继续兼容；没有用途说明的旧记录明确显示未知。目录摘要字段可选，保持 SQLite v2 兼容。
- 界面每秒更新扫描/计划到期状态，自动禁用过期计划的规则复查并隐藏失效的旧证据，同时继续由后端校验有效期。

## 2026-10-16 · 第十四阶段：只读任务的进程所有权与退出等待

### 已实现
