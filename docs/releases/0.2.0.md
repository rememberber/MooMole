# MooMole 0.2.0 发布验证

2026-10-29：[GitHub Release](https://github.com/rememberber/MooMole/releases/tag/v0.2.0) 已公开发布，说明提供英语、简体中文和日语。App 与标签绑定提交 `cc7176af49e5de80e67363f934927af02c1747d6`；发布后的 README 和更新清单另行提交，不改变已验证二进制的来源。

## 发布内容

相比 0.1.0，包含速战速决与用户缓存处理、AI 深度扫描、中英日界面、窗口拖动和任务动效，以及固定至 `308bf9911179ddfa40e5df9fdc42095a18ba5cfc` 的 Mole CLI 1.65.0。DMG 内安装说明也提供三语。

## 已完成

- [Candidate installers 40806398419](https://github.com/rememberber/MooMole/actions/runs/40806398419) 同一提交的五项作业全部成功：前端/仓库、macOS 14 arm64 与 macOS 15 Intel 原生检查、两架构优化安装包构建及源码/依赖材料封装。
- 前端 190 项单元测试、320 项浏览器回归及三语 2,313 条消息校验通过；两架构各 560 项默认 Rust 测试、22 项上游源码对照、2 项选定历史集成测试通过；69 项显式可选测试保持默认忽略，不表述为全部测试均已运行。
- 两份实际 Actions artifact 的完整字节数与官方 SHA-256 匹配。每份十三个预期文件、十一份有效载荷及十二行内部 SHA512SUMS 全部复核；候选清单和摘要重新 seal 后逐字节相同。
- 客户端与 Mole 源码逐项匹配对应 Git 树；依赖分发物摘要以及 npm 原始源码输入的字节/模式与固定来源匹配。此项属于材料完整性验证，不代替完整对应源码/许可证审阅。
- 两架构 App ZIP 完整 CRC、解包后三处可执行文件的架构与最终 ad-hoc 签名、引擎和许可资源核对通过。实际只读挂载两份 DMG，核对内容后确认卸载。
- 从下载后的 arm64 App 实际调用包内 analyze/status 程序，得到有效 JSON；分析自建目录返回三个直接子项、27 字节及完整状态。没有执行用户数据的清理、卸载或维护。
- 发布后使用未认证的公开地址重新下载全部五项资产，逐份核对大小、SHA-256 和 SHA-512，公开 SHA512SUMS 与上传原件一致。通过后才把 0.2.0 加入 main 更新清单，保留 0.1.0 记录。

## 验证边界

这是已公开的学习研究版本，不宣称完整生产验收通过。未使用付费 Apple Developer ID 或公证；自动化 Intel 检查不等于 Intel 原生交互验收。本轮本机锁屏，未进行新的原生窗口操作、系统授权或安装替换。

公开隔离下载后的首次打开、跨版本安装/权限行为、支持环境的完整故障与恢复矩阵、Claude 真实调用和完整对应源码/许可审阅仍待完成。公开 CLI 下载与校验不能代替 Gatekeeper 或交互验收。既有清理、卸载、Quick Look 的实际执行记录与限制继续见 [首发验收](../first-release-execution.md)、[速战速决](../quick-cleanup.md) 和 [安装升级方案](../distribution.md)。

本机原始证据保存在忽略目录 `local-artifacts/release-0.2.0/`，未将本机状态、用户路径或数据库上传为公开资产。
