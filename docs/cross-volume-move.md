# 跨磁盘移动

2026-10-30：文件整理中使用原有“移动到目录…”入口。后端按实际设备判断移动方式；另一磁盘使用独立确认，展示每个源文件、最终目标和重名处理，再依次复制、核验、发布副本和将原件移入系统废纸篓。它使用独立的结构化计划及双端记录，不冒充同卷改名。

原件进入原磁盘的废纸篓后仍占空间。不会永久删除原件、清空废纸篓、覆盖目标或自动删除已发布副本。复制后停止可能保留两份；只有取得已核验副本和原件废纸篓的两份实际收据，才显示该项移动完成。请先关闭相关文件；本轮没有完整检查所有应用占用。

## 首条流程与保护

从当前个人文件扫描的确切 ID 取出源对象，最多二十项、合计 16 GiB；不接受界面传入任意源路径。首批只支持本账户、单链接、已落地的本地普通文件和物理目标目录，延续敏感路径、资料库、链接、硬链接、云占位与用户保护排除规则。软件内容、重复文件等其他来源尚未接入此执行方式。

确认三十秒有效且单次使用；开始后有十五分钟预算，继续核验源文件身份、内容观察、用户保护、目录与祖先绑定。源和目标都经过正式 Mole 路径保护检查，复制和原件处理之前分别检查；配置在检查期间变化即保留。重名时跳过或保留两份的最终名称在确认前固定，执行期间不重新编号。

系统 `fcopyfile(COPYFILE_ALL)` 在目标目录描述符下排他创建的临时文件中复制，保留权限、扩展属性及资源分支。比较源与副本的数据 SHA-256，以及所有者、组、权限、修改时间和扩展属性摘要；存在 ACL、属性无法核对、超出核验预算或不匹配时保留原件。扩展属性列表上限 64 KiB，值合计上限 16 MiB。创建时间、访问时间与所有文件系统特性不构成已经完整验证的迁移承诺。

安全属性不移除、不自行改写。系统复制会重新序列化 quarantine 的时间和来源显示字段；核对其格式、确切数值保护位和事件标识，不把系统重写的时间/显示名称当作字节相同。其余扩展属性（包括资源分支）按原始字节核验。参考 [Apple copyfile 实现](https://github.com/apple-oss-distributions/copyfile/blob/main/copyfile.c)，实际系统行为同时由本机样例验证；不使用 RUN_IN_PLACE 或绕过系统确认。

落盘同步和最终检查后，以 `renameatx_np(RENAME_EXCL)` 发布；再次核对目标真实身份及内容，然后持久保存副本收据。原件处理前重新检查正式保护、源文件和目标副本，再调用现有原生废纸篓执行器，保存系统返回的真实原件位置。检查不是文件锁或原子快照，无法承诺阻止其他程序同时写入；变化或无法核对时停止，不自动重试。

## 取消、历史与恢复边界

专用任务持有互斥注册与更新租约。界面丢失响应不丢失后台所有权，也不重新提交。复制/哈希有取消检查和系统复制回调；发布前尝试仅清理本次持有的临时对象，不能清理替换物。已发布副本保留。原件处理已经开始时取消以实际逐项结果为准，不能撤销已经发生的系统操作。

独立 SQLite `file_transfers` 表保留结构化计划、临时路径、阶段意图、摘要及两端收据，使用既有 FULL 同步连接。容量六十四条，不静默淘汰；未核对的部分完成、未知或中断阻止下一批跨磁盘移动。“已核对”只保存核对标记，不把结果改为成功、不发起文件操作。

重开将没有执行所有者的未结束记录标为中断，保留已经落盘的收据；不自动继续、重放或清理。历史可以按各自记录位置在 Finder 核对，位置可能因后续人工操作而过期。独立记录尚未加入旧的便携执行归档，日志导出/容量管理、应用内跨卷恢复和临时文件管理仍待补充；不提供一键回滚，也不自动删除副本以模拟恢复。

## 验证范围

在内置 APFS 与外接 SSD 的实际不同设备上，用独立自建文件执行正式 Mole + 原生复制/废纸篓流程，验证内容、扩展属性、资源分支、安全保护位、两端真实收据和未选文件保留；随后按实际收据取回自建原件。独立且相同属性的样例验证复制后取消仅保留副本、不处理原件，以及副本收据提交后注入中断、重开保留证据且不重放。证据保存于 `.cache/cross-volume-native.json`，所有样例由测试创建并回收。

取回后的同一原件在立即重用时观察到 ctime 单独变化；仍拒绝继续，未放宽身份检查。确定性的属性变化回归也要求拒绝发布并保留原件。原生复制组件另验证同名不覆盖、取消时只清理自身临时文件。中断注入模型不等于已经完成 App 强制退出窗口验收。

页面回归覆盖独立确认、双端结果、取消、历史核对与重载不重复提交；个人文件/归档相邻流程一并验证。浏览器 IPC 模拟只证明页面链路。当前 Mac 锁屏，实际 App 新入口窗口仍待验收；其他文件系统、卷移除、大文件、完整故障矩阵、安装升级身份与跨卷恢复仍待后续推进。未安装、推送或公开发布。
