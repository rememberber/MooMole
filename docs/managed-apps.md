2026-11-02：本类持久记录现可通过[统一执行归档](execution-archive.md)完整保存、只读导出/打开并释放共享活动历史容量；原结果、未知及核查标记保留，不据导入记录重新执行或提供新的恢复权限。应用更新和启动管理的独立恢复记录仍留在原处。

应用列表中由 Mole 标记为 Homebrew 的副本，现在可进入独立的管理器卸载流程。显示确切 App 路径、已安装包标识、版本与管理命令位置；用户核对恢复边界并单独确认后，交给 Homebrew 正常卸载，再重新读取包登记和原 App 位置。结果进入“操作历史”，与普通 App 的废纸篓卸载分开。

## 第一条可用范围

- 普通账户、标准 Homebrew 安装：Apple Silicon `/opt/homebrew/bin/brew`，Intel `/usr/local/bin/brew`（只接受固定的标准解析位置）。执行环境使用当前账户标准 Homebrew 配置、缓存与日志目录，不继承任意 shell 选项；自定义配置根与非标准安装继续待支持。
- 来源必须是当前保留的成功 Mole 清单里的 Homebrew 行，且直接位于 `/Applications` 或该账户 `~/Applications`。前端只传清单任务与索引，不传命令、包名或目标路径作为执行依据。
- 活动包清单必须唯一指向这个 App；已安装的 `INSTALL_RECEIPT.json` 与 `config.json` 独立核对 tap、安装版本、唯一 App 声明及实际 appdir。不能用较新目录声明代替已安装收据。脚本、pkg、其他附属对象、多 App、重命名或不支持的收据均保留，提示使用原管理工具。
- 当前账户拥有的完整本地 App、可读取的身份与权限、停止状态均重新核对。Mole 当前保护、官方卸载器、自身与用户保护继续适用；已知后台/特权声明、登录组件、系统扩展与商店收据保留。未实现完整系统服务或打开句柄覆盖，不能将本节点称为所有应用均可卸载。

## 确认、执行和恢复

准备只读取、建立两分钟的一次性确认。确认绑定原 Mole 行、完整 App 身份、固定 manager 脚本身份、活动包及已安装收据，单调时钟与墙钟同时约束；过期、时钟回退、来源/保护/文件变化都需要重查。关闭撤销，迟到准备结果撤销且不执行。

实际调用仅为 `brew uninstall --cask <确切已核对标识>`。使用 `HOMEBREW_NO_AUTOREMOVE=1`，不加 `--zap`、`--force` 或 `--ignore-dependencies`，禁用自动更新、自动安装清理与升级。没有自行删除 App 的回退路径，不调用 shell，不自动关闭应用或提权。正常 Homebrew 卸载及系统行为仍可能影响内容；这不是完整个人数据保留承诺。

FULL 同步的独立历史先写检查记录，再持久化执行意图，之后才启动受监督的 Homebrew。成功需命令成功、再次读取不含该包标识、原 App 路径确实不存在三者同时成立。检查前拒绝/停止保留；意图之后的取消、超时、错误或失去完成记录均需要核实实际状态，不称为未执行，也不自动重试。工作所有者保留任务、互斥和记录收集，即使窗口不再等待；前端在关闭确认窗和重开后继续只读接回运行记录，历史可停止确切请求，取得终态后撤下忙碌状态并要求刷新原应用清单；重开后不重放，运行登记消失的历史根据原阶段变为中断或未知。未核查未知结果阻止新的修改；人工核查只记录确认，不改变原结果，也不发出卸载。

管理器卸载没有本应用的废纸篓收据或应用内撤销。通常需重新安装；应用版本和个人数据兼容性需另行处理。历史最多 64 项并计入共享准入容量；本类记录已接入 v4 统一执行归档，完整保存后可释放共享活动容量；管理器状态与原结果仍只作为历史证据。
