# 产品宗旨与功能边界

2026-10-15：根据用户在开发过程中的明确补充，本文件作为当前产品方向依据。

**MooMole 的宗旨是对 Mole CLI 进行客户端可视化，以及在此基础上提供更多的人性化功能。**

2026-10-17 用户补充：**简单直观，让用户先看懂结果，知道下一步该做什么。** 这与 CLI 可视化、人性化扩展共同约束后续设计和开发。

界面先展示结论、可能影响和下一步，把技术来源、规则细项、计划编号和诊断放在按需展开的详情中。关键保护、未知、过期和不可执行状态仍直接可见；不以简化为由隐藏风险，也不将“未发现限制”写成“可安全清理”。后续模块沿用这一原则，逐页验收。

2026-10-17 用户进一步明确：**简洁高效，更像桌面工具，避免管理后台式层层标题和导航。** 当前采用侧栏定位、顶部工具栏操作、内容区直接展示结果；移除全局/目录面包屑、重复页面标题/副标题、英文装饰标签、首页宣传卡片和重复页脚。有效的数据分组标题、当前结果路径、Mole 版本及关键状态仍保留。约定见 [桌面界面](desktop-ui.md)。

同日补充：**工具栏不与侧栏同色，侧栏和内容区明确区分，并减少视觉割裂。** 工具栏与内容区形成同色连续工作区，侧栏保留独立底色和细竖线；顶部静止时不画横线，页面滚动后再显示工具栏分隔线。后续模块沿用这一约定。

用户随后澄清：**并非全面禁用面包屑，空间分析中可点击的路径导航有实际价值，应保留。** 当前在结果摘要原路径位置提供祖先目录跳转，不恢复重复页面名称的全局面包屑；“简单直观”以操作便利和信息清晰为准，不机械地删除控件。

产品功能以 Mole CLI 的能力为基础组织。应用负责把 CLI 的输入、过程、结果和权限状态变成易理解、可控制的桌面流程；开发缓存分析只是补充能力之一，不作为整个产品的定位。

## 人性化功能

优先实现目录选择、搜索/筛选、影响说明、逐项审阅、保护列表、可取消任务、明确的权限与失败提示、历史记录，以及主题和键盘操作。界面不能让未知大小看起来是零，不能把“移入废纸篓”等同于“已释放空间”。

客户端扩展应有明确的使用场景，并保持与 Mole CLI 执行语义一致。已有的路径保护与应用保护规则应继续生效；需要逐项执行的流程先完成适配，不能把用户确认的一份预览替换为另一次全量清理。

1.0 的完整流程范围、首发基线、固定版本每个用户入口/参数的支持状态及源码证据见 [能力映射](mole-capability-map.md)。此表和 release-roadmap 共同追踪后续开发，不将范围定义当作功能已完成。

## 开发阶段

2026-10-20 用户确认调整推进顺序：应用列表和只读详情阶段性收口，暂停厂商/产品特例的长尾扩展，优先完成范围明确的清理操作闭环，再推进其他 Mole 核心流程。完整卸载保留为独立里程碑；每轮以用户可完成的操作及明确验收关口衡量进展，不以新增目录规则或测试数量代替功能完成。当前顺序见 [发布路线图](release-roadmap.md)，清理的隔离联验见 [受控清理闭环](controlled-cleanup.md)。

当前交付以只读可视化为主，已接入来源明确的单文件日志确认与受限执行，见 [日志执行边界](log-cleanup-execution.md)。该范围的发布 App 权限、任务控制与故障继续作为验收条件；本机普通账户的完整占用视图受限，不放宽规则，验证受限按次授权路线前同步推进状态持续采集等只读核心流程。当前不是完整 MVP，也不以开发缓存检查代替完整 CLI 能力适配。

技术栈、开发前创建 `.gitignore`、界面风格参考，以及 README/App 的学习研究用途、风险说明和官方产品引导，继续遵循 [guidance.md](guidance.md)。

## 安装与升级约束

用户没有付费 Apple 开发者签名能力。正式发布以免费分发为前提，参考 MooTool Electron 的“检查更新 → 下载匹配架构 DMG → 校验大小和 SHA-512 → 用户打开 DMG 并手动替换 App”流程。保持 Tauri 技术栈，由 Rust 实现对应能力。

不将 Developer ID、Apple 公证或自动覆盖安装作为发布门槛。采用适合 Tauri 的 ad-hoc 签名与真实安装验证，并如实说明首次打开可能出现的系统提示。方案、参考源码及验收要求见 [distribution.md](distribution.md)。

应用关联位置以只读方式提供精确标识、原名/空格/XDG/渠道及严格包名派生、VS Code 专属规则及厂商嵌套目录的有界位置观察，默认折叠并全部保留。派生来源和可能共用的解释按需展示，不把另一产品的包名误作数据归属。位置存在不代表独占归属，未发现不代表没有其他数据；多副本、共享与个人数据判断及执行前验证仍是完整卸载的前置工作。见 [关联位置](application-associations.md)。

应用详情可按需核对 [同标识系统登记位置](application-copies.md)，发现时提示关联数据可能共用；失效、超限和变化保留不完整，未发现不代表数据独占。完整 Mole 多副本/共享规则仍待适配。

[共享关联](application-copies.md) 已接入固定 Mole 同标识、点分派生 ID 与渠道包名保留语义；核对本次清单前 64 项及系统登记前 32 项的本地身份，区分命中原因和不完整。未进行完整安装根/卷/收据扫描，未命中不能解除保留或提供执行资格。

共享关联已增加 [常用安装根的有界发现](application-discovery.md)，补查未登记/被清单省略的位置；目录问题、变化和上限保持不完整。命中仍持有证据，未命中释放句柄并在返回前重新核对元数据，不提供执行资格。外接卷枚举与收据仍待完成。
