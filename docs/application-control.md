# 应用打开、正常退出与重新注册

2026-10-30：应用列表中的普通 App 可选择“打开”或“退出…”，核对确切安装路径后确认执行。只从保留的成功 Mole 清单解析目标，不接受前端提供的路径、PID、命令或任意参数。

- 打开使用 NSWorkspace，已有运行副本时仅向相同位置请求显示。遵循 macOS 安全提示，不绕过 Gatekeeper。
- 退出使用 NSRunningApplication 的正常退出请求，核对包标识、安装位置和当前用户；保护目录、系统/客户端和后台专用应用不提供退出执行。没有强制结束。
- 请求前核对 App、Info.plist 和主程序的本地身份。退出可能被拒绝或出现保存提示，十秒内未确认则显示待确认；停止等待不撤销已经发出的请求。
- 每次操作在系统请求前写入任务历史，再保存观察结果。取消/失败不重试，重启不重放。完成后列表标记过期，刷新后才继续操作或卸载。此流程不产生删除或恢复收据。

基本验证：前端构建、203 项单元测试；7 项应用列表与操作浏览器回归；Rust 默认回归及专用原生样例测试。原生测试临时编译、自签和启动自建 App，观察打开、正常退出及原包保留；未操作用户应用。AppKit 的后台线程通知可能滞后，退出观察同时接受明确的 PID 不存在结果，权限不明不算退出。

用户级登录配置的暂停、后台注册移除与凭收据恢复已另接通首条主流程，详见 [启动管理](startup-management.md)。尚待补充：实际打包 App 的新入口窗口验收、多窗口保存提示交互及更完整中断矩阵。关联数据处理、其他登录项/后台来源和更新仍属后续应用管理范围，不能以打开/退出或首个启动来源代表完整应用管理完成。

## 图标与打开方式：确切副本重新注册

维护页“应用图标或打开方式异常”进入应用列表，用户读取清单、展开所选副本的“位置与来源”，再单独确认“重新注册此副本…”。导航和展开均不执行注册；请求只传成功清单的任务 ID、行号、动作及确认，不接受前端路径或任意命令。系统/当前客户端、受保护和非普通 App 不执行；请求前后重新核对所选包、Info.plist、主程序身份及保护状态。

原生执行调用公开的 [LSRegisterURL](https://developer.apple.com/documentation/coreservices/1446350-lsregisterurl)，`update=true` 更新这个安装副本。该 API 会注册应用及其文档/URL 声明，可能改变“打开方式”候选；没有调用显式默认应用设置 API，不能据此保证所有既有匹配结果不变。无需管理员或付费签名，不清空 Launch Services 数据库、不启动或退出任何应用、不重启 Finder，也不修改所选应用包。生产功能没有自动撤销或取消注册操作。

仅当系统状态为零，且 [NSWorkspace 返回的应用位置](https://developer.apple.com/documentation/appkit/nsworkspace/urlsforapplications%28withbundleidentifier%3A%29)包含确切安装路径时，结果显示“已观察到所选副本注册”。这不是图标显示或打开方式已修复的证明；用户需回到原问题验证。状态非零、位置无法核对或包/保护变化显示未知；接受请求但八秒内未观察到路径显示待确认，不自动重试。取消只停止后续核对，不能撤回已发出的系统调用；十二秒接口超时后原生工作仍持有活动任务和更新锁直至真实返回，不能把接口超时视为工作已结束。

请求前写入 `appregistration` 任务历史，记录确切路径和最终说明；重开时未结束任务按中断对账、不重放。没有文件删除/恢复收据；完成或接口错误后清单标为过期，需刷新再操作。

自建原生验收：在用户 Applications 下唯一临时目录编译普通 Cocoa App、ad-hoc 签名，真实调用注册后观察到该副本，Info.plist 和可执行文件字节保持原样；历史关闭重开后仍可读取。系统可能提前发现该目录中的 App，本次验证是**更新已有注册**，不声称证明从完全未注册到首次发现。仅测试结束时取消注册这个独有样例并移除自建文件，未启动/退出样例或用户应用。临时系统目录中的样例曾被 API 接受但未被位置查询发现，产品保留待确认分支。证据在本地 `.cache/app-registration-native.json`；实际打包 App 窗口、原问题视觉恢复及多副本长尾矩阵仍待验收。

本节点验证：Rust 全量 619 通过、84 个显式忽略样例（其中本次注册样例另行真实执行通过），前端单元测试 212 通过，应用列表/操作/问题入口浏览器回归 14 通过；三语言、格式、前端构建及 arm64 release App 构建校验通过。首次默认并发全量有两个既有进程测试失败，分别是退出样例后仍观察到占用、逃逸输出样例超时；两项单独复验通过，随后四并发全量通过，未修改无关实现。验证 App 位于 `local-artifacts/MooMole-0.2.0-mac-arm64-9bifto`，尚未安装或发布。
