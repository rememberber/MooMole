# 低空间系统提醒

2026-11-02：持续管理增加独立的系统提醒设置与提交记录。默认关闭；只在 MooMole 仍运行、定期空间观察明确开启、最近可靠样本低于已有 5/10/20 GiB 阈值时提交 macOS 本地通知。没有文件扫描、自动清理、网络请求、常驻 helper 或登录注册。采集周期与菜单栏的开关保持独立，退出后不通知。

## 用户流程

打开持续管理只读取配置、记录与系统通知状态，不申请权限或提交通知。先点“申请系统通知权限”，核对系统提示，再单独点“开启低空间提醒”。允许系统通知不会默许开启提醒或定期采集；提醒开启而采集关闭时页面说明不运行。拒绝后按 macOS 系统设置中的“通知”核对 MooMole，不反复发起申请。

可以在展开区单独勾选并发送一条测试提醒；测试不改变观察或提醒开关。提交后消费本次勾选，双击不重复；错误或响应丢失后先刷新记录，不自动重试。权限、开启状态和系统接受提交分别显示。“已提交给 macOS”不证明横幅出现或用户看到了通知，专注模式、前台状态及显示设置可能影响呈现。关闭开关不撤回已交给系统的通知。

## 原生接口与持久性

使用 Apple [UserNotifications 的授权接口](https://developer.apple.com/documentation/usernotifications/asking-permission-to-use-notifications)和 `UNUserNotificationCenter` 的状态读取与请求提交接口；不使用 AppleScript 或 Shell 发送通知，不增加前端任意标题、正文、附件、URL 或系统命令能力。标题和内容由后端中英日固定模板生成，只带当时容量和阈值，不放入个人路径或文件名。当前只请求 Alert，不请求声音、角标、临界通知或其他 entitlement。

原生适配须在匹配 App 标识的 `.app` 内、后台线程使用；未打包的测试/命令行进程拒绝且不弹窗。状态与提交等结果最多等待五秒，授权最多等待六十秒；回调持有自己的对象，超时后不会访问已释放的栈。迟到的权限结果不会开启任何配置；后续通过显式刷新核对。未知不推断成拒绝或成功，也不自动再申请。原生工作实际返回前保留安装占用；方法在超时返回后仍可能收到只携带结果的系统回调，不据此继续提交或写设置。

配置/去重状态和最近五十条提交记录分别保存在独立可选 SQLite 表 `storage_notification_state`、`storage_notification_records`，不变更 v8 版本、文件执行历史或共享执行容量。默认观察不创建表；明确保存配置或测试才创建。未来版本或损坏状态拒绝覆盖。只在 FULL 同步下写入提交意图和去重状态，事务提交成功后才调用系统；结果另行写入。结果写入丢失或应用退出后，重开把未完成提交记为未知，不重发。同一次低空间状态即使提交失败也不重复自动提醒；可核对权限和最近记录，再明确发测试。

去重按卷标识、总容量和阈值绑定。仅接受新于上次观察时间且处于两倍采集间隔内的样本；采集失败、进行中、历史/未来或时间回拨不触发。低于阈值只提交一次，持续低位不反复提醒；恢复到阈值以上一 GiB 后解除这一状态。切换卷或阈值以新的可靠观察重新判断，不回填休眠期间通知。读取与配置/测试/后台提交串行，最多一分钟检查一次已有空间样本，不增加独立文件扫描。

## 验证与剩余范围

真实临时 SQLite 回归覆盖默认关闭、权限/采集/提醒分离、阈值与恢复迟滞、过期/未知/时间回拨、持久意图先行、事务失败、完成丢失后的重开不重发、记录上限、未来版本保留及个人执行历史不变。所有样例自动回收，不在 home 创建目录。

`scripts/test-storage-notifications-native.mjs` 用自动回收的临时 ad-hoc App 包调用**同一生产原生适配**只读核对 macOS：实际返回 `notDetermined`，字段为真实 JSON 布尔值。脚本不申请权限、不提交通知、不安装或注册新登录项；临时包和编译源码在 finally 中删除。该证据只证明原生系统状态读取，不把未授权或模拟传输计作真实发送成功。授权弹窗、通知中心接受/实际显示、正式安装身份、重新打开和睡眠/专注模式完整矩阵仍待 App 内验证，未声称已经通过。

页面验证独立申请/开启、测试单独勾选、双击、拒绝/超时/错响应、未知刷新与重载不重发及紧凑中英日文；浏览器使用受控 transport。当前 DMG 未重打，不包含本节点。整个持续管理及八方向目标继续推进。
