# RAW 照片预览与视觉比较

2026-11-02：文件整理、重复文件、相似照片及软件内容的现有逐项预览支持系统可识别的 RAW 照片；相似照片的视觉模式也可收集 RAW，生成缩略图并与普通照片人工比较。列表显示“RAW 系统预览”，默认零选择；返回列表不改变选择。系统预览不代表完整动态范围、全部像素细节、编辑结果或完整原片。JPEG、RAW 与 XMP 不等价，不自动挑选、配对或连带处理同名文件。

## 主流程与边界

后端从保留扫描的来源、扫描 ID 和项目 ID 解析原文件，不接受任意路径。支持后缀包括 DNG、NEF/NRW、CR2/CR3/CRW、ARW/SR2/SRF、RAF、RW2、ORF、PEF 等；后缀只提供格式提示，仍须 ImageIO 实际确认其类型符合 camera RAW 且只有一份图像。格式名并不保证某相机可解码；不支持、异常、占位、受保护、身份变化、共享硬链接或超限时保留原件并显示失败/未完整覆盖。有效 PNG 和 TIFF 改名成 DNG、NEF 或 CR2 也会被拒绝。

单份 RAW 输入上限 256 MiB、八千万像素且任一边不超过六万。预览最长边 1024，比较输入最长边 384；只将有界 PNG 交给页面和既有 Vision 第二版比较。相似扫描继续共用二百张、512 MiB 输入预算及两分钟范围，不因 RAW 放宽；连续拍摄模式目前跳过 RAW 并标记未完整覆盖，不伪造 RAW 连拍线索。照片图库、Live Photos、权威连拍和完整编辑工作流仍待补。

读取前后核对本地状态、所有权、单链接、源身份、保护及完整内容摘要。解码使用单独的自有进程，输入为系统匿名临时文件的继承描述符和确切大小/设备/inode/摘要/随机请求标识，原文件路径不传给解码器。副本随描述符关闭回收，不建立用户目录内样例或长期 RAW 缓存。父进程校验返回标识、摘要、原尺寸、输出尺寸与 PNG，再核对当前来源。与已有预览共用并发槽位，执行任务期间不启动 RAW 预览。

关闭预览请求取消本任务，页面丢弃迟到结果；父进程负责停止并回收自有进程。单个解码进程响应期限最多十五秒、CPU 上限十二秒；独立二十秒退出计时覆盖没有 CPU 消耗或失去主程序监督的等待。整体预览三十秒响应期限到达仍保留真实工作所占资源直到结束，避免叠加解码。这些是自有进程的生命周期约束，并非操作系统沙箱或硬内存限额。

相似分组继续使用现有保守阈值和共同参考图规则，视觉相似不当作完整内容相同。计划记录每份所选 RAW 和保留文件的完整原始摘要；执行前流式重读完整文件，不能用预览 PNG 的摘要替代。至少保留一份，逐项选择后单独确认，涉及 RAW 时明确提示保留 JPEG 无法替代原始信息。真实废纸篓、停止、逐项持久结果、SQLite 重开与归档沿用现有个人文件流程。不清空废纸篓或承诺立即释放空间。

## 本节点验证

- 三份经公开仓库逐份 CC0 声明和 SHA-256 核对的真实相机样例：Ricoh GR DNG（4928×3264）、Nikon D3200 NEF（6016×4000）、Canon EOS 7D sRAW2 CR2（2592×1728）。实际 ImageIO 类型分别为 `com.adobe.raw-image`、`com.nikon.raw-image`、`com.canon.cr2-raw-image`。三张系统输出均已视觉查看；不外推为全部 RAW/相机兼容。
- 使用自有临时副本真实完成匿名句柄跨进程解码、Vision 分组、整组全选拒绝、单份选择/保留原片、正式 Mole 规则与原生废纸篓、确切收据取回、未选文件/XMP 保留、SQLite 重开及完整归档读回。所有样例根自动回收；收据取回是验收收尾，不计作产品内恢复验收。
- 在实际解码进程启动后取消，确认退出回收；独立工作进程在保持 stdin 打开且没有监督输入时二十秒自行退出。普通 PNG/TIFF 格式提示、保护/取消/变化、非匿名文件、请求和返回绑定四项默认测试与两项显式原生测试通过。
- 三份真实预览及真实分组报告通过正式 TypeScript 解析函数；真实处理结果通过页面容量计算。七条 RAW WebKit 流程覆盖默认不选、类型过滤、另行确认、错误来源/缺少 RAW 类型拒绝、关闭时确切请求取消及迟到丢弃、中英日文与 960×780 布局；另有二十六条相邻预览、影音、办公、个人文件和相似照片回归通过。
- 当前默认 Rust 704 项、前端 260 项及生产前端构建、4277 条翻译和格式检查通过。精简证据以 `raw-photo-native.json`、`raw-photo-protocol.json` 的条目进入 `.cache/verification/native-evidence.json`；实际图片、相机下载副本、截图和编译产物在收尾清理，只留来源/尺寸/摘要等可核对记录。

样例来源：[raw.pixls.us](https://raw.pixls.us/)；确切下载地址和逐份摘要在验证记录的 `cameraSources` 中。系统接口参见 [ImageIO source type](https://developer.apple.com/documentation/imageio/cgimagesourcegettype(_:)) 与 [thumbnail size](https://developer.apple.com/documentation/imageio/kcgimagesourcethumbnailmaxpixelsize)。显式原生测试需要先将记录中三份经许可核对的公开样例放到项目受控 `.cache/raw-samples` 并准备来源清单，构建本机 worker 后以 `MOOMOLE_RAW_WORKER_PATH` 指向该确切二进制运行 `personal_files::raw_photo` 的 ignored 测试，结束即清理；不得改成 home 样例或借用用户照片。
