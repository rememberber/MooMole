# 客户端任务诊断摘要导出

2026-10-17。任务详情提供“生成诊断摘要 → 预览完整内容 → 选择位置并保存”，用于用户主动提供最小排查信息。没有自动导出、自动上传或附带原始日志。

## 报告范围

报告为 UTF-8 JSON，schema 为 `moomole-client-task-summary-v1`。Rust 按任务 ID 读取现有 SQLite 记录，使用固定字段生成内容：

| 字段 | 含义 |
| --- | --- |
| appVersion / platform / architecture | 当前构建版本、操作系统及架构常量；不包含设备名称、硬件清单或用户名 |
| currentEngineVersion | 生成摘要时通过包内完整性检查的当前引擎版本；无法确认时为 null，不补写历史引擎版本 |
| taskKind / taskState | 已支持的任务类型与状态；未知值映射为固定 unknown，不复制原值 |
| directoryRecorded / diagnosticRecorded | 是否保存目录/诊断字段；诊断存在不代表失败，也不导出字段内容 |
| recordElapsedMs | 起止时间差；缺失、倒退或超出日期范围时为 null，零用时为 0，不等于引擎测量耗时 |
| schema / note | 固定格式与证据边界说明 |

不导出路径（含 HOME 和卷名）、任务 ID、精确时间、主机名、原始类型/状态自由文本或原始诊断。自由文本直接省略，不靠正则猜测并替换其中的密码、邮箱、URL 或其他隐私。原始诊断仍可在详情中本地查阅；摘要不包含具体错误正文，可能不足以单独定位失败原因。

## 预览与保存

- 生成摘要不写文件、不启动 Mole 任务，也不更改历史。报告固定为生成时的快照；历史详情继续更新时，报告不随之改变。重新生成会清除旧预览及提示。
- 完整 JSON 以可聚焦、可滚动的文本区展示；生成后焦点移到预览。只有已有预览才显示保存操作，保存的 UTF-8 字节与预览字符串一致（含末尾换行）。
- `save_task_diagnostic` 只接受有限大小（8 KiB）、固定 schema/字段/枚举/构建信息和规范序列化格式，不接受任意文本或输出路径。额外字段和不支持格式被拒绝。
- 原生保存窗口返回用户选择的本机 .json 路径；不增加前端文件写入或通用 Shell 权限。取消返回未保存；失败显示原因并保留预览以便重试。关闭任务详情会清除报告界面，迟到的结果不会进入下一次详情；已打开的系统保存窗口仍需用户完成或取消。
- 使用所选目录中的私有临时文件（0600）、完整写入及同步，然后以不覆盖方式发布。已有普通文件、目录或末级符号链接均不会被替换，提示换新文件名；写入失败清理自己的临时文件，不触及原文件。
- 用户选择的报告文件独立于 App 历史保留期，由用户管理；不自动回读、分享或上传。

## 验收边界

Rust 隔离测试覆盖自由文本省略、未知/时间边界、非法或附加字段拒绝、预览与保存字节一致、0600 权限、现有文件/链接保护和失败临时文件清理。浏览器验证先预览后保存、静态快照、取消/失败重试、生成失败及关闭重开清除；原生验证系统保存窗口和实际文件。具体结果见开发记录第三十五阶段。

本轮只覆盖客户端检查任务元数据摘要，不代表 Mole 原始历史、执行收据、环境故障诊断或原始日志的脱敏导出已完成，也没有新增清理/恢复功能。
