<h1 align="center">MooMole</h1>

[English](README.md) · [简体中文](README.zh-CN.md) · **日本語**

Mole CLI の機能を分かりやすい操作で利用できる、非公式の macOS 向け GUI クライアントです。結果を見て、影響を理解し、次の操作を選ぶ、シンプルで直感的な体験を目指します。React + Vite + TypeScript + Tauri + SQLite を使用しています。

> 本プロジェクトは学習・研究向けの独立した非公式プロジェクトです。操作の影響を理解し、重要なデータをバックアップしてからご利用ください。利用のリスクおよび生じた問題は利用者の責任となります。
>
> 一部の機能は [Mole CLI](https://github.com/tw93/Mole) に基づきます。作者と貢献者に感謝します。開発成果を尊重し支援するため、日常利用には [Mole 公式製品](https://mole.fit/)をご検討ください。

## 言語

画面は簡体字中国語・英語・日本語に対応しています。**設定 → 一般 → 表示言語**で、再起動せずいつでも切り替えられます。初回起動はシステムの第一優先言語に従い、対応外の言語では英語を使用します。手動選択は本機に保存され再起動後も有効で、「システムに従う」に戻すこともできます。パス・元のログ・診断の証拠は原文を保持します。詳細な開発文書は現在主に中国語です。

## ローカル開発

ビルド対象は macOS 14 以降です。実際のネイティブ操作検証は主に Apple Silicon の開発機で行っており、対象指定だけで最低 OS や Intel の検証完了を意味しません。

Node.js 24 以降・npm・Rust・Go・Xcode Command Line Tools が必要です。固定バージョンは[ビルド検証](docs/build-validation.md)をご覧ください。スクリプトはプロジェクト `.cache/` のツールを優先し、Shell 設定を変更しません。新規クローンではツールの準備が必要です。

```sh
npm ci
npm run engine:prepare
npm run desktop

# ブラウザのサンプルのみ。本機データは読まない
npm run dev

# 本機用の最適化 App・ZIP・検証報告を生成。アップロードや公開はしない
npm run build:local-app

# アーキテクチャに合う無料 ad-hoc DMG も生成・マウント・検証・取り出し
npm run build:local-dmg
```

エンジンは固定 Git ツリーからビルドし、リソース・アーキテクチャを検証後に原子的に配置します。失敗時は旧エンジンを保持します。必要なキャッシュがあれば準備・本機用生成コマンドに `-- --offline` を追加できます。App の実行には開発ツールは不要で、内蔵エンジンをダウンロード・個別更新しません。[エンジン準備](docs/engine-integrity.md)と[ローカルビルド](docs/local-app-build.md)をご覧ください。

## チェック

アプリの版は `package.json` のみ編集し、`npm run version:sync` でネイティブとロックファイルを同期します。

```sh
npm run version:check
npm run format:check
npm test
npm run build
npm run notices:prepare # ネイティブビルド前のライセンス資料準備。Tauri ラッパーも自動実行
npm run check:rust
npm run test:engine
npm run test:adapter
npx playwright install chromium
npm run test:e2e
```

ブラウザ回帰は専用の 1431 ポートを使い既存サーバーは再利用しません。競合時は `MOOMOLE_E2E_PORT=1432` を指定できます。開発 App は 1420 です。その他の版・成果物・出所・ライセンス・候補ツールの確認は[ビルド検証](docs/build-validation.md)をご覧ください。通常の Checks はリリースと独立しています。MooTool と同様に、版タグの push で並列パッケージ生成、3 言語の GitHub Release 公開、更新フィードと README のダウンロード欄の更新を自動実行します。[リリース規約](RELEASE_CONVENTIONS.md)をご覧ください。

## ローカルデータと復元

設定と記録は `~/Library/Application Support/io.github.rememberber.moomole/`、DB は `moomole.sqlite` です。パス・確認結果・操作意図・ゴミ箱レシートを含む場合がありますが、本文や管理者パスワードは保存しません。AI 詳細スキャンのみ別途同意後、限定したメタデータを選択 Agent のモデルサービスに送ります。他の記録は自動アップロードしません。

タスク・スキャン・確認履歴は既定 30 日で、7 日・90 日も選べます。実行証拠と未照合の中断証拠は通常履歴と一緒に削除しません。3 実行モジュールは共通の変更受け入れと活動記録上限を使い、満杯なら新バッチを停止します。**操作履歴 → アーカイブ…**で、終了して必要な照合済みの記録を完全保存し活動枠を解放できます。元のプラン・各結果・レシート・イベント・照合マークを保持し、書き出し・読み取り専用表示に対応しますが実行許可は復元しません。[保持方針](docs/local-data-retention.md)と[実行アーカイブ](docs/execution-archive.md)をご覧ください。

DB schema は v7 です。v1〜v6 からの更新前には自動バックアップします。旧 App で新 DB を直接開かないでください。中断後は変更を自動再開しません。不明な結果は実物を照合してから確認済みを記録し、元の不明結果を書き換えません。DB のワンクリック巻き戻しや共通取り消しはありません。[更新と復元](docs/native-upgrade-recovery.md)をご覧ください。

フロントエンドに汎用 Shell・任意 SQL・直接のファイルアクセスインターフェイスはありません。変更はログ・アンインストール・Quick Look の個別確認と実行時検証を通します。更新は固定取得元のみで、フォルダ・履歴・診断は送りません。[更新のプライバシーと仕様](docs/update-check.md)をご覧ください。読み取り専用の確認でも本機キャッシュや確認記録を書く場合があり、完全な書き込みゼロを意味しません。
